### 출처 ID 검증 시 주의

- `train_source_split`+`train_source_index` 두 값만 비교하면 **61개 키가 겹침**. 모두 **MNIST 숫자 Training vs EMNIST 문자 Test**처럼 서로 다른 원본 데이터셋에 속해 발생하는 **인덱스 숫자 재사용**으로 확인됐다.
- 원본 데이터셋 종류(숫자 MNIST / 문자 EMNIST)를 추가해 비교하면 출처 교집합은 **0건**이다. 따라서 해당 61개를 근거로 동일 원본 데이터 누출이라고 판단하면 안 된다.
