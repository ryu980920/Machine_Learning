# Hand-made 데이터 활용·분할 계획 (2026-11-10)

> **신규 640장씩은 권장 수집안이며 수집·최종 확정된 데이터가 아니다.**

| 데이터 | 규모 | 역할 |
|---|---:|---|
| 공식 Training 내부 학습 | 76,800장 | Normal과 Combined 공통 Training |
| 공식 Training 내부 Validation | 19,200장 | 공식 데이터에 대한 개발용 Validation |
| 기존 Hand-made, 41–44번 | 2,560장 | Combined 추가 학습 **후보**, 효과 비교 실험 후 채택 |
| 신규 Hand-made Validation | 640장(제안) | 새로운 작성자의 개발용 반복 검증 |
| 신규 Hand-made Test | 640장(제안) | 모델 고정 이후의 독립 손글씨 평가 |
| MNIST·EMNIST 공식 Test | 16,000장 | 모델 고정 이후 별도 공식 평가 |
| 교수님 1차 데이터 | 미정 | 배포 지침에 따른 별도 외부 평가 |

## 신규 수집 제안
- Validation: 신규 작성자 8명 × (0–9,A–F 16개 클래스 × 클래스별 5장) = **640장**.
- Test: 학습·Validation과 다른 신규 작성자 8명 × 80장 = **640장**.
- 모두 28×28, 0–255 Grayscale, 클래스 레이블 및 원본·처리 이력을 별도 기록.
- 9:1 또는 8:2 비율을 억지로 맞추기보다 **작성자 독립성·클래스별 균형·수집 가능성**을 우선한다.

## Normal vs Combined 효과 비교
1. Normal: 공식 Train **76,800장만** 학습.
2. Combined 후보: 같은 공식 Train **76,800장 + 기존 손글씨 2,560장** 학습.
3. **각 모델의 모델 설정·전처리·분할·평가지표는 동일**하게 유지하여 손글씨 추가 효과만 평가한다.
4. 두 조건 모두 **동일한 신규 Hand-made Validation 및 공식 Validation**으로 Accuracy, Macro F1, 클래스별 성능, 작성자별 성능 및 추론 시간을 비교한다.
5. 효과가 확인되면 Combined 채택을 논의한다. 결과가 나쁘면 데이터 비중 조정·증강·전처리 등의 후속 실험 대상으로 남긴다.

## 데이터 누출 및 평가 오염 방지
- 기존 2,560장 전체는 이미 탐색 평가를 거쳤으므로, 이후 개발·학습에 활용해도 되지만 **최종 독립 Test라고 부르지 않는다**.
- Training/Validation/Test는 **작성자가 겹치지 않도록** 관리하고, 학습 원본의 증강 이미지가 Validation/Test에 들어가지 않도록 한다.
- Validation은 반복 사용해 모델 설정을 개선할 수 있으나 **개발용 점수**로 표기한다.
- 모델·전처리 고정 전 신규 Test와 공식 Test를 사용하지 않는다. Test 점수를 보고 다시 튜닝하면 그 Test는 더 이상 독립 평가가 아니다.
- 교수님 배포 1차/2차 데이터는 실제 배포 지침에 따라 별도로 관리한다.
