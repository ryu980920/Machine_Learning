# 02_data — 데이터셋 제작 및 관리

## 1. 개요

eMNIST와 직접 만든 Hand-made 데이터셋의 수집, 이미지 변환, 레이블 검수, 결합 및 수정 이력을 관리합니다. 데이터가 어디서 왔고 어떤 과정을 거쳐 사용되었는지 추적하는 것이 목적입니다.

## 2. 작업 내용

- 대상 클래스는 숫자 0~9와 대문자 A~F, 총 16개로 통일합니다.
- 개인별 손글씨는 클래스당 40개, 총 640개를 작성합니다. 16행 × 10열로 160자씩 4장을 만들 수 있습니다.
- 원본을 촬영·스캔한 뒤 글자별 28×28 grayscale 이미지로 분리하고 정답 레이블을 연결합니다.
- 원본 이미지, 이미지·레이블을 담은 .npz, 변환·검증 Notebook(.ipynb)을 검수합니다.
- eMNIST의 16개 클래스 수량을 확인하고 학습에 사용할 데이터를 균형 있게 구성합니다(전체 10만 인스턴스 이상).
- 원본, 전처리본, 결합 데이터, 교수님 배포 평가 데이터의 용도를 구분합니다. 최종 테스트 데이터는 학습에 섞지 않습니다.
