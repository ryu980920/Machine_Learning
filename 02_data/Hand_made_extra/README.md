**이번 브랜치의 목적:** 7·8·9·B를 보강한 실제 손글씨 480장을 **추가 Training 후보**로 보존하고, 기존 Combined와 학습 데이터만 바꾼 실험을 수행한다. 기존 Hand-made 41–44 NPZ와 공식 Training, 기존 Validation/OOF, 원본 Test를 변경하지 않는다.

- 외부 손글씨 438장과 **바이트 수준 완전 일치 이미지 0개**, 최대 픽셀 코사인 유사도 **0.87197**(참고 진단).

## 사용 정책

- 기준선: 공식 Train 76,800장 + 학습용 기존 3 Writer 1,920장 = **78,720장**.
- 추가 조건: 기준선과 똑같은 전처리·하이퍼파라미터, **추가 480장에 CoM만 적용**, 총 **79,200장**으로 학습.
- 기존 4-Writer Fold의 보류 Writer 640장 및 OfficialVal 19,200장에 새 480장을 섞지 않는다.
- 이전 실측 438장은 이번 신규 480장과 **별도**이며, 학습/선정에 다시 사용하지 않는다.
- 원본 Test·교수님 Test 불사용. 별도 독립 신규 작성자 검증 전까지 일반화 개선을 단정하지 않는다.

**원본 보존:** 마스터 NPZ의 이미지·레이블·형상·강도를 임의로 수정하거나 필터링하지 않았다. 사람이 판독하기 애매한 7은 모델 평가에서 오류 방향을 모니터링할 연구용 주의 대상으로 남긴다.
