# Extra Trees 실험 계획

## 분할과 선정 기준

- W02 실험 2의 공식 Train 76,800장, 공식 Validation 19,200장, 분할 시드 42를 고정한다. source group과 분할 인덱스를 보존한다.
- Normal 학습은 공식 Train만 사용하고, 팀 손글씨 41~44번은 개발용으로 평가한다.
- Combined 학습은 41~44번 작성자 중 세 명의 원본 손글씨 1,920장을 공식 Train에 더한다. 각 Fold에서 보류 작성자 640장의 예측을 한 번씩 수집한다. 공식 Validation의 Fold 평균은 같은 19,200장을 네 모델이 예측한 수치다.
- 각 모드의 원본 픽셀 기준선에서 공식 Validation 정확도 하락 0.50%p 이하 후보를 비교한다. 연구에서 정한 선택 조건이며 팀 공통의 합격 기준과 구분한다. 손글씨 Macro F1을 최대화하고, 동률일 경우 손글씨 정확도, 공식 정확도, 적은 트리 수 순서로 결정한다. Combined와 Normal에서 각각 동일한 절차를 적용한다.
- 개발 자료는 후보 선정에 사용된다. 결과의 일반화 범위는 본 연구의 공식 Validation 및 네 작성자에 한정한다. Original Test와 교수님 Test는 실행 대상에서 제외한다.

## 대조 조건과 가설

| 실험 | 비교 대상 | 변경 변수와 가설 |
|---|---|---|
| P00 | W02 실험 2 | 원본 0–255 픽셀과 ExtraTreesClassifier 기본 설정, 시드 42 |
| P01 | P00 | CoM만 적용하면 위치 차이로 생기는 오류가 줄어든다 |
| P02 | P01 | 공식 학습 30%에 긴 변 16·18·20·22·24 px를 균형 배정하면 글자 크기에 치우친 판단이 줄어든다 |
| P03 | P02 | 동일한 크기 대상에 획 혼합 0.28을 적용하면 획 굵기 차이를 흡수한다 |
| P04 | P03 | 픽셀에 HOG를 추가하면 국소 획 방향이 유사한 클래스 구분에 도움이 된다 |
| P05 | P04 | HOG만으로도 충분하다면 픽셀을 빼도 손글씨 성능이 유지된다 |
| T01–T06 | 각 모드의 P단계 선택 후보 | max_features, min_samples_leaf, max_depth, n_estimators를 한 변수씩 변경한다 |
| R42/17/73 | 최종 선정 설정 | 설정을 고정하고 추정기 시드별 편차를 측정한다 |
| LC20/40/60/80 | R42 | 공식 Train의 클래스 층화 중첩 부분집합으로 데이터 수 효과를 측정한다 |
| CTRL_normal | Combined R42 | Combined 선정 설정에 공식 Train만 사용한다. 모델·시드·전처리를 고정한다 |

P단계는 트리 100개, max_features=sqrt, min_samples_leaf=1, max_depth=None, bootstrap=False다. HOG는 9방향, 7×7 px 셀, 2×2 셀 블록, L2-Hys로 324차원을 만든다. 픽셀은 784차원이다. 크기·획 증강은 팀 공통 구현의 공식 학습 이미지 일부 교체 방식이다. 획 0.28은 원본과 침식 또는 팽창 결과의 혼합 계수이며, 전체 Train의 28%를 추가한다는 뜻과 다르다. 획 위상을 바꾸는 후보는 거부한다. 평가와 손글씨 학습에는 크기·획 증강을 적용하지 않는다. Normal과 Combined의 대조에 같은 공식 Train 인덱스와 전처리 시드를 사용한다.

T01: max_features=0.08 · T02: max_features=0.18 · T03: min_samples_leaf=2 · T04: max_depth=24 · T05: n_estimators=64 · T06: n_estimators=160. 이 탐색은 선택한 전처리 주변의 일변수 비교다.
