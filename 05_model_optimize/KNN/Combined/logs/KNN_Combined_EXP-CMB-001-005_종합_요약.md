# KNN Combined EXP-CMB-001~005 종합 실험 기록

## 목적 및 평가 설계

- 대상: MNIST 숫자 0~9 및 EMNIST 문자 A~F, 16개 클래스
- 공식 데이터: Training 76,800장, Validation 19,200장. Official Test는 Combined 탐색 과정에서 사용하지 않음.
- Hand-made: 작성자 41·42·43·44, 각 640장(총 2,560장)
- Combined 검증: Leave-One-Writer-Out 4-Fold. 각 Fold에서는 공식 Training + 학습 작성자 3명(1,920장)만 학습, 나머지 작성자 640장 평가.
- 성능 표기는 4개 작성자 각각의 보류 예측을 합친 OOF 결과이며, 기존 Hand-made 데이터를 반복적으로 모델 선정에 이용했기 때문에 **개발용 OOF**임. 독립적인 최종 테스트 성능이 아님.

## 최종 개발 후보 설정

- KNeighborsClassifier(n_neighbors=3, weights='distance', metric='minkowski', p=2)
- 전처리: Center of Mass 정렬 → Deskew
- 특징: Pixel(784) 20% + HOG(324) 80%, 총 1,108차원
- 매 Fold 공식 Training 기반: 107,520장 (원본 76,800 + 일반 증강 23,040 + 표적 클래스 D/B/5/3 증강 7,680)
- 매 Fold 추가 손글씨: 학습 작성자 3명 원본 1,920 + 증강본 1,920 + 혼합 복제 960 = 4,800장
- **총 학습 샘플 112,320장/Fold**
- 보류 작성자의 손글씨는 해당 Fold 학습·증강·복제에 전혀 포함하지 않음.
- 개발 OOF: 2,403/2,560, Accuracy 93.8671875%, Macro F1 0.938730
- 공식 Validation: 마지막 실험 20:80에서 Fold 최저 98.1667%; 단일 최종 학습 모델의 공식 Validation이나 Test 성능으로 오해하지 말 것.

## 결과 해석과 남은 작업

1. 최적화 Normal 개발 평가(2,381장) 대비 Combined 최종 개발 OOF는 2,403장 정답으로 **22장(+0.859375%p)** 개선됨.
2. 4명 모두를 반복적으로 최적화에 사용했으므로, OOF라 하더라도 새로운 작성자에 대한 완전히 독립적인 테스트가 아님. 보류 작성자는 해당 Fold 학습에서 제외됐지만 설정 선정에 간접 사용됨.
3. 실험별 변화가 작은 CMB-003/004/005의 차이에 통계적 확신을 부여하지 말 것.
4. 최종 단일 배포 모델이 필요하다면 **공식 Training 기반 107,520장 + 전체 네 작성자의 원본·증강 및 정해진 복제 규칙**으로 한 번 더 학습해야 함. 이 모델은 4-Fold OOF에 쓰인 네 모델과 다름.
5. 이전 Normal의 Official Test는 이미 사용했으므로 모델 선택을 위해 Official Test를 재사용하지 않는 것이 바람직함. 새로운 작성자 데이터가 확보되면 학습에 전혀 관여하지 않은 외부 테스트로 별도 검증.
