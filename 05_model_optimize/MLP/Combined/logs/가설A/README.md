# Combined — 가설 A: 숫자·문자 간 픽셀/형태 판단 근거

## 검증 목적

Combined 4-Fold OOF에서 남은 `0↔D`, `8↔B` 혼동은 **어떤 픽셀 좌표·획 영역·연결 구조가 경쟁 클래스 점수에 영향을 주는지**를 조사할 필요가 있다.

- `0`과 `D`, `8`과 `B`의 정답/오답 사례에서 Signed IG와 클래스 간 Logit Margin은 어떻게 다른가?
- Normal은 맞혔지만 Combined에서 새로 틀린 사례에서 모델 판단은 어떻게 달라졌는가?
- 좌표별 픽셀 민감도와 사람이 구분하는 획·형태의 영향은 구별되는가?

## 선행 및 실험 목록

- [Combined 초기분석 EXP유002 — Error Analysis](../초기분석/EXP유002_Error_Analysis.md) (**계획 / 미실시**)에서 전체 오류·실제 이미지·특징과 대표 판단 근거를 먼저 살펴본다.
- 후속 가설 A 실험은 **아직 등록된 실행·산출물이 없다**. 원인 분석 결과가 확보된 뒤 독립 실험 로그를 만든다.
- 참고: [Normal 가설 A](../../../Normal/logs/가설A/README.md). Normal에서의 결과를 Combined의 검증된 사실로 옮기지 않는다.

## 판단 원칙

기존 가중치 고정, 작성자 보류 Fold 준수, 실제 이미지와 무작위/동일 밝기량 대조군 사용. Signed IG만으로 MLP가 사람과 동일한 형태 개념을 학습했다고 결론 내리지 않는다.
