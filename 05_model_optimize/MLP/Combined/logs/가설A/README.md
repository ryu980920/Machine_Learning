# Combined — 가설 A: 숫자·문자 픽셀 판단 및 의미 있는 획 구조

## 목적

MLP의 특정 좌표 픽셀 반응과 사람에게 의미 있는 획·곡률·연결 구조의 역할을 구분한다.

## 현재 판정 — 조건부 보류

[초기분석 CMB-002](../초기분석/EXP-CMB-002_Error_Analysis.md)에서 실제 이미지 89장의 클래스 간 Logit Margin·Signed IG와 고정 영역 제거 실험을 수행했다. 영역별 민감도는 확인됐으나, **픽셀의 위치·밝기·형태가 함께 바뀌는 개입**만으로 의미 있는 획 구조의 효과를 분리하지 못했다.

추가로 전체 밝기 히스토그램·Bounding Box와 전경 수를 보존한 픽셀 교환을 **61개 원본 이미지**에 적용했지만, 획 4-이웃 연결을 더 많이 훼손한 조작의 추가 효과는 이미지 단위 95% 구간에 0이 포함되었다.

따라서 **가설 A를 기각하는 것이 아니라, 별도 개선 실험으로 먼저 진행할 실증 근거가 부족해 보류**한다. [가설 B](../가설B/README.md)를 우선 검증한 뒤에도 남는 오분류에서 사람이 형태 유지·훼손을 검증한 대조가 필요할 때 재개한다.

참고: [Normal 가설 A](../../../Normal/logs/가설A/README.md). 서로 다른 기존 학습 모델의 결과를 혼용하지 않는다.
