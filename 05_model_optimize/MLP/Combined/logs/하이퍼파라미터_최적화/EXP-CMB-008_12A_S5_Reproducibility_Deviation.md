# EXP-CMB-008 · 12A 재현성 검증 결과와 실험 프로토콜 변경 기록

> **기록 시점:** 36개 신규 Epoch Trace 학습 완료 및 최초 집계 중 재현성 검증 오류 확인 직후. 자료를 사후 삭제하거나 원본 S5 성능에 억지로 맞추지 않는다.

## 1. 사전등록에서 약속한 검증

- Original S5 ES=True `run 44020696572`의 3 Seed × 4 Fold 각 Stop Epoch와 최종 held-out Writer 예측 640개를 신규 `es10` 실험으로 정확히 재현해야 한다.
- 동일 Seed/Writer의 `es10`과 `internal120`은 초기화·Validation 분할·Optimizer를 동일하게 하고, Stop 이전 Epoch의 Train Loss/Validation Accuracy/OOF 정확도/4개 혼동 방향이 모두 일치해야 한다.
- 위 조건 불충족 시 '원본과 동일 경로' 또는 '종료 방식만 바꾼 완전한 인과 비교'라는 결론을 내리지 않는다.

## 2. 실제 발견한 문제

최초 집계에서 **36개 학습 및 원본 아티팩트 다운로드는 모두 성공**했지만, 원본 S5와 신규 `es10`의 Stop Epoch/최종 OOF 예측을 함께 비교할 때 **정확히 일치한 Fold는 3/12개**였다. 다른 Fold는 종료 횟수 또는 최종 예측이 달랐다. 예: Seed43 Writer41 원본 67 Epoch, 신규 36 Epoch. 이는 동일 Seed 설정이 반드시 동일한 학습 경로를 재현한다는 가정이 실제로 만족되지 않았음을 의미한다.

- `prepareraw`의 Size/Stroke 증강은 Seed와 원본 인덱스 기반 결정론적으로 정의되지만, 모든 실행 환경에서 전체 MLP 학습이 완전히 결정론적이었다고 증명하지는 못했다.
- 원인은 현재 **미확정**이다. BLAS/OpenMP 연산 순서, 내부 검증 점수의 작은 변화 등이 가설일 뿐 단정할 수 없다.
- **원본 데이터, 이전 S5 CSV/JSON, 기존 모델은 변경하지 않는다.** 불일치를 무시하고 '재현 확인'이라고 기재하지 않는다.

## 3. 결과 공개 방식의 변경과 제한

최초 집계의 '완전한 재현 필수' 검사가 실패했으므로, 이후 보완 집계에서는 **각 Fold별 Stop Epoch·원본 예측 불일치 건수, `es10` vs `internal120`의 Stop 이전 곡선 일치 여부를 모두 공개**한다. 이 검증 결과가 12/12가 아니라면:

1. 그래프는 **같은 설정으로 재측정한 실제 모델들의 Epoch별 관측값**으로 표시한다.
2. `es10` 복원 OOF를 이전 S5의 91.771%라고 표기하지 않고, **원본 S5 발표값과 신규 재측정값을 분리해 표기**한다.
3. `internal120`이 Stop 이후 성능을 개선하더라도, Stop 이전 경로가 일치하지 않으면 'Stop만 뒤로 미뤄서 성능이 개선됐다'는 엄격한 인과적 결론을 내리지 않는다.
4. 필요시 **같은 실행 환경·같은 Fold에서 `es10`과 연장 학습을 연속 수행**하는 추가 재현성 실험이 필요하다는 점을 차기 과제로 명시한다.
5. Held-out Writer OOF별 최고 Epoch는 여전히 진단 전용이다. 과적합을 유발할 수 있으므로 사후 최적 Epoch로 가중치를 선택해 배포하지 않는다.

- 보완 결과에는 `diagnostic_summary.json`의 Fold별 `replay_s5_audit`, `continuation_audit`가 포함된다.
- Learning Curve는 **엄격한 인과 재현성 검증과 별개로** 실측 시각화한다. 실험 프로토콜 변경을 숨기지 않으며 원본 S5 선정값은 재평가 결과가 검증되기 전까지 유지한다.
