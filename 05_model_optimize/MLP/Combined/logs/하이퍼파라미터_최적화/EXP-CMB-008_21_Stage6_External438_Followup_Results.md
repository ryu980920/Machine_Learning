# EXP-CMB-008 · S6 후속 — Batch 128/200 사용자 판정 438장 비교 및 우선 후보 재검토

> **연구 판단(2026-11-18): Batch 128을 정확도 중심의 개발용 우선 후보로 상향한다.** 신규 438장 평균 Accuracy, Macro F1, Writer OOF, OfficialVal에서 Batch 128이 모두 우세했다. 다만 **기존 S6 사전등록 가드레일은 Batch 128이 통과하지 못했다**. 이는 S6 원래 판정을 소급 수정한 것이 아니라, 새 438장 평가에 따른 **사후 후속 판단**이다. 독립 Test 평가·최종 HP 적용·모델 배포는 하지 않는다.

## 1. 배경과 이번 실험의 목적

- 기존 [S6 36모델 결과](EXP-CMB-008_20_Stage6_Batch_Size_Results.md)에서는 Batch 128이 Writer OOF **92.409%**로 Batch 200 **91.810%**보다 높았으나, `B→8`, `0→D`, 취약 클래스 전체 오분류율 비증가 조건을 통과하지 못해 **Batch 200을 개발용 기준으로 유지**했다.
- 사용자 판정이 반영된 새로운 Hand-made 480장 중 품질 검토를 통해 42장을 제외한 **438장**이 준비되어, Batch 128·200이 기존 작성자 이외 입력에서 어떻게 다른지 직접 비교했다.
- 비교 대상은 기존 S6 실험 조건 그대로 재학습한 **Batch 200 12모델 / Batch 128 12모델**, 총 24모델이다. 평가용 438장은 어떤 학습·Early Stopping·증강 설정에도 사용하지 않았다.
- 단, 438장은 이전 모델의 오류 확인과 사용자 품질 판정이 개입된 데이터이므로 **독립적인 최종 Test가 아닌 개발 진단용 외부 손글씨 데이터**다.

## 2. 실험 조건 및 데이터 경계

## 4. 혼동 방향·취약 클래스의 상충 결과

**438장에서 모델 1개당 평균 혼동 건수** (각 모델이 같은 이미지를 평가):

| 실제 → 예측 | Batch 200 | Batch 128 | 판정 |
|---|---:|---:|---|
| D→0 | 1.17 | **0.75** | 개선 |
| B→8 | 6.50 | **5.83** | 개선 |
| 8→B | 0.00 | 0.00 | 동일 |
| 0→D | **3.33** | 4.25 | 악화 |
| 7→9 | **8.33** | 8.75 | 악화 |
| 7→A | **1.42** | 1.75 | 악화 |
| 4→F | 2.00 | **1.67** | 개선 |

**438장 실제 클래스 기준 평균 전체 오분류율**:

| 클래스 | 해당 이미지 수 | Batch 200 | Batch 128 |
|---|---:|---:|---:|
| 0 | 27 | **19.136%** | 19.444% |
| 7 | 22 | 51.515% | 51.515% |
| 8 | 28 | 2.381% | **1.488%** |
| B | 26 | 29.808% | **26.923%** |
| D | 27 | 12.654% | **7.099%** |

- Batch 128은 B·D 등 취약 클래스에서 개선됐지만, `0→D`와 `7→9`가 증가했다.
- 특히 **7 클래스 전체 오분류율 51.515%**는 두 Batch에서 동일하고 높다. Batch Size 변경만으로 이 문제를 해결했다고 볼 수 없다.
- **기존 4-Writer OOF의 사전등록 가드레일 기준으로는 Batch 128이 여전히 실패**한다. 기존 S6 오류 건수: Batch 200 `D→0=77`, `B→8=46`, `8→B=46`, `0→D=10`; Batch 128 `72`, `50`, `43`, `15`. 따라서 438장의 일부 혼동 개선을 원래의 안전 기준 통과로 바꾸어 적지 않는다.

## 5. 원본 S6와 이번 재실행 간 재현성 감사

| 비교 | Batch 200 Writer OOF | Batch 128 Writer OOF |
|---|---:|---:|
| 기존 S6 36모델 실행 (기록 보존) | 91.810% | 92.409% |
| 이번 24모델 재실행 | 91.497% | 92.565% |

- 두 실행은 동일 S6 조건을 목표로 했으나 수치가 정확히 재현되지 않았다. 원인은 확정되지 않았으며, 원래 36모델 결과나 사전등록 판정을 **덮어쓰지 않는다**.
- Batch 128과 200의 438장 차이는 **이번 24모델 재실행 내부의 대응 비교**로 해석한다. 원래 S6의 200과 새 S6의 128을 섞어 직접 비교하지 않는다.
- 438장은 이미 확인·품질 선별한 데이터이므로, 이를 근거로 HP 우선순위를 바꾸면 개발 데이터에 대한 추가 선택 편향이 생길 수 있다. 새로운 결론을 사전등록 결과처럼 제시하지 않는다.

## 6. 후속 판단 및 다음 단계

1. **정확도 중심 개발용 우선 후보: Batch 128.** 신규 438장, 재실행 Writer OOF·OfficialVal, Macro F1 및 Fold 간 변동성에서 Batch 200보다 우세하다.
2. **기존 안전 기준의 공식 통과 판정: 변경 없음.** Batch 128은 기존 S6 `B→8`, `0→D`와 일부 취약 클래스 비악화 가드레일에 미달했다. 기존 S6의 Batch 200 유지 판단은 당시 규칙에 따라 타당하게 기록된 결과로 남긴다.
3. **남은 문제:** `7→9`와 `0→D`의 악화, 7 클래스의 높은 오류율을 별도 후속 진단 대상으로 삼는다. 신규 438장을 다시 반복적으로 선택·튜닝하는 경우 독립 검증 필요성을 함께 기록한다.
4. **배포 결정:** Batch 128은 **후속 우선 후보**이지 최종 배포 확정 모델이 아니다. Original Test·교수님 Test 평가나 모델 배포, 최종 HP 갱신은 별도 사용자 승인과 절차 이후 진행한다.
