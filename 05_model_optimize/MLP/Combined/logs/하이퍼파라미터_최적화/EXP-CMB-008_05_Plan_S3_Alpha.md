# EXP-CMB-008 · 05 사전등록 — S3 L2 alpha 최적화

> S2 결과 확인 후, 신규 S3 학습 **시작 전 작성**. 결과를 본 후 후보·판정 규칙 변경 금지. [S1 실측](EXP-CMB-008_02_Stage1_Width_Results.md) → [S2 계획](EXP-CMB-008_03_Plan_S2_Depth.md) → [S2 결과](EXP-CMB-008_04_Stage2_Depth_Results.md) → 본 S3 계획.

## 1. 왜 다음으로 L2 규제인가?

- S2에서 (256,) 기준 OOF **92.213542%**, OfficialVal **97.044271%**. (256,128)은 OOF **91.927083%**로 하락하고 B→8 43→54건, 8→B 38→48건, 0→D 14→24건으로 악화.
- (256,256)은 OOF **92.278646%**로 미세하게 향상했지만 8→B 38→50건 및 0→D 14→22건 증가. D→0은 67→66건으로 1건 개선.
- 따라서 두 번째 은닉층 추가는 핵심 오류 비증가 조건을 만족하지 못했으므로 **(256,) 단층 유지**. 표현 용량은 고정한 상태에서 L2 강도 변화가 Writer 일반화·D→0 혼동에 미치는 영향을 분리한다.

## 2. 후보와 사전 가설

| L2 alpha | 선택 이유 | 가설 |
|---|---|---|
| 1e-5 | 기본 규제 1/10 | 규제가 너무 강해서 0/D 판별 특징을 제한했는지 검증 |
| **1e-4** | 현재 기준, 기존 12개 모델 재사용 | 정확도·오분류 대조 |
| 1e-3 | 기본 규제 10배 | 가중치 규제 강화로 Writer 변동·오류 감소 가능한지 검증 |
| 1e-2 | 기본 규제 100배 | 강한 규제의 일반화 이득과 과소적합을 함께 확인 |

- 신규 실험: 3개 alpha × Seed 42/43/44 × 보류 Writer 41/42/43/44 = **36개 MLP**. 기준 alpha=1e-4 (256,)의 12개 모델은 S1 GitHub Actions **43914675988** 산출물을 중복 학습 없이 재사용.
- **고정:** Size30% / Stroke28% / CoM, 구조 (256,), ReLU+Adam, Learning Rate=0.001, max_iter=200, Early Stopping=False, 학습 이미지·증강 Seed 20261116, 데이터 SHA 및 Writer 분할.
- 보류 Writer/OfficialVal에는 증강을 적용하지 않는다. Original Test·교수님 Test·신규 손글씨 480장은 접근 금지.

## 3. 결과 확인 전에 정하는 채택·탈락 기준

1. D→0 / B→8 / 8→B / 0→D **각 방향의 실제 클래스 기준 OOF 오분류율이 각각 5% 미만**(클래스당 3 Seed 총 480회 예측 중 최대 23건)이 1차 목표다.
2. 위 목표를 모두 충족하고 전체 OOF 정확도가 기준 **92.213542% 이상**인 후보 중 정확도 최대인 조건 채택. 0.20%p 이내의 근소한 차이는 D→0 오류 최소를 우선.
3. 모든 후보가 목표 미달이라면 OOF 정확도 비하락, 네 방향 오류 비증가, 실제 0/8/B/D 클래스 전체 오류 비증가 및 과적합 가드레일을 모두 통과하는 최고 정확도 대안 채택. 그렇지 않으면 **기존 alpha=1e-4 유지**.
4. OfficialVal 하락 0.50%p 초과 금지, Writer별 OOF 하락 1.0%p 초과 금지, 16클래스 최대 Family Flip 증가 5.0%p 초과 금지. Seed 변동, Writer별 정확도, 학습 Loss curve, 반복 수, 수렴 경고, 학습 시간도 수집한다.
5. 동일 이미지에서 기존 오답 교정·새로운 오답 유발을 대응 비교하며 0/D나 8/B의 오류가 다른 클래스로 전가되지 않았는지 검사한다.
6. 같은 Writer OOF/OfficialVal에 대한 반복 탐색 역시 선택 과적합 위험이 있다. 모든 HP 동결 전 독립 Test를 사용하지 않는다.
