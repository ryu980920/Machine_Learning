## 현재 결정

- **전처리·증강 조건 동결:** Official Train Size 30% / Stroke 혼합 강도 28% / CoM. **최종 배포 MLP를 확정했다는 의미가 아님**.
- **기존 대조:** 3 Seed × 4 Writer-held-out OOF 정확도 **90.716146%**, 오분류율 **9.283854%**, OfficialVal **96.117187%**.
- **변경할 것:** MLP 은닉층 너비 → 깊이 → L2 규제(`alpha`) → 초기 학습률 → Early Stopping. **실행되지 않은 단계는 확정이라고 쓰지 않는다**.

## 최신 통과 기준 (사용자 수정)

- **D→0, B→8, 8→B, 0→D 각각 5% 미만:** 클래스당 480회 예측 기준 **23건 이하**.
- **전체 OOF 정확도 우선:** 네 방향을 모두 5% 미만으로 낮추고 OOF 정확도 90.716% 이상인 후보 중 최고 정확도를 선택한다.
- **달성 불가능하면:** OOF 정확도 비하락, 네 방향별 오류율 비증가, 0/8/B/D 전체 클래스 오류율 비증가 및 과적합 가드레일을 만족하는 모델 중 최고 정확도를 선택한다. 없으면 기존 100뉴런을 유지한다.
- **최우선 감시 방향:** D→0 기준선 71건(14.79%); B→8 54건, 8→B 43건, 0→D 19건.
- **과적합 방지:** Writer/Seed/OfficialVal/16클래스 안정성·수렴을 함께 확인하고 Original/교수님 Test는 보호한다.
- 예전 **0건 필수 조건은 폐기**했고, 수정 경위는 [EXP-CMB-008 §2-B](EXP-CMB-008_01_Plan_30_28_Frozen_HP.md)에 보존한다.
