- **전처리·증강 조건 동결:** Official Train Size 30% / Stroke 혼합 강도 28% / CoM. **최종 배포 MLP를 확정했다는 의미가 아님**.
- **기존 대조:** 3 Seed × 4 Writer-held-out OOF 정확도 **90.716146%**, 오분류율 **9.283854%**, OfficialVal **96.117187%**.
- **변경할 것:** MLP 은닉층 너비 → 깊이 → L2 규제(`alpha`) → 초기 학습률 → Early Stopping. **실행되지 않은 단계는 확정이라고 쓰지 않는다**.

## 우선 통과 Gate (사용자 요청)

- 개발용 OOF에서 **숫자 0→문자 D 0건**, **숫자 8→문자 B 0건**을 엄격한 최종 통과 조건으로 둔다. 3 Seed(실제 클래스당 160장/Seed) 모두 합산하여 판단한다.
- 동시에 OOF 정상 정확도가 높은 후보를 우선하고 D→0/B→8의 반대 오분류 증가, 특정 작성자 및 클래스 붕괴를 방지한다.
- 0건이 아니면 **잠정 설정**일 수는 있어도 최종 통과라고 기록하지 않는다. [수정된 사전등록 통과 규칙](EXP-CMB-008_01_Plan_30_28_Frozen_HP.md#2-a-사용자-통과-기준-추가-사전등록--특정-오류-0건-우선-s1-실험-이전)을 적용한다.
