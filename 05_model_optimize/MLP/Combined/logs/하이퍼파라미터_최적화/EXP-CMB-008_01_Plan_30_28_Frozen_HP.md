# EXP-CMB-008 · 01 사전등록 — Size30/Stroke28 고정 MLP 하이퍼파라미터 최적화

> **상태: 실험 설계 및 선정 조합 확정 / 신규 HP 학습·검증 미실행.** 이 문서는 결과를 보기 전에 비교 순서, 선택 근거, 검증 규칙을 고정하는 기록이다. 실험 후 관측 수치는 후속 문서에 기재하며, 이 파일의 사전 규칙을 결과에 맞춰 소급 변경하지 않는다.
>
> 이 실험의 **선정**은 다음 연구의 학습 증강 조건 확정이며, 최종 배포 모델의 학습 또는 미사용 Test 성능 확정이 아니다.

## 0. 선행 근거와 고정할 조건

- [CMB-007의 31조건 검증](../가설B/EXP-CMB-007_03_Final_Size60_100.md) 및 [상위 3개 오분류율 재검증](../가설B/EXP-CMB-007_04_Review_Top3_OOF_Error.md)에서 **Size30%-Stroke28%**가 Hand-made 4-Writer OOF Accuracy **90.716146%**, Error **9.283854%**, OfficialVal Accuracy **96.117187%**였다.
- 30%-14%는 OOF **90.690104%**, 30%-0%는 OOF **90.572917%**. 세 후보의 차이가 작으며, B/D 개별 클래스나 안정성은 30%-28%가 일관되게 최고가 아니었다. **선정 이유는 이번 프로젝트에서 OOF 정상 인식률을 우선하는 후속 개발 의사결정**이며 모든 클래스에 대한 절대적 우위 입증이 아니다.
- **고정 Train 증강:** Official Train 76,800장 중 약 **30%**에 클래스 균형 Size(목표 BBox long-side 16/18/20/22/24px) 및 **Stroke 혼합 강도 28%**를 적용하여 이미지 **1:1 대체**. 기존 `nested_subset`/증강 시드 **20261116**, 픽셀 처리 및 거부 규칙을 동일하게 보존한다. Size 30%는 **입력 이미지를 30% 축소하라는 의미가 아님**.
- **고정 CoM:** 증강된 Official Train, 다른 작성자의 Hand-made 학습 이미지, 보류 Writer, OfficialVal의 중심 정렬은 기존 `process(...,"com",20)` 로직을 그대로 사용한다. 보류 Writer/OfficialVal에 Size·Stroke **훈련 증강을 적용하지 않는다**. 별도 ×0.8/×1.2 입력은 안정성 *진단*에만 사용한다.
- **고정 데이터:** 각 Fold는 Official Train 76,800 + Hand-made 학습 Writer 3명 1,920 = 78,720장을 학습; 나머지 Writer 640장 보류; Writer 41/42/43/44 모두 보류한 Seed당 OOF 2,560장; OfficialVal 19,200장. 학습 Seed **42/43/44**, 보류 Writer 4-Fold, 같은 Train/Val 원본 SHA 사용.
- **기준 MLP:** `Pipeline(PixelScaler255(), MLPClassifier(random_state=seed))` = `hidden_layer_sizes=(100,)`, `activation='relu'`, `solver='adam'`, `alpha=0.0001`, `learning_rate_init=0.001`, `max_iter=200`, `early_stopping=False`. 실제 구현 전 sklearn 버전/기본값을 manifest로 검증한다.
- **수정 금지:** Original Test, 교수님 Test, Normal 신규 손글씨 480장, 최종 모델 경로, 기존 CMB-001~007 CSV·체크포인트. Normal EXP유017의 HP 선정값은 구조 선택의 *참고*일 뿐 서로 다른 데이터/증강의 실측을 Combined 결과로 옮기지 않는다.

## 1. 연구의 논리적 질문

**왜 하이퍼파라미터를 바꾸는가?** 크기·획 분포 변화를 고정한 뒤 남은 OOF **9.284% 오분류율**이 MLP의 표현 용량, L2 규제, 최적화 속도, 종료 시점에 얼마나 반응하는지를 한 단계씩 분리하여 검증한다.

**실험 원칙:** 한 단계의 승자(또는 승자 없음)를 **평가표와 근거로 확정**한 후 다음 변수를 연다. 후속 단계는 이전에 채택한 설정을 고정하므로, 어떤 변화가 어떤 영향을 냈는지 추적 가능하다. 실험 결과가 예상과 다르면 해당 가설을 기각하거나 보류하고 이전 설정으로 돌아간다.

## 2-A. 사용자 통과 기준 추가 사전등록 — 특정 오류 0건 우선 (S1 실험 이전)

> **이 절은 기존 §3의 일반 정확도 우선 선정 규칙보다 우선 적용한다.** 사용자 요청에 따라 **전체 정확도가 높으면서 0→D·8→B 같은 주요 오분류가 발생하지 않는 모델**을 최종 통과 기준으로 정했다. 기준을 변경한 시점은 EXP-CMB-008 S1 신규 학습 이전이며, 이전 CMB-005~007 결과를 바꾸지 않는다.

1. **최종 통과 필수 조건:** 동일 조건의 **Seed 42/43/44 각각에 대해 Writer 41~44 보류 OOF를 결합**했을 때, 실제 숫자 `0→D`, 실제 숫자 `8→B`의 합계 오류가 **모두 0건**이어야 한다. 클래스당 160장/Seed = **480회 클래스 노출/3Seed**를 기준으로 하며, 기존 작성자를 반복 사용하므로 독립적인 오류확률 0의 보증이 아님. 0건은 관측된 개발집합 안에서만 의미가 있다.
2. **다른 오분류 이동 방지:** `D→0`, `B→8`는 **30/28 기본모델보다 증가하면 불합격**. `5→F`, `7→9`, `7→A`, `4→F`도 상세 보고하여 단순히 0→D·8→B를 다른 오답으로 옮긴 모델을 가리지 않도록 한다.
3. **기존 안전 가드레일 유지:** OfficialVal −0.5%p 초과 하락 금지; Writer 한 명 −1.0%p 초과 악화 금지; 정상 입력 8/B/D 전체 오분류율 +3.0%p 초과 악화 금지; 16클래스 평균 최대 Family Flip +5.0%p 초과 악화 금지.
4. **최종 합격 모델이 여러 개면:** 모든 필수 Gate 통과 후보 중 **Hand-made 4-Writer OOF Accuracy가 가장 높은 설정**을 우선 선택하고, OOF 동률권(0.20%p 이내)에서는 Seed 변동과 OfficialVal·복잡도를 함께 비교한다. 특정 오류 0건을 만족하지 않는 고정 모델은 **최종 합격이라고 부르지 않는다**.
5. **S1~S5 중간 결정을 위한 잠정 규칙:** 아직 0건 모델이 없더라도 다음 단계 탐색이 중단되지 않도록, 기존 모델에서 **0→D·8→B 각각 오류 건수를 늘리지 않고**, 일반 가드레일을 통과하며, OOF 정확도가 기준선 대비 0.20%p보다 크게 낮지 않은 후보 중 OOF Accuracy 1위(동점 시 두 오류 합 적은 조건)를 **잠정 설정**으로 삼는다. 없으면 직전 설정을 유지. 잠정은 최종 통과가 아니며, 각 단계에서 0건 달성 여부를 새로 검증한다.
6. **기준선 직접 관측값:** CMB-005 30%-28%의 Seed 42/43/44 OOF에서 0→D 약 **6.33건/Seed**, 8→B 약 **14.33건/Seed**(실제 클래스 160장/Seed). **목표 0건은 아직 달성하지 못했다.** S1에서 원본 CSV로 재검증한다.
7. **보고 형식:** 매 단계 `실제→예측`의 **오류 건수와 실제 클래스 기준 오분류율**, 전체 OOF 정확도, OfficialVal, Writer·Seed별 결과, 다른 클래스 악화, Gate 실패 원인, 잠정 설정·최종 통과 여부를 명확하게 구분한다.

## 3. 모든 단계에 동일하게 적용할 평가 및 채택 규칙

1. **정상 입력 핵심:** Seed 평균 4-Writer OOF Accuracy, OOF Macro-F1, Writer별 4개 Accuracy 및 최악 Writer, Seed 간 표준편차, OfficialVal Accuracy.
2. **오류 구조:** 전체 16클래스별 Error Rate(특히 숫자 8, 문자 B·D), 방향별 `8→B`, `B→8`, `0→D`, `D→0`, 숫자/문자 Family Flip(×0.8/×1.2, OOF 및 OfficialVal), 가능하면 이미지 키 동일 비교의 corrected/induced 건수.
3. **수렴/비용:** Fit 시간, Loss, 반복 횟수, 경고 발생 여부. 불수렴 후보는 '정확도만'으로 채택하지 않고 재현성 문제를 별도 표시한다.
4. **가드레일(이번 개발 연구의 운영 기준; 통계적 보증 아님):** 기준 30/28 대비 OfficialVal Accuracy 악화 **0.50%p 초과 금지**, Writer 하나에서 OOF Accuracy 악화 **1.0%p 초과 금지**, 정상 입력 8/B/D의 각 오류율 악화 **3.0%p 초과 금지**, 두 데이터 출처의 16클래스 평균 최악 Family Flip 증가 **5.0%p 초과 금지**. 기준선은 과거 원본 3Seed 4Fold의 같은 정의로 계산하고, 모든 비교는 동일 이미지·Seed·Writer로 수행한다.
5. **고정 순서:** (a) 가드레일 전부 통과 → (b) Seed 평균 OOF Accuracy 최대 → (c) OOF 차이가 **0.20%p 이내**면 Seed 편차가 작은 모델 → (d) 그마저 근소하면 OfficialVal 정상 정확도 → (e) 여전히 비슷하면 파라미터 수·학습시간이 적은 모델. **높은 정확도여도 가드레일 미통과라면 선정하지 않는다.**
6. 새 후보 중 기준 대비 **유의미한 우위가 확인되지 않거나 가드레일 통과 후보가 없으면 해당 단계 변수는 기본값/직전 고정값을 유지**하고 이유를 명시한다. 0.20%p 구분은 실무적 동률 허용 폭이며 통계적 유의성 기준이 아니다. Writer 4명을 반복 탐색했으므로 OOF도 **새 작성자에 대한 독립 평가가 아님**을 모든 결론에 표시한다.
7. **결정은 결과가 나온 단계부터 기록.** 실제 학습이 없는 상태에서 'S1 너비 확정' 등으로 미리 적지 않는다. 예정 후보·관측 수치·채택 이유를 별도 열로 둔다.
