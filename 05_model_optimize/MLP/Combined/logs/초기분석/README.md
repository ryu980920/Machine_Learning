# Combined 초기분석 — EXP-CMB-002~003

[전체 연구 흐름](../README.md)으로 돌아가기

두 실험 모두 **새로운 최종 모델을 채택하기 위한 실험이 아니라**, CMB-001의 오분류를 분석하고 후속 정규화·증강 실험의 근거를 확보하기 위한 단계다.

| 순서 | 실험 | 검증 질문 | 결론 |
|---|---|---|---|
| CMB-002 | [Error Analysis](EXP-CMB-002_Error_Analysis.md) | 0↔D, 8↔B 오류가 어느 작성자·형태·공간 조건에서 집중되는가? | 가설 B(공간·중심·크기) 우선, 가설 A(획 형태·연결성) 조건부 보류 |
| CMB-003 | [Input Sensitivity](EXP-CMB-003_Input_Sensitivity.md) | 모델을 재학습하지 않고 입력만 변형할 때 어떤 오답이 교정되고 신규 오답이 생기는가? | 95% 축소의 개선은 작성자 편중. 획 얇게25%를 재학습 검토 후보로 구분 |

**연결:** [CMB-001 Baseline](../EXP-CMB-001_Baseline_4Writer_OOF.md) → CMB-002 → CMB-003 → [가설 B의 CMB-004~007](../가설B/README.md).

표의 진단 결과는 서로 다른 실험 조건의 성능 수치를 혼용하지 않고 원본 로그에서 확인한다.
