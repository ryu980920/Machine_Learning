# EXP-CMB-010 · 01 — 신규 손글씨 480장 품질 검사 및 Combined Training 편입 계획

> **2026-11-18 / Training 편입용 실험 브랜치 / 기존 배포 모델 불변.**
>
> 연구 질문: **전처리를 더 늘리는 대신, 오분류가 집중된 7/9와 B/8의 실제 손글씨 480장을 학습에 추가하면 4 Writer OOF와 OfficialVal이 개선되는가?**

## 1. 직접 확인한 입력 파일

- 사용자 제공: `handwritten_7_8_9_B_28x28_grayscale(1).npz`; 원본 크기 111,287 bytes, SHA-256 `3d1686c67d7bb5c6193384eca1aa9218213c842252baa5b7e172698743b83fc7`.
- NPZ 필드: `X` (480,784) `uint8`, `images` (480,28,28), `y`와 `labels` (480,), `label_text`, `class_names`, `available_classes`, `source_image`, `cell_row_col`, `pixel_range`.
- 클래스별: 7 **160장**, 9 **160장**, 8 **80장**, B(11) **80장**. 0/D는 자료에 없음. `X`와 `images`, `y`와 `labels`, 정수↔문자 레이블은 **전부 일치**.
- 픽셀 범위 0–206, 빈 이미지 0, `threshold=32` 기준 전경 적어도 23px, 경계 접촉/잘림 **0장**, 완전히 동일한 이미지 **0쌍**.
- 같은 클래스끼리 픽셀 코사인 유사도 0.99 이상인 쌍 **0**, 7과 9의 가장 높은 코사인 유사도 **0.9263** (인덱스 8·354). 유사도는 정답의 증거나 레이블 오류 판정이 아님.
- 이전 개발용 438장 `EXP018_user_screened_438.npz`와 **완전 중복 0**, 가장 높은 코사인 유사도 약 **0.87197**. 두 데이터를 하나로 합치지 않음.

## 2. 실제 이미지 육안 점검 및 유보 사항

모든 클래스의 480장 인덱스가 표시된 접촉시트를 확인했다. 7은 상단이 둥글게 말리고 아래쪽 획이 곧게 내려오는, 기존 모델이 9와 혼동하는 형태가 다수 포함돼 있다. **수집자가 7로 레이블한 사실만으로 잘못된 정답이라고 단정하지 않으며**, 원본 이미지를 변형하거나 임의 배제하지 않았다. 일부 이미지에 대해 향후 수집자의 레이블 재확인이 유익하나, 현재 구조적 품질 기준을 위반한 이미지는 없다.

**미확인 핵심 메타데이터:** 작성자 ID. `source_image = 7 / 9 / B8`는 원본 시트 명칭이어서 서로 다른 작성자라는 근거가 아니다. 누출 방지를 위해 전체 신규 데이터 **480장을 단일 신규 코호트로 관리**한다. 작성자가 기존 41~44 중 한 사람일 가능성까지 완전히 배제할 수 없으므로 기존 작성자 OOF도 엄밀한 독립 새 작성자 검증으로 보고하지 않는다.

## 3. 정확히 바꿀 학습 조건

| 항목 | 기준선 A | 실험 B — 480장 추가 |
|---|---|---|
| 공식 Train | 76,800 | 76,800 |
| 기존 다른 3 Writer 손글씨 | 1,920 | 1,920 |
| 이번 신규 7/8/9/B | **0** | **480** |
| 각 Fold Training 총량 | **78,720** | **79,200** |
| 보류 기존 Writer | 640장 평가 전용 | 동일 640장 평가 전용 |
| OfficialVal | 19,200장 평가 전용 | 동일 평가 전용 |
| 추가 480장 전처리 | 해당 없음 | **CoM-only** (공식 Train 30% Size/Stroke 대체 규칙을 새 손글씨에 적용하지 않음) |
| HP | MLP (256,), ReLU, Adam, alpha=1e-4, LR=.001, ES=False, Batch=128, max_iter=200 | 동일 |

- Seed 42/43/44 × 보류 Writer 41/42/43/44 × 두 조건 = **24개 독립 모델 학습**.
- 오차 비교: 전체 Writer OOF Accuracy·Macro F1, OfficialVal Accuracy·Macro F1, 16개 클래스별 오답·정답, 7↔9, B↔8, 0↔D, 작성자별 차이, 기존 정답→오답·오답→정답.
- 학습 데이터 변화 이외 **모든 모델/전처리 설정 고정**. 새 480장만으로 성능이 개선되었는지 대조.
- 개발용 판단 기준: Writer OOF **비하락**, OfficialVal 하락 **0.3%p 이내**, 7→9 **감소**, 9→7·B→8·8→B·0↔D **비증가**. 모두 충족하지 않으면 *개발 후보*로만 기록하고 배포하지 않는다.

## 4. 데이터·배포 경계

- 신규 데이터는 사용자 요청에 따라 실험 브랜치에 **Training 후보**로 등록한다. 이미 검토한 438장(기존 모델 개발용)은 이번 학습·평가에서 사용하지 않는다.
- 기존 41~44 보류 분할과 Original/교수님 Test 자료는 변경하지 않는다. 새 480장을 어떤 독립 Test에도 넣지 않는다.
- 실제 작성자 중복 여부가 확인되지 않았으므로 해당 위험을 기록한다. **최종 모델 교체 및 main 병합은 별도 성능 확인과 사용자 승인 전까지 하지 않는다.**
