# EXP-CMB-011 · 03 — 별도 손글씨 438장 실측과 최종 기존 Combined 유지 결정

> **평가 완료 (2026-11-19):** CMB011에서 학습된 **84개 저장 가중치**(7조건 × Seed 3 × 보류 Writer 4)를 사용자 판정 438장에 직접 평가했다. 기존 Combined와 신규 손글씨 보강의 장단점을 비교하고, **최종 모델 구성은 `base`로 확정**했다. 이 문서의 438장 결과는 **반복 개발용 진단 결과**이지 독립 Test가 아니다.

## 1. 동일 원본·평가 프로토콜

- 원본: 사용자 검수 후 **438장**. 처음 480장 가운데 판독/품질 관련 **42장 제외**.
- NPZ: `EXP018_user_screened_438.npz`, SHA-256 `a4a1be864abea59793d534f9f94fbf56795e48bcc7693c40ace60a1967baca51`. 입력 `X` (438,28,28) Grayscale `uint8` 및 `y` (16클래스)만 사용; `X_gray`/`X_binary` 미사용.
- 전처리: GitHub 원본 **CoM** `threshold=32`, 중심 `(13.5,13.5)`, 정수 이동·zero padding·무순환, 이후 저장 Pipeline의 `PixelScaler255`.
- CMB011 Actions [#44345990347](https://github.com/ryu980920/Machine_Learning/actions/runs/44345990347)의 **84개** `candidate_model.joblib`을 **추가 학습 없이 평가**. Manifest 입력 원본 해시·저장된 모델 SHA-256 대조 완료.
- 조건별 **12모델 × 동일 438장 = 5,256회 예측**; **독립 5,256장의 성능으로 취급하지 않음**.
- Original Test·교수님 Test는 사용하지 않음. 이 438장은 이전 오류 분석/Batch Size 선택에 이미 참고한 **개발용 데이터**.

| CMB011 조건 | Training 구성 | Accuracy | Macro Precision | Macro Recall | Macro F1 | 기존 대비 정확도 |
|---|---|---:|---:|---:|---:|---:|

| add480 | 기존 + 신규 전체 480장 | **87.9376%** | **0.89077** | **0.87550** | **0.87601** | +0.2093%p |
| dup79 | 기존 공식 7·9를 320장 재삽입 | 87.1956% | 0.88391 | 0.86666 | 0.86550 | −0.5327%p |

**438장 최고 점수는 `add480`지만 기존 대비 +0.2093%p에 그친다.** 이는 *12개 모델에 대한 평균*이며 각각 다른 학습 Fold 가중치를 사용한 결과다. `dup*`는 학습에 이미 있던 공식 이미지를 추가로 반복한 대조이며 신규 고유 이미지는 아니다.

## 3. 주요 클래스·혼동 방향의 상충

**기준선 → add480, 클래스별 Recall:**

| 클래스 | 기존 | add480 | 변화 |
|---|---:|---:|---:|
| **7** | 47.73% | **59.47%** | +11.74%p |
| **B** | **75.96%** | 74.04% | −1.92%p |
| **D** | **93.83%** | 91.98% | −1.85%p |
| **A** | **81.55%** | 79.46% | −2.08%p |
| **4** | **86.21%** | 83.62% | −2.59%p |
| **9** | 100.00% | 100.00% | 동률 |

**모델 1개당 평균 오분류 건수** (`base → add480`): `7→9 8.50 → 7.08`, `9→7 0 → 0`, `B→8 5.25 → 5.50`, `0→D 4.17 → 3.58`, `D→0 0.67 → 0.58`.

12모델 대응 비교에서 기존 오답 **146회 교정**, 신규 오답 **135회**, 순정답 **+11회**. 438개 이미지 단위 3,000회 Bootstrap의 정확도 변화 95% 구간 **−0.609 ~ +1.084%p**는 0을 포함한다. 이는 별도 작성자까지 독립인 효과 추정이 아니다. 이 세트에는 `9→7` 오류가 전혀 없으므로 다른 작성자에서의 `9→7` 안전성을 보증할 수 없다.

## 4. 기존 작성자 보류 평가와 상충 결과

| 조건 | CMB011 Writer OOF Accuracy | 별도 개발 438장 Accuracy |
|---|---:|---:|
| **base** | **92.3568%** | 87.7283% |
| add79 | 92.2135% | 87.9186% |
| addB8 | 92.3307% | 87.5951% |
| add480 | 92.3307% | 87.9376% |

- 신규 7·9만 추가한 경우 438장에서는 개선(+0.1903%p)이지만 **Writer OOF는 −0.1432%p**. Writer OOF에서는 `7→9`가 **22→29건**으로 악화했다.
- B·8만 추가한 경우 `B↔8` Writer OOF 양방향 오류가 감소했으나 전체 Writer OOF는 −0.0260%p였다.
- 전체 480장은 438장에서 +0.2093%p지만 **Writer OOF −0.0260%p**이고, `9→7`·`0→D` 등 다른 오류의 부작용이 남아 있다.
- 438장은 이전에 재사용한 개발용 자료이며 신규 480장의 **작성자 ID도 미확인**이다. 따라서 이번 438장에서의 작은 이득을 독립 일반화 성능 개선으로 확정할 수 없다.

## 5. 최종 결정

**기존 Combined `base` 구성을 최종 선택하고 동결한다.**

이는 '438장 정확도 1위 모델'을 선택한 것이 아니라 **기존 Writer OOF, OfficialVal, 438장 진단 및 클래스별 악화·개선의 일관성을 종합한 선택**이다. 추가 데이터가 정확도에 유리했던 경우까지 결과를 숨기지 않되, 현재는 기존 구성을 바꾸기 위한 충분한 근거가 없었다.

- 최종 고정 조건: **MLP (256,), alpha=1e-4, LR=0.001, Batch=128, Early Stopping=False, 공식 Training Size30%-Stroke28%-CoM, 기존 손글씨 Writer-held-out 학습**.
- 신규 7/9/8/B 480장: 원본·실험 기록 보존, **최종 학습에서 제외**.
- CV 12개 체크포인트와 모델 설정·입력 전처리 동결을 구분. **4명 전체 손글씨를 학습한 단일 추론 모델 가중치가 새로 생성된 것은 아니다.**
- 최종 Test 미사용·후속 가중치 변경 미실시. 선정 근거: [최종 동결 로그](../EXP-CMB-012_Final_Combined_Model_Freeze_20261119.md) / [JSON Manifest](../../results/Final_Model/FINAL_COMBINED_FREEZE.json).
