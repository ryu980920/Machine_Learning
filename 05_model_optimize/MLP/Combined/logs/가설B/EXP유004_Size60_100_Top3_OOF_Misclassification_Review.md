# EXP-CMB-007 후속 검토 — 31조건 OOF 상위 3개와 오분류율

> **상태**: 기존 31조건 원본 CSV 재검증 결과만 기록. 재학습 없음, 신규 Test 사용 없음, 최종 모델 채택 보류. 이 문서는 **OOF 정확도 순위**를 정리한 것이며 안정성/일반화에 관한 최종 선정 순위가 아니다.

## 1. 원본과 산정 방식

- 원본: [31조건 종합 CSV](../../results/Balanced_Scale_Stroke_HighFraction/full_0to100_comparison/all_31_preprocessing_conditions.csv), [16클래스 정상 입력 오분류율](../../results/Balanced_Scale_Stroke_HighFraction/full_0to100_comparison/all_16_class_error_rates_across_31_conditions.csv), [240개 방향별 오분류율](../../results/Balanced_Scale_Stroke_HighFraction/full_0to100_comparison/all_240_directed_errors_across_31_conditions.csv).
- 정렬 기준: Hand-made **Writer-held-out OOF mean_accuracy** 내림차순; 동일 기본 MLP HP, Seed 42/43/44, Writer 41/42/43/44. Seed당 OOF 2,560장, 클래스당 160장.
- **오분류율(Error Rate) = 1 − Accuracy.** 이는 모델의 `predict_proba`가 출력한 클래스별 '예측 확률'과 다른 실측 **잘못 분류한 비율**이다.
- OfficialVal 수치는 독립 Test가 아니라 기존 탐색에 반복 활용된 Validation 성능이다.

## 2. 전체 31조건 중 OOF 정확도 상위 3개

| 순위 | Size / Stroke | OOF 정확도 | OOF 오분류율 | OfficialVal 정확도 | OfficialVal 오분류율 |
|---:|---|---:|---:|---:|---:|
| 1 | **30% / 28%** | **90.716146%** | **9.283854%** | 96.117187% | 3.882813% |
| 2 | **30% / 14%** | 90.690104% | 9.309896% | 96.134115% | 3.865885% |
| 3 | **30% / 0%** | 90.572917% | 9.427083% | **96.180990%** | **3.819010%** |

- 모두 Size 30%이며, 1위와 2위 OOF 오분류율 차이는 **0.026042%p**. 3-Seed 관측상의 순위가 독립 신규 작성자에 대한 통계적 우월성을 의미하지는 않는다.
- OfficialVal 오분류율은 세 조건 가운데 30%-0%가 가장 낮다. 즉 OOF 순위와 OfficialVal 순위는 일치하지 않는다.

## 3. OOF 클래스별 오분류율 — 8/B/D

| 실제 클래스 | 30%-28% | 30%-14% | 30%-0% |
|---|---:|---:|---:|
| 숫자 8 | **13.7500%** | **13.7500%** | 14.1667% |
| 문자 B | 17.9167% | 17.2917% | **17.0833%** |
| 문자 D | 17.7083% | 17.9167% | **17.5000%** |

- 위 값은 각 클래스의 오답 수 / 해당 클래스 160장/Seed로 계산한 3-Seed 평균이며, 방향별 혼동과 구분한다.

## 4. OOF 오분류 방향 — 8↔B, 0↔D

| 실제 → 예측 | 30%-28% | 30%-14% | 30%-0% |
|---|---:|---:|---:|
| 8 → B | 8.9583% | 8.9583% | 10.2083% |
| B → 8 | 11.2500% | **10.4167%** | **10.4167%** |
| 0 → D | 3.9583% | **2.0833%** | 5.2083% |
| D → 0 | **14.7917%** | 15.4167% | 15.4167% |

모든 방향별 오분류율의 분모는 '실제' 클래스의 OOF 이미지 수이며, 예측된 클래스의 이미지 수가 아니다. 30%-28%는 전체 OOF 우위와 D→0 오류 감소가 관찰되지만, B→8 오류는 다른 상위 조건보다 높다.

## 5. 이전 후속 분석 — 크기 변화와 계열 확률

31조건 최종 보고서 이후 원본 `per_class_and_scale.csv` 12개 조합(4개 조건 × 3개 Seeds, 각 Seed 4 Writer Fold)을 직접 합산한 **진단용 평균 확률**. P(letter)는 A~F 클래스 확률 합. 오분류율과 혼동하지 않는다.

| 조건 | OfficialVal B: 원본 → ×1.2 P(letter) | OfficialVal D: 원본 → ×1.2 P(letter) | OOF 8: 원본 → ×0.8 P(letter) |
|---|---|---|---|
| 30%-28% | 96.81% → 85.00% | 96.45% → 80.00% | 10.17% → 30.33% |
| 50%-0% | 96.02% → 93.81% | 95.36% → 85.49% | 10.22% → 28.48% |
| 80%-0% | 93.57% → 80.12% | 93.41% → 74.72% | 14.81% → 28.92% |
| 100%-0% | **89.54% → 44.44%** | **89.24% → 43.45%** | 14.01% → 26.70% |

이 값은 클래스 평균 확률이므로 개별 이미지가 B→8, D→0 또는 8→B로 전환했다는 직접 증명이 아니다. 이미지별 부호/양방향 전환을 판단하려면 보관된 모델 체크포인트로 동일 이미지에 크기 변환을 적용하고 `P(y)`, `P(letter)`, 대립 클래스 마진, 예측 클래스를 대응 추출해야 한다.

## 6. 결론 및 배포 범위

1. **OOF 정확도 상위 3개**는 30%-28%, 30%-14%, 30%-0%이고 각각 **OOF 오분류율 9.284%, 9.310%, 9.427%**이다.
2. 상위 3개의 정상 입력 B/D 위험은 30%-0%가 다소 낮다. 따라서 30%-28%를 모든 클래스에서 우위인 모델로 서술하지 않는다.
3. Family Flip / 클래스별 안정성 균형 후보인 50%-0%와 OOF 정확도 상위 3개를 혼동하지 않는다.
4. **Original Test / 교수님 Test / 신규 손글씨 480장 미사용**. 선택 편향을 고려하여 최종 채택은 보류.
5. 이번 기록은 **PR #19 실험 브랜치에만 게시**하고, 별도 승인 전 `main` 병합 및 체크포인트 교체는 하지 않는다.
