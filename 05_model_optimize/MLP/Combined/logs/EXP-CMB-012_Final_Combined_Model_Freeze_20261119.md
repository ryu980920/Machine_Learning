# EXP-CMB-012 — 최종 Combined MLP 선정·설정 동결 (2026-11-19)

> **최종 결정: 신규 480장 추가 이전의 기존 Combined MLP (`CMB011/base`)를 최종 모델 구성으로 확정한다.** 7·9 320장, B·8 160장, 전체 480장 추가 및 공식 Train 이미지 재삽입 조건은 최종 학습 구성에 포함하지 않는다. 기존 실험 데이터·원본·가중치를 삭제하거나 과거 판단을 소급 수정하지 않는다.
>
> **확정 범위:** 아키텍처·하이퍼파라미터·학습/추론 전처리·기존 Hand-made 학습 데이터 구성 및 작성자 보류 평가 프로토콜. **CV 12개 체크포인트는 실험 재현 근거**이며, 4명 전체를 학습한 단일 최종 추론 체크포인트를 이번 작업에서 새로 학습·교체했다고 주장하지 않는다.

## 1. 선정 이유와 판단 기준

- 목표는 OfficialVal, 작성자 보류 Writer OOF, 사용자가 추가 제작한 438장, 주요 혼동쌍(7↔9, B↔8, 0↔D)에서 **서로 상충하는 성능을 함께 검토**하고, 새 데이터를 투입한 대안이 기존 구성의 일반화를 확실하게 개선하는지 확인하는 것이다.
- CMB008 S6 기존 사전등록 실험에서 Batch 128이 정확도는 높았으나 B→8·0→D 안전 조건에 실패하여 당시 Batch 200을 유지한 **역사적 판정은 보존**한다. 이후 별도 438장·Writer OOF에서 Batch 128을 **정확도 중심 개발용 우선 후보**로 올린 후, CMB009 및 CMB010·011을 **Batch 128 고정 조건**으로 수행했다. 이번 최종 선정은 사용자의 후속 의사결정이며 S6 가드레일을 통과했다고 소급 주장하지 않는다.
- CMB009 추가 전처리 72개 모델에서는 채택 기준을 통과한 Local Warp/Rotation/Shear 조합이 없었다.
- CMB010에서 전체 480장 추가는 Writer OOF Accuracy **92.4089% → 92.2917%**, Macro F1 **0.924018 → 0.923033**, OfficialVal **97.0972% → 97.0677%**로 하락했다.
- CMB011에서 동일 설정으로 클래스별 추가 효과를 분리해 총 **84개 모델(7개 학습 조건 × 3 Seed × 4 Writer)**을 학습했다. 기준선과 모든 추가 조건을 **같은 실행 안에서** 비교하고, 기존 예제를 같은 수량 재삽입한 대조도 수행했다.
- 별도 438장에서는 신규 480장 추가 모델이 약간 높은 점수를 보였으나, **반복 활용한 개발용 자료**이고 이미지 단위 Bootstrap 95% 구간에 0이 포함됐다. 전체 16클래스에서 뚜렷하고 일관된 우위를 입증하지 못했으므로 최종 구성으로 교체하지 않는다.

## 2. 최종 고정 모델 및 데이터

| 항목 | 확정 값 |
|---|---|
| 구분 | **Combined MLP — 기존 기준선 (`CMB011/base`)** |
| 분류 | 숫자 0–9·문자 A–F, 총 16클래스 |
| 모델 | `sklearn.neural_network.MLPClassifier` |
| 은닉층 | **`(256,)`** (1개 은닉층) |
| Activation / Solver | `relu` / `adam` |
| L2 alpha | `0.0001` |
| learning_rate_init | `0.001` |
| Batch Size | **128** |
| Early Stopping | **False** |
| max_iter / tol / n_iter_no_change | `200` / `0.0001` / `10` |
| 학습 공식 데이터 | **76,800장**; OfficialTrain의 30%를 클래스 균형 Size/Stroke 강도 28% 변형으로 대체, 그 후 CoM |
| 기존 손글씨 학습 | **Writer-held-out Fold당 다른 3명 × 640 = 1,920장**, CoM-only |
| Fold별 전체 학습 수 | **78,720장** |
| Writer 보류 평가 | 41·42·43·44 각각 640장, 해당 Fold 학습에서 제외 |
| 공식 Validation | **19,200장**, 평가 전용 |
| 입력 추론 | **CoM(threshold=32, 중심=(13.5,13.5), 정수 이동, zero-padding, 무순환) → PixelScaler255(/255) → MLP** |
| 반복/재현 | Seed 42·43·44 × 보류 Writer 41·42·43·44 = 12개 CV 학습·평가 |
| **최종 추가 학습 데이터** | **신규 7/9/8/B 480장: 0장 (미채택)** |
| 독립 Test | Original Test·교수님 Test **미사용** |

※ ‘Size30%’는 입력 이미지 전체를 30% 축소한다는 뜻이 아니라 **공식 Train의 30%를 학습용 크기 변형으로 대체하는 증강 비율**이다. ‘Stroke28%’는 학습용 획 변형 강도이며 **최종 추론에는 Size/Stroke 증강을 적용하지 않는다**.

**자료 경계:** 사용자 신규 480장 NPZ는 실험 원본으로 GitHub에 보존하되, 이를 `base`의 Training에 자동 합산하지 않는다. 사용자가 따로 품질 판정한 438장은 어떤 CMB011 학습 조건에서도 사용하지 않았다.

## 3. Writer OOF / OfficialVal — CMB011 동일 실행

| 학습 조건 | Writer OOF Accuracy | Writer OOF Macro F1 | OfficialVal Accuracy | 결정 |
|---|---:|---:|---:|---|
| **기존 Combined** | **92.3568%** | **0.923571** | 97.0781% | **최종 유지** |
| 신규 7·9 320장 | 92.2135% | 0.922364 | 97.0543% | 미채택 |
| 신규 B·8 160장 | 92.3307% | 0.923392 | **97.1445%** | 미채택 |
| 신규 전체 480장 | 92.3307% | 0.923488 | 97.1085% | 미채택 |

Writer OOF는 기존 이미지 2,560장을 Seed 3개에서 반복 평가한 7,680회 예측이다. 7,680장의 독립 이미지가 아니다. 이번 재실행과 CMB010의 OOF는 서로 수치가 완전히 일치하지 않으므로 **실행이 다른 절대값을 섞어 차이로 해석하지 않는다**. 후보 간 상대 비교는 CMB011 동일 실행을 기준으로 한다.

## 4. 별도 사용자 판정 438장 — CMB011 저장 모델 84개 실제 평가

동일한 438장에 조건별 **12개 저장 모델**을 적용했다. 각 지표는 모델별 점수 평균이며, 독립 테스트가 아닌 개발용 외부 손글씨이다.

| 학습 조건 | Accuracy | Macro Precision | Macro Recall | Macro F1 | 기준선 대비 |
|---|---:|---:|---:|---:|---:|
| **기존 Combined** | 87.7283% | 0.88592 | 0.87186 | 0.87083 | 기준 |
| 신규 7·9 320장 | 87.9186% | 0.89084 | 0.87528 | 0.87586 | +0.1903%p |
| 신규 B·8 160장 | 87.5951% | 0.88608 | 0.87067 | 0.87004 | −0.1332%p |
| 신규 전체 480장 | **87.9376%** | **0.89077** | **0.87550** | **0.87601** | **+0.2093%p** |

전체 480장 추가 모델은 438장의 실제 7 Recall을 **47.73%→59.47%**로 개선했으나, B **75.96%→74.04%**, D **93.83%→91.98%**, A **81.55%→79.46%** 등이 낮아졌다. 기준선 대비 교정 **146회 / 신규 오류 135회** (12개 모델의 반복 예측 합산), 정답 순증가는 11회다. 이 차이의 **438장 이미지 단위 Bootstrap 95% 구간 −0.609~+1.084%p**에는 0이 포함된다.

또한 신규 480장 작성자 ID가 없어 기존 Writer 41~44와 동일인이 포함됐는지 확인할 수 없다. **438장의 소폭 우세가 독립 작성자에 대한 성능 우세를 확증하지는 않는다.**

기존 Combined를 최종 유지하는 이유는 단순히 ‘438장에서 가장 높기 때문’이 아니라, **Writer OOF에서 추가 학습의 우위가 확인되지 않았고 438장 차이도 작고 불확실하며, 다른 클래스의 악화가 동반됐기 때문**이다.

## 5. 모델 확정 범위와 재현성

1. **선정·동결 완료:** 기존 Combined의 모델 종류, 전처리, Seed·Writer OOF 평가 규칙, 최종 추가 학습 데이터 **0장**, 하이퍼파라미터.
2. **보존된 CV 가중치:** CMB011의 `base` 12개 Fold별 `candidate_model.joblib`은 [GitHub Actions #44345990347](https://github.com/ryu980920/Machine_Learning/actions/runs/44345990347)의 `cmb011-base-s*-w*` 아티팩트에 존재하며, SHA-256은 [FINAL_COMBINED_FREEZE.json](../results/Final_Model/FINAL_COMBINED_FREEZE.json)에 기록했다(원래 보존 기간 30일).
3. **이번 작업에서 하지 않은 것:** CV 가중치를 임의로 하나 선택하거나 Soft Voting 정책 결정, 4명 전체에 대한 최종 추론용 단일 모델 신규 재학습, 실제 가중치 교체, Original Test 16,000장 또는 교수님 Test 평가.
4. 향후 단일 추론 체크포인트가 필요하다면 **고정된 설정으로 작성자 4명 전부를 학습하는 별도 마지막 Fit**과 체크포인트 해시·검증 기록이 필요하다. 그것은 이 '최종 모델 구성 선정'과는 구별한다.
5. 이번 최종 선정 이전 CMB008 S6의 역사적 판단과 CMB009~011의 개별 실험 로그는 수정하지 않는다.

## 6. 최종 연구 판단

**최종 Combined = 기존 `CMB011/base` / 공식 Training + 기존 Hand-made만 / Size30%-Stroke28%-CoM / 단층 MLP (256,) / alpha=1e-4 / LR=.001 / Batch=128 / Early Stopping=False.**

이번 결정으로 **Combined MLP의 하이퍼파라미터 및 학습 데이터 구성 탐색을 종료하고 최종 모델 구성을 고정한다.** 후속 분석이 있어도 별도 승인과 재검증 없이 자동 변경하지 않는다. Original Test·교수님 Test는 여기서 사용하지 않았다.
