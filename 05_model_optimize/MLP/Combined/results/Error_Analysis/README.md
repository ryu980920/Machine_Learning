# EXP-CMB-002 — Combined Error Analysis 결과 안내

**상태: 계획 / 미실시 · 현재 실측 산출물 없음.**

이 폴더는 [초기분석 EXP유002 계획](../../logs/초기분석/EXP유002_Error_Analysis.md)의 실제 실행 결과를 향후 저장하기 위해 마련한 위치다.

**계획 파일 유형:** 전체 및 작성자별 Viridis Count/Row-normalized CM, `image_features.csv`, `error_transitions.csv`, `writer_metrics.csv`, `per_class_metrics.csv`, `feature_comparison.csv`, `margin_ig_diagnostics.csv`, `run_manifest.json`, 오류 실제 이미지 Grid.

현재 확정된 원본 결과는 [EXP-CMB-001 OOF_predictions.csv](../EXP_CMB_001/OOF_predictions.csv)에 보존되어 있다. 신규 분석이 끝나고 원본과 교차 검증된 파일만 이곳에 등록하며, 예정 파일 이름을 실제 산출물로 표시하지 않는다.
