## 1. 사전 연구 질문과 가설

**가설 3:** MLP가 B↔8, D↔0, F↔5처럼 형태가 비슷한 숫자·문자를 구분할 때 실제 획 형태뿐 아니라 글자 크기를 판단 단서로 학습했다.

EXP유010에서 공식 문자의 원본 BBox 긴 변 중앙값 24px / 숫자 20px, Hand-made 문자는 주로 20px으로 관찰됐다. EXP유011에서는 CoM-only와 Size-only 모델의 혼동 방향이 뒤집혔다.

이 실험은 **같은 손글씨 이미지에서 크기만 의도적으로 0.8/0.9/1.0/1.1/1.2배로 조작**하고, 매 단계 CoM 위치를 (13.5,13.5)로 재정렬한 뒤, 기존 CoM·Size·Size→CoM MLP 각각의 확률·혼동쌍 마진을 측정한다. **모든 16개 클래스/4명 작성자/3개 Seed**를 평가하며, B/8 D/0 F/5는 사전에 정한 핵심 쌍이다.

## 2. 실행 방법·검증

- **기존 EXP유006 원본 모델 9개**, Seed42·43·44 각 CoM/Size/Size→CoM 학습 모델을 GitHub Actions #43785390739에서 그대로 다운로드. 원본 checkpoint SHA256과 입력·정답 건수를 모두 재검증(일치). 새로운 모델 학습·조정 없음.
- 고정 비율의 등방성 affine 변환을 **원본 BBox 중심**에 적용(order=1, cval=0), 그 뒤 기존 center_batch(method='mass', threshold32) 적용. 1.0배는 크기 변경 없이 CoM만 적용.
- Hand-made 2,560장 × 5배율 × 3 Seed × 3 기존 모델. 지표는 클래스/그룹별 Accuracy와 `P(true) − P(confusable)` 평균 마진, 지정 방향의 오분류 건수, 같은 이미지의 클래스 변화.
- 0.8↔1.2 비교에서 topology 유지 subset도 별도로 계산해 형태 손상만으로 추세가 발생하는지 점검.
- 부작용 통제: 위상(연결요소/Euler 수) 변화, 이미지 질량 비율, 변환 후 CoM 오프셋.
- 공식 Original Test/교수님 Test 및 학습용 Hand-made 미사용.

**전체 숫자·문자 16개 클래스 정확도도 크기에 반응했다.** (고정 모델, 동일 Hand-made, Seed 3개 평균)

| 원본 대비 크기 | CoM 모델 숫자 | CoM 모델 문자 | Size→CoM 모델 숫자 | Size→CoM 모델 문자 |
|---|---:|---:|---:|---:|
| 0.8배 | 75.31% | 25.00% | 45.42% | **91.11%** |
| 0.9배 | **88.23%** | 40.90% | 67.00% | **93.47%** |
| 1.0배 | 84.42% | 66.49% | 83.23% | 82.33% |
| 1.1배 | 49.06% | 89.79% | **84.73%** | 61.35% |
| 1.2배 | 19.06% | **95.35%** | 75.35% | 39.10% |

이는 단순 특정 B/D 편향뿐 아니라 **모든 숫자·문자에서 일어나는 크기 의존적인 성능 상충**이라는 점을 보여준다. 여기서 1.0배는 *원본 Hand-made→CoM*이며 EXP유006의 Size→CoM 입력과 다르므로, 기준선 혼동을 피한다.

## 3. CoM 모델은 작은 B/D를 숫자로, 큰 B/D를 문자로 판단하는 경향

**3 Seed 평균 · Hand-made 진짜 클래스 기준 · 같은 모델과 같은 원본 이미지**, 값은 `P(실제 클래스) − P(혼동 상대)`이며 양수는 정답 클래스 우세:

| 실제 → 상대 클래스 | 0.8배 | 1.0배 | 1.2배 |
|---|---:|---:|---:|
| **B vs 8** | **−0.1573** | −0.0724 | **+0.9331** |
| **D vs 0** | **−0.6380** | +0.1394 | **+0.9482** |
| 8 vs B | +0.5154 | +0.5256 | **−0.8366** |
| 0 vs D | +0.8757 | +0.6505 | **−0.8475** |
| F vs 5 | −0.0244 | +0.6661 | +0.9490 |
| 5 vs F | +0.7099 | +0.6892 | −0.2382 |

같은 손글씨 B를 **0.8배**로 줄이면 B-vs-8 마진이 음수지만 **1.2배**로 키우면 크게 양수로 바뀌었다. D 역시 작을 때 0으로 판단하는 경향이 커지고, 커지면 D로 인식한다. 반대로 숫자 8/0은 크기를 키울 때 문자인 B/D로 예측하는 경향이 증가했다.

같은 CoM 모델에서 실제 B Recall은 0.8배 **0.63%** → 1.0배 **35.83%** → 1.2배 **93.96%**로 변했다. D Recall은 **10.42% → 54.79% → 95.42%**였다.

## 4. Size→CoM 모델에서는 '크기 단서 방향'이 오히려 뒤집힘

같은 이미지·같은 배율 조작을 **Size→CoM 학습 모델**에 적용한 결과:

| 실제 → 상대 클래스 | 0.8배 | 1.0배 | 1.2배 |
|---|---:|---:|---:|
| **B vs 8** | **+0.7884** | +0.4760 | **−0.1320** |
| **D vs 0** | **+0.8916** | +0.4237 | **−0.2984** |
| 8 vs B | −0.5313 | +0.6163 | +0.6226 |
| 0 vs D | −0.4073 | +0.6482 | +0.8366 |
| F vs 5 | +0.9410 | +0.8901 | +0.5036 |
| 5 vs F | +0.1102 | +0.7533 | +0.7833 |

Size→CoM 모델에서 B Recall은 **0.8배 80.21% → 1.0배 68.12% → 1.2배 20.83%**이고, D Recall은 **93.12% → 68.75% → 29.79%**였다.

**가장 핵심적인 발견:** CoM-only 모델은 '큰 B/D = 문자' 쪽으로 반응하지만, Size→CoM 모델은 그 반대의 크기 반응을 보였다. 따라서 모델이 단순히 필체의 형태만 본 것이 아니라 **전체 스케일 변화에 매우 민감하고, 어떤 크기 단서를 유리하게 사용하는지가 학습 전처리에 따라 크게 바뀐다.**

이 분석은 Hand-made 원본을 0.8~1.2배로 조작한 **동일 배율 실험**이지, 공식 Training에서 Size 학습이 실제 어떤 단일 특징을 학습했는지 분해한 것이 아니다.

## 5. 위상 유지 이미지에서의 반례 점검

0.8배·1.0배·1.2배 모두에서 **topology(연결요소 수/Euler 수)가 원본과 동일한 이미지**만 남겨 같은 방향이 나타나는지 점검했다. 아래 수치는 3개 Seed 반복을 합친 관측 이미지·예측 표본 수와 평균 pair margin이다.

| 진짜 클래스 / 고정 모델 | 보존 표본 수 (Seed 포함) | 0.8배 | 1.2배 |
|---|---:|---:|---:|
| B / CoM | 327 | −0.157 | **+0.966** |
| B / Size→CoM | 327 | +0.850 | **−0.179** |
| D / CoM | 381 | −0.669 | **+0.971** |
| D / Size→CoM | 381 | +0.904 | **−0.327** |

위상 정보가 보존된 이미지 집합에서도 **크기 반응 방향이 모델에 따라 역전**됐다.

**더 엄격한 검증:** 0.8·0.9·1.0·1.1·1.2배의 **5개 배율 모두에서** 연결요소/Euler 위상이 원본과 같았던 이미지는 6개 핵심 클래스 총 960장 중 **714장(74.38%)**이었고, 3 Seed 반복으로는 2,142개 평가행이다. 이 집합에서도 CoM 모델의 B Recall은 **0.8배 1.01% → 1.2배 97.31%**, D는 **10.57% → 97.56%**, 숫자 8은 **54.29% → 2.22%**, 숫자 0은 **92.42% → 2.53%**로 같은 역전 방향을 보였다. 반복 Seed가 동일 이미지를 재평가한 것이므로 2,142건을 독립 이미지라고 해석하지 않는다.

## 6. 변형 자체의 교란 요인

배율 변화는 순수한 크기만 바꾸지 않는다. 동일 크기 그룹에서 실제 측정된 대표 값:

| 실제 클래스 | 변형 | 위상 변화율 | 평균 잉크 질량/원본 |
|---|---|---:|---:|
| B | 0.8배 | 28.13% | 0.641 |
| B | 1.2배 | 17.50% | 1.440 |
| D | 0.8배 | 20.00% | 0.640 |
| D | 1.2배 | 11.25% | 1.438 |

이로 인해 **크기, 획 굵기, 보간법, 총 밝기·경계 효과가 동시에 달라졌다.** 위상 유지 표본에서도 굵기·밝기·국부 형태 변화는 남는다. 따라서 '모델이 크기만을 독립적인 특성으로 학습했다'는 강한 인과 결론은 아직 내릴 수 없다. 정확한 결론은 **크기 관련 변형이 분류 점수와 정오답을 크게 변화시키며, 전처리 학습 조건에 따라 반응 방향까지 역전한다**는 것이다.

## 7. 가설 3 판정과 다음 분리 검증

**지지:** 동일 모델·동일 이미지에서 CoM을 재정렬해도 크기 배율에 따라 B↔8, D↔0 예측 방향이 체계적으로 바뀌었다. 크기 변형에 대한 학습된 민감도는 확실히 관찰됐다.

**추가로 필요한 검증:** Scale 변화 시 Stroke width/픽셀 질량을 별도 제어하거나, 특정 픽셀 구조를 유지하는 대조(획 복원/강도 정규화)를 추가하면 순수한 BBox 크기와 두께·밝기 단서를 더욱 구분할 수 있다.
