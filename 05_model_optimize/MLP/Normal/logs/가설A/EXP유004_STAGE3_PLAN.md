# 가설 A EXP유004 — Stage3 전체 크기 정규화 강도 비교

**실측 근거:** Stage2 C9는 공식 Training에서 측정한 Bounding Box 긴 변 중앙값 20px로 모든 입력을 정규화 후 CoM 적용. 3개 seed 문자 평균 약 90.97%, 숫자 약 85.35%, 공식 Validation 약 95.57%로 문자 통과·Validation 미달. 단순히 통과라고 판정하지 않는다.

**후속 목표:** 크기 정규화를 약하게 하면 문자는 ≥80%로 유지하고 Official Validation은 ≥97.30%로 회복되는지를 검증. **전처리 기준은 공식 Training만으로 fit**, 정답·작성자·Hand-made 정보를 사용하지 않는다.

- C10~C14: 공식 Training의 긴 변 중앙값을 목표로 하는 등방성 크기 정규화 강도 0.20, 0.35, 0.50, 0.65, 0.80 → CoM.
- 획 연결·구멍 변화는 8-연결/오일러 특성 검증으로 억제. 28×28 실제 원본/변형 이미지를 함께 보관한다.
- 동일 MLPClassifier(100, ReLU, Adam), 공식 Train 76,800장, Validation 19,200장, 각 seed 42·43·44, max_iter200.
- 공식 Test 및 교수님 Test를 평가·튜닝에 사용하지 않는다. 기존 Hand-made는 이미 반복적으로 분석된 개발 지표이며 새로운 작성자에 대한 일반화를 보장하지 않는다.
- **판정:** 문자 ≥80%, 숫자 ≥85%, 공식 Validation ≥97.30%를 세 seed 평균 및 최소 2/3 seed에서 동시 충족해야 개발 통과. 
- 사용자 승인 없이 main에 병합하거나 배포 모델을 교체하지 않는다.
