# 가설 A · EXP유003 — 형태·위치·숫자/문자 혼동 원인 통합진단

> **연구 질문:** MLP의 B/8·D/0·5/F 혼동을 절대 픽셀 위치와 획의 인접·위상 구조 변화만으로 설명할 수 있는가? 향후 **MLP 자체의 최적화**에서는 무엇을 통제·개선해야 하는가?
>
> **상태:** **기존 MLP의 원인 분석 완료(1차), MLP 자체의 개선 학습·효과 검증 미완료.** 기존 MLP 가중치를 고정해 평가했으며 새 MLP 재학습·최적 모델 선정은 수행하지 않았다. 공식 Original Test 및 교수님 Test는 사용하지 않았다.

## 1. 배경과 실험 목적

- [EXP유001](EXP유001_픽셀판단근거_분석.md): 특정 픽셀 영역 제거/약화가 B·D·5의 상대 점수 및 예측에 영향을 주는 사례를 확인. 그러나 획 의미와 픽셀 밝기 변화를 분리하지 못했다.
- [EXP유002](EXP유002_형태대좌표_분리검증.md): 밝기 히스토그램·변경 픽셀 수를 맞춘 작은 픽셀 교환에서, 4-이웃 연결 감소가 무작위 재배치보다 유의하게 더 큰 효과를 준다는 근거를 확보하지 못했다. 국소 좌표별 민감도의 설명력이 높았다.
- **본 실험:** 대표 사례에서 전체 Hand-made로 오류 방향을 확장하고, 실제 이미지에서 **① 고정 MLP의 입력 이동 ② 획 연결·폐곡선 위상 변화**를 개별 검증한다.

**최종 연구 목표는 MLP 자체의 형태 견고성, 위치 견고성, 유사 클래스 구별 능력을 개선하는 것**이며 이번 실험은 그 전단계 원인 진단이다.

## 2. 실제 데이터·모델·통제 조건

- **전수 예측:** 기존 실험의 Hand-made **2,560장(4명×640장, 16클래스)** 예측 CSV 원본에서 작성자·정답·이미지 순서·모델 조건을 대조해 재검증. 각 클래스당 160장.
- **원본 픽셀 실험:** 이전 실험에서 실제 픽셀·모델 체크포인트를 검증한 **Hand-made 20장**만 사용한다. 전체 2,560장에 이미지 변형 실험을 했다고 해석하지 않는다.
- **모델:** 기존 Normal MLP, CoM 학습 MLP 및 기존 CoM 반복 학습·±1px 증강 MLP의 고정된 예측 결과. **최적화 대상과 비교 대상 모두 MLP**이며 새 가중치를 학습하지 않았다.
- 위치 이동·획 제거 실험은 저장된 **Normal MLP 및 CoM MLP 체크포인트**를 직접 사용. 원본 모델 SHA256: Normal `9b54ba9c60e389575200d88ad0b93c47ec47f9c673eebeb755ff47e3ebe23b0a`, CoM `3c1aac362d75ff5c4d9652188c1c4fd97524525f5409ec00d5a6c56fa3ad27ef`.
- 모델 비교·오류 분석은 이미 사용한 개발용 Hand-made를 재활용한 것이므로, 독립적인 새 작성자에 대한 성능 추정으로 해석하지 않는다.

## 3. 전체 2,560장 MLP 기준선 검증

| 기존 MLP·입력 조건 | 전체 (2,560장) | 숫자 (1,600장) | 문자 (960장) |
|---|---:|---:|---:|
| Normal / 원본 | 62.8516% | 56.3125% | **73.7500%** |
| Normal / CoM 입력만 이동 | 70.8984% | 82.0000% | 52.3958% |
| CoM 학습 MLP / 원본 | 64.8438% | 72.4375% | 52.1875% |
| CoM 학습 MLP / CoM | 77.1094% | 83.1875% | 66.9792% |
| CoM 반복 5회 학습 MLP / CoM | 78.8281% | 84.4375% | 69.4792% |
| CoM ±1px 증강 MLP / CoM | **79.5313%** | **87.0000%** | 67.0833% |

- 전체 정확도 향상이 문자 정확도 향상으로 이어지지 않았다. 예를 들어 CoM ±1px 증강의 **숫자 87.00%**는 높지만 **문자 67.08%**는 기존 Normal/원본 **73.75%**보다 낮다.
- 입력 이동과 학습된 모델의 판단 변화를 구분하기 위해 **동일 입력·서로 다른 모델**, **동일 모델·서로 다른 입력** 조건을 별도로 비교했다.

### 대표 오분류 변화 (2,560장 전수)

| 실제→예측 | Normal/원본 | Normal/CoM 입력 | CoM 모델/원본 | CoM 모델/CoM |
|---|---:|---:|---:|---:|
| B→8 | 53 | 58 | 77 | 79 |
| D→0 | 16 | 61 | 70 | 67 |

**해석:** B→8은 모델을 바꿀 때도 증가하며, D→0은 입력 이동과 모델의 변경 모두에서 증가했다. 따라서 **문자 오분류를 CoM 위치 이동 하나로 환원할 수 없다.** 이 표는 조건 간 연관성과 상대적 차이를 보여 주지만 하나의 원인을 완전히 분리하는 인과 실험은 아니다.

## 4. 위치 의존성 검증 — 잉크 손실 없는 입력 이동

- 기존 실제 손글씨 **20장**을 CoM 정렬한 뒤 (±1, 0), (0, ±1), (±2, 0), (0, ±2) 및 대각 이동을 적용.
- **원본 픽셀 밝기 합계가 정확하게 유지되는 경우만 채택**하여 자르기(클리핑)로 인한 형태 손실을 제외. 동일 MLP 가중치를 고정.
- 1픽셀 변형은 **63개**, 2픽셀 변형은 **105개**(각 모델 기준). 여러 변형이 같은 20장에 속하며 독립 손글씨 63/105장이 아니다.

| 변형 거리(맨해튼) | Normal MLP (CoM 입력) 예측 변경률 | CoM 학습 MLP 예측 변경률 |
|---|---:|---:|
| 1px | **38.10%** | **20.63%** |
| 2px | **46.67%** | **39.05%** |

**판정:** CoM 학습 MLP는 선택 사례에서 상대적으로 안정적이지만, 작은 절대 위치 이동에도 예측이 바뀌는 현상은 남아 있다. **이 자체로 위치 증강·모델 구조 변경의 개선 효과가 검증된 것은 아니다.**

## 5. 획 연결·폐곡선 변화 검증 — 실제 픽셀 국소 제거

- **실제 손글씨 20장**에서 획 일부를 제거하는 후보를 만들고, 픽셀의 **8-연결요소 수** 또는 **내부 구멍 수**가 달라지는 조건과 유지되는 조건을 짝지었다.
- 조건을 짝지을 수 있었던 원본은 **18장**. 같은 반경의 국소 제거 **151쌍/302개 변경 입력**을 비교했다.
- 실제 B(작성자41/#59), D(작성자41/#333)는 해당 제약에서 적합한 대조군을 만들지 못해 제외.
- 선택한 개입에서 제거 픽셀 수와 밝기량은 두 조건 간 완전히 일치하지 않으므로 **형태 구조만의 순수 효과 실험은 아니다**.

| 조건 | 원본 대비 평균 절대 logit margin 변화 |
|---|---:|
| 연결요소·구멍 수 변화 | **2.915** |
| 연결요소·구멍 수 유지 | **3.127** |

- 이미지 단위 평균 차이 **−0.212 logit**, 원본 이미지 단위 부트스트랩 95% 구간 **−0.764~+0.288**.
- 획 연결·구멍 수를 바꾼 조건이 유지 조건보다 **일관되게 더 큰 분류 변화**를 유발했다고 보기 어렵다.
- 개입이 실제 인쇄체·필기체의 의미적 획이나 곡률을 훼손하는지 **사람에게 직접 판독받지 않았다**. 연결요소/구멍 개수는 사람의 글자 인식을 대신하는 기준이 아니다.

**원본 이미지 근거:** 실제 B·5 입력의 변형 픽셀을 표시한 `topology_real_image_examples.png`는 검토용 원본 묶음에 별도 보관. 이 저장소에 이미지는 업로드하지 않았으며 실험 과정에서 얻지 않은 요약 그래프는 임의로 생성하지 않는다.

## 6. 가설 A의 세 목표별 검증 상태

| 목표 | 현재 판단 | 후속 MLP 자체 최적화에서 수행할 검증 |
|---|---|---|
| **형태적 특징** | **미완료** — 위상 구조 개입은 했지만 사람의 판독·형태 증강 학습 없음 | 사람이 동일 문자로 읽는 변형의 판독 확인 후 **형태 증강 MLP** 학습·평가 |
| **위치 의존성** | **원인 확인, 개선 미검증** — 고정 모델의 위치 민감도 확인 | 같은 데이터·노출량의 **위치 증강 MLP**와 반복 대조군 학습 |
| **B/8·D/0·5/F 혼동** | **오류 방향 분석, 개선 미검증** — 클래스 집중 재학습 없음 | **유사 클래스 집중 학습 MLP**를 다른 클래스 성능과 양방향 오분류까지 평가 |

### 최종 판정

이번 EXP유003은 **기존 MLP의 오류 원인을 세부적으로 확인한 진단 실험**이며, **MLP 자체를 최적화하는 새 학습·개선 결과는 아직 없다.** 세 목표를 달성했다고 표시하지 않는다.

## 7. 다음 실행 계획 및 완료 조건

1. **공식 Training 76,800장 / Validation 19,200장**의 기존 그룹 분할·데이터 SHA를 재현하고, Official Test 16,000장 및 교수님 Test는 보류한다.
2. 같은 MLP 구조와 동일한 데이터 노출·업데이트 예산, 복수 seed로 **① 반복 학습 대조군 ② 위치 증강 ③ 형태 증강 ④ 유사 클래스 집중 학습**을 비교한다.
3. 형태 증강은 **사람이 원래 글자로 읽을 수 있는지** 독립적으로 확인한 조건에 한해 유효성을 평가한다.
4. 정확도는 **전체/숫자/문자**로 분리하고 **B↔8, D↔0, 5↔F 양방향 오류 및 작성자별 부작용**을 함께 분석한다.
5. 데이터가 확보되어 실제 MLP 후보들을 학습·평가하고, 세 목표별 통제 실험이 끝나기 전까지 EXP유003을 **완결된 최적화 성과**로 표시하지 않는다.
