# 가설 A — 모델의 숫자·문자 분류 기준 및 CoM 이후 문자 저하 원인

## 검증 목적

**MLP는 사람이 관찰하는 획의 형태·방향·연결 구조를 기준으로 분류하는가, 아니면 특정 좌표의 픽셀값과 그 조합에 반응하는가?**

- B/8, D/0, 5/F 등에서 모델이 실제로 중요하게 다루는 픽셀 위치는 어디인가?
- 사람에게 의미 있는 획이 모델에도 같은 방향의 분류 근거로 작동하는가?
- 왜 CoM 이후 B→8과 D→0은 증가하고 5→F는 감소하는가?
- 위치·전체 밝기 등을 통제하고 획의 연결·형태만 바꿔도 분류 기준을 확인할 수 있는가?

[가설 B](../가설B/README.md)에서는 위치 민감도의 존재를 이미 확인했다. 여기서는 **픽셀 위치에 대한 반응과 획의 형태에 대한 학습을 구분**하는 실험을 수행한다.

## 실험

- **[EXP유001 — 픽셀 판단 근거 분석](EXP유001_픽셀판단근거_분석.md):** 전체 Hand-made **2,560장 혼동행렬**과 **20장 실제 손글씨**의 Signed IG·영역 제거/약화 결과 분석.

- **[EXP유002 — 픽셀 좌표 반응과 획 인접 연결성 분리](EXP유002_형태대좌표_분리검증.md):** 실제 20장·1,993개 픽셀 교환 실험. **구조 연결 훼손 vs 무작위 재배치** 대조와 **국소 픽셀 민감도 R² = 0.9459** 검증.

- **[EXP유003 — 형태·위치·혼동 원인 통합진단](EXP유003_형태위치_혼동원인_통합진단.md):** Hand-made 2,560장 기존 MLP 예측 전수 검증, 실제 20장 무손실 위치 이동, 18장 151쌍의 위상 변경/유지 픽셀 개입. **원인 분석 1차 완료, MLP 개선 학습 미실행**.

- **[EXP유004 — Training 분포 기반 획 굵기·크기 정규화 및 MLP 재학습](EXP유004_Training분포기반_획굵기_크기정규화_MLP_실험일지.md):** 공식 Training만으로 보정 기준을 산출하고 **15조건 × 3 seed = 45개 MLP**를 재학습. C9 전체 크기 정규화에서 Hand-made 문자 **90.972%**, 숫자 **85.354%**, 공식 Validation **95.569%**. **세 통과 기준 동시 달성 0/15조건**; 원본+C9 혼합 학습은 미실시.

## 현재 판단

선택한 획 영역의 픽셀값을 바꾸면 클래스 점수와 일부 예측이 바뀐다는 점을 확인했다. **그러나 중요한 픽셀이 획 위에 있다고 해서 모델이 사람처럼 획 구조를 인식했다는 뜻은 아니다.** EXP유002에서 구조 연결을 크게 훼손한 변화가 무작위 픽셀 재배치보다 반드시 더 큰 효과를 보이지 않았고, 작은 픽셀 교환에 대한 국소 좌표별 민감도 설명력이 높았다. **아직 사람과 같은 획 형태 인식 여부는 검증되지 않았다.** EXP유003에서는 전체 2,560장 예측 비교와 실제 픽셀의 무손실 이동·위상 구조 변경까지 확장하였다. 이후 EXP유004에서 공식 Training만으로 보정 기준을 산출해 **실제 MLP 45개를 재학습**했고, C9가 Hand-made 문자 인식률을 크게 높였으나 **공식 Validation 유지 기준에는 미달**했다. 다음 과제는 C9 원본·변형본 혼합 학습의 효과 검증이며, **새 작성자 및 최종 Test 일반화는 아직 미확인**이다.

번호는 가설 A 안에서 독립적으로 관리한다.
