# 가설 A — 모델의 숫자·문자 분류 기준 및 CoM 이후 문자 저하 원인

## 검증 목적

**MLP는 사람이 관찰하는 획의 형태·방향·연결 구조를 기준으로 분류하는가, 아니면 특정 좌표의 픽셀값과 그 조합에 반응하는가?**

- B/8, D/0, 5/F 등에서 모델이 실제로 중요하게 다루는 픽셀 위치는 어디인가?
- 사람에게 의미 있는 획이 모델에도 같은 방향의 분류 근거로 작동하는가?
- 왜 CoM 이후 B→8과 D→0은 증가하고 5→F는 감소하는가?
- 위치·전체 밝기 등을 통제하고 획의 연결·형태만 바꿔도 분류 기준을 확인할 수 있는가?

[가설 B](../가설B/README.md)에서는 위치 민감도의 존재를 이미 확인했다. 여기서는 **픽셀 위치에 대한 반응과 획의 형태에 대한 학습을 구분**하는 실험을 수행한다.

## 실험

- **[EXP유001 — 픽셀 판단 근거 분석](EXP유001_픽셀판단근거_분석.md):** 전체 Hand-made **2,560장 혼동행렬**과 **20장 실제 손글씨**의 Signed IG·영역 제거/약화 결과 분석.

- **[EXP유002 — 픽셀 좌표 반응과 획 인접 연결성 분리](EXP유002_형태대좌표_분리검증.md):** 실제 20장·1,993개 픽셀 교환 실험. **구조 연결 훼손 vs 무작위 재배치** 대조와 **국소 픽셀 민감도 R² = 0.9459** 검증.

## 현재 판단

선택한 획 영역의 픽셀값을 바꾸면 클래스 점수와 일부 예측이 바뀐다는 점을 확인했다. **그러나 중요한 픽셀이 획 위에 있다고 해서 모델이 사람처럼 획 구조를 인식했다는 뜻은 아니다.** EXP유002에서 구조 연결을 크게 훼손한 변화가 무작위 픽셀 재배치보다 반드시 더 큰 효과를 보이지 않았고, 작은 픽셀 교환에 대한 국소 좌표별 민감도 설명력이 높았다. **아직 사람과 같은 획 형태 인식 여부는 검증되지 않았다.** 향후 사람 평가를 포함한 형태적 의미 조작과 전체 오분류 확대 분석이 필요하다.

번호는 가설 A 안에서 독립적으로 관리한다.
