# EXP유019 — 국소 획 위치 증강 학습 실험 결과 (실측, B1·B2 모두 불채택)

## 1. 실험 목적·조건

- **검증 목적:** EXP유018에서 파악한 숫자 7의 상단 U/아치형 획과 하단 꼬리 상대 좌표에 대한 MLP의 민감성을 줄이고 실제 `7→9`를 감소시킬 수 있는지 확인
- **원본:** GitHub `02_data/datasets/MNIST_EMNIST_official_split_112000.npz` 최종 v3, SHA-256 `0e9570d0eb04c0c1da99d043b85bfdab7f3b639eebe4b10335b05b57ad671879` 검증; 테스트 분할 미열람
- **Train/Val:** StratifiedGroupKFold 첫 분할 **76,800/19,200**, 학습에는 Train만 사용; Val은 평가 및 안전 Gate 확인용
- **기존 전처리 재현:** Train 80% 16/18/20/22/24px 클래스 균형 Size, Stroke 14% morphology + topology 검사, CoM; Seed 고정, 61,440장 증강; Stroke 실제 적용 57,642장, topology 거부 3,798장. 기존 EXP유017 기록과 수치 일치
- **모델:** ReLU/Adam MLP `(256,128)`, alpha=0.03, LR=0.001, max_iter=200, Early Stopping=False, Seed 42·43·44; 기존 모델 3개는 SHA 검증된 동결 체크포인트를 재사용
- **B1/B2:** 기존 CoM 처리된 학습 이미지에서 상단(B1)/하단(B2)의 국소 수평 warp ±1px 추가, 뒤에 CoM 재적용. Seed와 무관한 고정 선택으로 16클래스에서 각 **약 20%**, 총 **15,358/76,800장**, 클래스별 좌·우 방향 50:50; 임계값 96·128에서 연결요소·Euler 수 보존; Train 76,800행 유지. 상단과 하단 **별도 모델**로 학습
- **추론:** OfficialVal 및 공식 Hand-made·신규 손글씨 모두 **CoM만 적용**. Hand-made 2,560장 원본 GitHub 41~44 NPZ, 42번 수정 SHA 검증. 새 480/438장은 이전에 여러 번 분석됐으므로 독립 Test가 아님
- **실행:** 기존 동결 3개 + 새로 학습한 B1/B2 각 Seed42/43/44 = **총 9개 비교 모델(신규 6개 학습)**. 원본 Test·교수님 Test 사용 안 함, GitHub main·배포 모델 미변경

## 5. 사전 제안 Gate와 최종 판정

**정확도 및 기존 크기 Shortcut 안전 조건:** OfficialVal 정확도 ≥96.2365%, Hand-made2560 정확도 ≥91.5703%; B·8·D 등 OfficialVal 0.8/1.2 배율 Family Flip 조건 유지; 9→7 증가 여부 확인. **주요 목표:** `7→9`의 재현성 있는 감소.

### B1 상단 ±1px
- OfficialVal: **96.3142%** (기존 대비 -0.2222%p), Hand-made2560: **92.2266%** (+0.1563%p)
- OfficialVal `7→9`: **11→11** (+0), `9→7`: **22→29** (+7)
- Hand-made2560 `7→9`: **27→29** (+2); 신규 438장 `7→9`: **27→21** (-6)
- B/8/D 배율 Family Flip 최악 (세 Seed 평균): **20.06%**, 대상 B×1.2
- **7→9 개선 성공 판정: 불합격.** 9→7 증가와 B 클래스 Family Flip 20% 초과

### B2 하단 ±1px
- OfficialVal: **96.7830%** (기존 대비 +0.2465%p), Hand-made2560: **92.2266%** (+0.1563%p)
- OfficialVal `7→9`: **11→12** (+1), `9→7`: **22→19** (-3)
- Hand-made2560 `7→9`: **27→30** (+3); 신규 438장 `7→9`: **27→29** (+2)
- B/8/D 배율 Family Flip 최악 (세 Seed 평균): **16.47%**, 대상 D×1.2
- **7→9 개선 성공 판정: 불합격.** 기존 크기 Shortcut 안전 Gate는 통과했으나 OfficialVal/Hand-made2560/신규438의 7→9 감소 실패

## 6. 결론과 다음 실험 방향

**B1:** 문제 손글씨 그룹에서는 일부 개선이 있지만 OfficialVal 9→7이 22→29건, B(문자)×1.2 Family Flip이 20.06%로 사전 제한 20%를 초과함. **탈락**.
**B2:** OfficialVal 정확도 96.7830%로 향상(+0.2465%p)하며 B·8·D 크기 Shortcut Gate는 통과. 그러나 7→9는 OfficialVal 11→12건, Hand-made2560 27→30건, 신규438 27→29건으로 증가. **7→9 해결 실패**, 채택하지 않음.
**따라서 국소 위치 변형을 무작위로 20% 일괄 적용하는 방식은 원인 후보에 대한 민감도와 실제 모델 개선 사이에 차이가 있음을 보여준다.** 자동으로 증강 비율을 늘리거나 B1/B2를 합치지 않는다.

**다음 단계(미실행):** Official Train의 7과 9에서 상단 곡선 방향·하단 꼬리의 상대 x 좌표를 측정해 **특징 분포 겹침과 유사한 7/9의 밀도**부터 확인. 그 후 실제 7과 9를 혼동할 만한 구간만 클래스 균형 대조 데이터로 보강하거나 형태/고리 보존에 대한 독립 판독을 포함한 학습 증강을 설계. 무작위 흔들기 강도만 늘리지 않음.

**제한:** 현재 실험의 국소 warp는 원래 숫자 의미 보존을 수치적 topology와 육안 예시로만 확인했으며 전체 증강본의 독립 인간 판독이 완료된 것은 아님. 438장 반복 사용으로 최종 일반화 성공을 주장할 수 없음. 공식 2,560장도 여러 차례 연구에 사용한 개발용 데이터. 원본 Test/교수님 Test 접근 없음.
