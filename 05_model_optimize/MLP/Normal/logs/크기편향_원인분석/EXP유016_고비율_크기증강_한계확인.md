# EXP유016 — 크기 증강 60~100% 확장 및 Shortcut 잔존 위험 최소화

> **사전 등록:** 2026-11-16 · 기존 EXP유010~015의 모든 Markdown 로그, 전체 26조건 판정 CSV, B·8·D 전환율 CSV를 실험 브랜치에 동기화한 후 작성함.
> **선행 기록:** [EXP유015 실측·완료](EXP유015_증강비율_획강도_최적화.md) · [26조건 전체 판정](EXP유015_26조건_전체판정.csv) · [B·8·D 여섯 개입 26조건](EXP유015_26조건_B8D_전환율_전체.csv)

## 1. 실험 질문과 명확한 우선순위

EXP유015에서 50%-28%는 Hand-made 숫자×1.2 Family flip 7.3958%, 문자×0.8 7.9861%로 전체 평균 Shortcut을 크게 완화했지만, **숫자 8 축소(0.8배) 23.54%, 문자 B 확대(1.2배) 21.875%** 등 일부 클래스의 판단이 여전히 불안정했다. 40%-28%는 여섯 B·8·D 개입의 최대가 21.875%로 오히려 50%-28%보다 낮았다.

**제1 목표:** 60%를 넘어서 100%까지 증강 비율을 높이면 **전체 Family flip뿐 아니라 각 클래스별 Family flip, 특히 B·8·D의 최악값까지 지속적으로 낮아지는가?** Shortcut 억제 제약을 먼저 적용하고, 그 뒤 공식 Validation·Hand-made 인식 정확도로 모델을 비교한다.

**제2 목표:** 획 굵기 증강 강도(0·14·28·42%)가 크기 증강 비율 증가와 함께 미치는 독립적·상호작용 효과를 확인한다. 변형 강도는 실제 획 두께를 28% 바꿨다는 의미가 아니라 팽창·침식 픽셀과 원본 픽셀의 혼합 비중이다.

## 2. 사전 확정된 실험 격자

| 조절 인자 | 조건 |
|---|---|
| 크기 증강 **대상 이미지 비율** | **60·70·80·90·100%** |
| 획 팽창·침식 혼합 강도 | **0·14·28·42%** |
| MLP 시드 | **42·43·44** |
| 전체 학습량 | **5×4×3=60개 신규 MLP**, 조건 20개 |
| 고정 기존 모델 | 기존 EXP유015의 **30-28, 40-28, 50-28** 각각 3 Seed, 재학습 없이 비교 |
| 크기 증강 목표 | BBox 긴 변 **16·18·20·22·24px** 균등 할당 |
| 학습 행 수 | 모든 모델 **Original Official Train 76,800장**으로 고정, 원본 데이터 중복 생성 없음 |
| 전처리 | 선택된 이미지 Size Augmentation→Stroke(조건별)→**CoM**, 선택되지 않은 이미지 CoM |
| 평가 | Official Validation 19,200장, Hand-made 2,560장 모두 기본 입력 **CoM만**, 변형 평가는 Hand-made 원본 ×0.8·0.9·1.0·1.1·1.2 후 CoM |
| 비사용 | Original Test/교수님 Test, Hand-made 학습, OfficialVal 학습 |

**50% 초과 nested 증강 설계:** 기존 EXP유014/015의 50% 증강 대상 이미지와 **16·18·20·22·24px 목표**를 그대로 유지하고, 나머지 원본 이미지에서 학습 조건에 따라 10%씩 새로운 증강 대상만 추가한다. Seed42/43/44 모두 증강 구성 자체는 동일하다. 크기 할당은 클래스별 목표 5종이 ±1개 이내로 균형이 되도록 한다. 기존 50% 집단의 획 팽창/침식 방향 역시 50%-28% 실행과 일치시켜, 비율 변화 외의 교란을 줄인다.

**주의:** 증강 100%는 전체 Training 이미지 100%를 크기 목표 5종 중 하나로 처리한다는 뜻이지 **글자를 100% 확대**한다는 뜻이 아니다. 일부 이미지는 우연히 원래와 목표 BBox 긴 변이 같을 수 있다.

## 3. 모든 결과를 보기 전에 고정하는 합격 기준

먼저 기존 EXP유015의 모든 집단 수준 Gate를 동일하게 적용한다.

- 실제 숫자 1.2배 확대 Family flip **3-Seed 평균 ≤10%**, 실제 문자 0.8배 축소 **≤10%**
- 해당 크기 개입의 평균 절대 `ΔP(letter)` 각각 **≤0.12**
- 어느 한 MLP Seed라도 핵심 집단 Flip **>15% 금지**
- 전체 배율 0.8·0.9·1.1·1.2 × 숫자·문자 집단 Family flip의 최대 3-Seed 평균 **≤12%**
- 기본 Hand-made 숫자 정확도 평균 **≥85%**, 문자 **≥80%**

**이번 실험에서 추가하는 개별 클래스 안전 Gate:**

- **B·8·D 각각의 0.8배·1.2배 전환율 3-Seed 평균 최대값 ≤20%**. 기존 50-28의 최댓값 23.54%보다 개선해야 합격.
- **16개 클래스 각각의 0.8배·1.2배 전환율 3-Seed 평균 최대값 ≤25%**. 일부 혼동 글자만 희생하는 모델 방지.
- **B·8·D 개별 시드/배율 전환율 최대값 ≤30%**. 평균이 낮아도 특정 Seed가 심각하게 불안정하면 제외.

각 `Family flip`은 동일한 원본 이미지에 크기 변형을 가한 뒤 `ΣP(A..F)≥0.5`로 결정한 숫자/문자 계열이 1.0배 원본 대비 바뀐 비율을 뜻하며, 반드시 실제 정답과 그룹을 함께 표기한다. 낮은 Flip만으로 모델이 정답을 맞힌다는 의미는 아니다.

## 4. 후보 순위 규칙

1. 위 **집단 Gate + 개별 클래스 Gate를 모두 통과한 모델만** 합격 후보.
2. 합격 후보 가운데 **16개 클래스 전체 × 0.8·1.2배의 최악 Family flip 최소화**를 1순위, **B·8·D 최대 Flip 최소화**를 2순위.
3. 그 다음 **Official Validation 정확도**가 높은 조건을 선호하고, 숫자·문자 중 낮은 Hand-made 정확도가 높을수록 우선한다.
4. 안전 Gate 전원 탈락 시 **신규 최적 모델을 선정하지 않는다**. 단, 후보들의 Pareto trade-off와 가장 낮은 잔존 위험 조건을 보고한다.

출력: 20조건 × 3 Seed 집계 정확도, 전체 배율 Family flip 및 평균 절대 확률 변화, **16개 클래스 개별×0.8·1.2 Flip**, B↔8·D↔0·F↔5 혼동, Writer별 정확도, Train 기하학적 Size-only Binary Probe, 실학습 행 수·SHA·분포, 합격/탈락 사유, 전체 순위, 30/40/50 과거 실측과의 공정 비교.
