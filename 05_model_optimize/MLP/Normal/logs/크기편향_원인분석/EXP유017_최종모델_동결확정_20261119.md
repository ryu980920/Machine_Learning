## 4. 사용·변경 정책

- 앞으로 추가 실험은 별도 후보로 취급하고, **EXP017 원본 가중치·전처리·하이퍼파라미터를 변경하거나 재학습하지 않는다.**
- 최종 모델 변경에는 3중 Gate의 재검증과 사용자 승인이 필요하다.
- 기존 Hand-made2560과 사용자 판독438은 반복 사용한 개발용 자료로서 **독립 Test가 아니다**. Original Test 및 교수님 Test는 사용하지 않았다.
- **최종 연구모델의 3개 Seed 체크포인트를 동결**한 것이다. 이 기록은 배포할 **단일 Seed** 또는 **3-Seed Soft Voting 앙상블**을 새로 선정·배포하는 결정은 아니다.
- GitHub는 공개 저장소이므로 **joblib 가중치를 새로 올리지 않고**, 해시와 고정 사양만 게시한다. 원본 체크포인트 3개와 SHA 검증 스크립트는 별도의 로컬 동결 ZIP으로 보존한다.
