- **실험일:** 2026-11-17
- **실행:** [GitHub Actions #44065285791](https://github.com/ryu980920/Machine_Learning/actions/runs/44065285791), EXP025 실험 브랜치
- **상태:** 신규 12개 MLP 및 최종 집계 모두 성공. 기존 EXP017 동결 모델은 유지하고, `main`에는 본 연구로그만 추가
- **핵심 결론:** **새 Batch Size 32·64·128·256 중 3중 Gate를 모두 만족한 후보는 없음. EXP017 `slot1_alpha_up` 동결 유지.**
- **선정 핵심:** Batch 128은 Hand-made에서 가장 높았지만, **OfficialVal 유지 기준 미달 + D×1.2 Family Flip 상한 초과(평균·Seed별)** 때문에 사전 고정한 선정 절차에서 제외했다. Hand-made 점수로 이 두 Gate를 상쇄하지 않는다.

## 1. 변경 동기와 변수 고정

ML26_09B의 Batch Size와 Learning Rate 의존성 설명을 근거로, 이전 EXP017에서 탐색하지 않은 Batch Size의 영향을 분리했다. 3개의 Seed에서 실험 조건을 고정하고 오직 Mini-batch 크기만 변경했다.

- **고정:** Official Train 76,800장, 동일 원본 및 80%-Size·14%-Stroke·CoM, 은닉층 `(256,128)`, ReLU/Adam, L2 `alpha=0.03`, LR `0.001`, `max_iter=200`, Early Stopping OFF, `tol=1e-4`, `n_iter_no_change=10`.
- **변경:** `batch_size=32/64/128/256`; 기존 Batch Size 200은 EXP017의 SHA 검증된 동결 모델을 재사용하고 다시 학습하지 않았다.
- **평가:** OfficialVal 19,200장은 정상(1.0배) 정확도와 0.8·1.2배 Shortcut Gate에만 사용, 기존 Hand-made 2,560장은 체크포인트 동결 후 사후 검증에만 사용.
- **엄격한 데이터 경계:** Original Test 및 교수님 Test는 사용하지 않았고, Hand-made는 반복 사용된 개발용 평가자료이므로 독립 Test가 아니다.

## 2. 사전 고정 모델 선정 순서

1. **OfficialVal 정확도 유지:** 3-Seed 평균 ≥ **96.5365%**.
2. **Shortcut 안정성 Gate:** 기존 EXP017의 모든 안전 조건 통과. 특히 B·8·D 0.8·1.2배 Family Flip 최악 3-Seed 평균 ≤20%, 단일 Seed 최악 ≤30%, 전체 16클래스 최악 평균 ≤25%, 숫자 1.2배·문자 0.8배 Family Flip 각 ≤10%, 대응 `P(letter)` 절대변화 ≤0.12, 숫자·문자 정상 정확도 각각 ≥85%.
3. **Hand-made 성능 유지:** 전체 2,560장 정확도 3-Seed 평균 ≥ **92.0703%**; 숫자·문자별, 작성자별, B·8·D Recall과 혼동쌍을 함께 확인.
4. **세 조건 모두 통과할 때만** 교체를 검토하며, 어느 하나라도 미달하면 EXP017 모델을 유지한다.

## 7. Batch Size 128 미선정과 기존 Batch Size 200 유지의 결정 과정

### 7-1. 왜 Batch 128을 유력 후보로 살펴봤는가

Batch 128은 기존 Hand-made 2,560장 평가에서 **92.7734%**를 기록해, 기존 EXP017 Batch 200의 **92.0703%**보다 **+0.7031%p** 높았다. 숫자 정확도도 **91.5833% → 92.8750%**로 상승했고, 숫자 8의 Recall은 **82.29% → 86.88%**로 개선됐다. 따라서 전체 손글씨 정확도만 비교하면 Batch 128이 가장 매력적인 후보로 보인다. 이러한 개선은 실측 결과로 인정하고 기록한다.

그러나 본 연구의 목표는 특정 데이터셋에서 정확도 하나를 최대화하는 것이 아니라, **기존 모델이 확보한 OfficialVal 정확도·크기 Shortcut 안정성·Hand-made 정확도를 동시에 유지하는 것**이었다. 이 세 가지는 Batch 128의 결과를 확인한 뒤 만든 조건이 아니라 신규 모델을 평가하기 전에 고정한 선정 기준이다.

### 7-2. 사전 선정 규칙을 순서대로 적용한 판정

| 평가 순서 | 사전 고정 기준 | 기존 Batch 200 | 후보 Batch 128 | Batch 128 판정 |
|---|---|---:|---:|---|
| ① OfficialVal 정상 정확도 | **96.5365% 이상** | **96.5365%** | **96.4653%** | **미달** (−0.0712%p) |
| ② B·8·D 최악 Family Flip (3-Seed 평균) | **20.00% 이하** | **16.67%** | **22.19%** | **미달** (+2.19%p 초과) |
| ② B·8·D 단일 Seed 최악 Family Flip | **30.00% 이하** | **19.25%** | **31.50%** | **미달** (+1.50%p 초과) |
| ③ Hand-made 전체 정확도 | **92.0703% 이상** | **92.0703%** | **92.7734%** | **통과** (+0.7031%p) |
| 최종 판단 | **모든 Gate 동시 충족** | **통과·동결 유지** | **2개 앞선 단계에서 미달** | **불채택** |

Shortcut 위반을 일으킨 핵심 조건은 **문자 D를 1.2배 확대하는 개입**이었다. 이 경우 숫자/문자 Family 판단이 뒤집힌 비율은 Batch 200에서 3-Seed 평균 **16.67%**였지만, Batch 128에서는 **22.1944%**로 증가했다. 특히 Batch 128의 **Seed 43은 31.50%**로 단일 Seed 제한 30%도 초과했다. 즉, Batch 128의 손글씨 정확도 개선을 얻는 대신, 기존 연구가 우선적으로 억제하려 했던 **크기 Shortcut의 재악화**가 나타났다.

### 7-3. Hand-made 전체 정확도가 가리는 취약 클래스의 손실

| Hand-made 지표 | 기존 Batch 200 | 후보 Batch 128 | 변화 |
|---|---:|---:|---:|
| 전체 정확도 | 92.0703% | **92.7734%** | **+0.7031%p** |
| 숫자 정확도 | 91.5833% | **92.8750%** | +1.2917%p |
| 문자 정확도 | **92.8819%** | 92.6042% | −0.2778%p |
| 문자 B Recall | **92.71%** | 89.17% | **−3.54%p** |
| 숫자 8 Recall | 82.29% | **86.88%** | +4.58%p |
| 문자 D Recall | **83.75%** | 81.46% | **−2.29%p** |

Batch 128은 숫자 8 등에서 개선됐지만, 문자 B·D에서는 Recall이 낮아졌다. 숫자·문자의 정확도 변화도 같은 방향이 아니었다. 따라서 **Hand-made 전체 정확도 +0.7031%p가 곧 취약 클래스의 안정성 개선을 뜻하지는 않는다.** B·8·D Recall은 오류 유형을 파악하기 위한 보조 지표이고, 위 ②의 Family Flip은 동일 이미지를 확대·축소했을 때의 숫자/문자 계열 판단 변화를 측정하는 **별도 안전 Gate**다. 두 지표를 혼동하지 않는다.

### 7-4. 최종 선정 논리

1. **후보 발견:** Batch 128은 Hand-made 전체 정확도에서 가장 높은 92.7734%를 기록했으므로 개선 효과 자체는 보존한다.
2. **1차 탈락:** OfficialVal 96.4653%가 동결 모델의 96.5365%를 유지하지 못했다. 차이가 0.0712%p로 작더라도, 사전에 정한 하한을 사후에 완화하지 않는다.
3. **안전 Gate 탈락:** 특히 D×1.2에서 Family Flip 22.19%(Seed 43: 31.50%)로 평균·단일 Seed 상한을 모두 위반했다. B·D 손글씨 Recall도 감소했다.
4. **Hand-made 통과는 탈락 사유를 상쇄하지 않음:** Hand-made 2,560장은 반복 사용한 개발용 데이터이므로 이 결과에 맞춰 OfficialVal·Shortcut 기준을 바꾸거나 모델을 재선정하지 않는다.
5. **결정:** 기존 Batch 200은 세 기준을 모두 통과했고, Batch 128은 두 선행 조건에 실패했으므로 **EXP017 `slot1_alpha_up`, Batch Size 200, Early Stopping OFF를 그대로 동결 유지**한다.

**판정 범위:** 이 결론은 이번 EXP025의 고정된 학습 조건과 3-Seed 평가에 대한 것이다. Batch 128이 모든 상황에서 열등하다는 뜻도, 0.0712%p 차이가 통계적으로 확정된 우월성을 뜻하는 것도 아니다. 채택하지 않은 직접 이유는 **사전등록한 다중 성능·안전 Gate를 충족하지 못했기 때문**이다.

## 8. 결론 및 후속 연구 선택

**결론: EXP017 동결 모델을 유지한다.** 새 Batch 32/64/128/256 중 OfficialVal 96.5365%, 원래 B·8·D Shortcut Gate, Hand-made 92.0703%를 동시에 충족한 모델은 없었다.

- Batch 32: B·8·D Family Flip은 개선되었으나 두 정확도 모두 현저히 감소.
- Batch 64: Hand-made는 근소하게 향상되었지만 OfficialVal과 Shortcut Gate에서 미달.
- Batch 128: Hand-made는 가장 좋았지만 OfficialVal과 B·8·D 안정성에서 미달. 취약 B·D Recall도 하락.
- Batch 256: OfficialVal·Shortcut·Hand-made 모두 기존 기준 유지 실패.

**다음 연구는 Batch Size 추가 탐색보다 ML09B의 Calibration/Overconfidence 정량 분석을 권장한다.** 기존 모델을 동결한 상태에서 NLL·ECE·Brier Score·고확신 오분류를 진단하면 불필요한 재학습 없이 모델의 확률 신뢰도를 확인할 수 있다. 다만 이 방향 역시 다음 실험으로 별도 등록하며 EXP017을 자동 변경하지 않는다.
