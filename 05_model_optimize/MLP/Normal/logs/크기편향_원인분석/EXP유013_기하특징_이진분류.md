# EXP유013 — 기하학적 특징만으로 숫자·문자 구분 가능성과 Shortcut 단서 검증

> **진행 상태:** 실행 중 / 성공한 실제 결과는 Actions Artifact CSV로 작성. 이 문서에는 결과를 미리 기입하지 않음.
> **실행 근거:** https://github.com/ryu980920/Machine_Learning/actions/runs/43809791116

## 문제와 검증 질문
EXP유010~012에서 숫자/문자 정확도 역전과 이미지 스케일 변경 시 예측 이동을 확인했다. 그러나 "원본 공식 Training의 크기·질량 정보만으로 클래스 계열을 구별할 수 있는가"는 직접 이진분류하지 않았다.

- **가설:** Official Train의 기하학적 특징에 레이블 계열(숫자/문자)과 연관된 정보가 있으며 정규화 후 일부 단서가 약해진다.
- **지표:** 이진분류기 Official Validation balanced accuracy 및 ROC AUC, Hand-made 개발용 성능. **기하학적 이진분류기 성능만으로 MLP가 해당 특징을 사용했다고 단정하지 않는다.** MLP 의존성은 EXP유012의 고정 가중치 개입 결과와 결합해 판단한다.

## 실험 조건
- 데이터: Official Train **76,800** / Official Validation **19,200** / Hand-made **2,560**(41~44 작성자).
- 출력 계열: 숫자 0~9 → 0, 문자 A~F → 1; 레이블을 모델 특징으로 입력하지 않음.
- 입력 4변수: `long_side`(Size), `width`, `height`, `mass`(픽셀 밝기 합). 기존 EXP유006·010의 `image_geometry` 재사용.
- 네 전처리: 원본(raw), CoM-only, Size-only, Size→CoM. Size 목표 긴 변 **20px**, threshold 32, 보간 방법을 기존 코드와 동일하게 유지.
- 이진분류기: 클래스 가중치 보정 Logistic Regression(StandardScaler), 얕은 Decision Tree(max_depth=3). Training에서만 모델 파라미터 학습.
- 단일 특징 및 ablation: Size만, Width+Height, Ink Mass만, 네 변수 모두, Mass 제외, Size 제외.
- Validation 및 Hand-made에서 fitting/기준값 학습 금지. 공식 Original Test / 교수님 Test 사용 금지.

## 판정
- 원본 이진분류 성능 높음→정규화 후 감소: 지름·질량 관련 데이터 Shortcut 단서가 감소한 증거.
- 정규화 후에도 ROC AUC 높음: 학습할 수 있는 구분 단서 잔존. 인과적 MLP 활용 여부는 EXP유012의 개입 반응으로 보완.
- Size, Width/Height, Mass 중 어느 묶음이 잔존하는지 보고 EXP유014 개선 방안을 평가.
- Hand-made는 동일 작성자를 반복 확인한 개발용 자료이며 독립 최종 Test가 아니다.
