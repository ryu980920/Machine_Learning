## 7. 모델 선정 결정 — 기존 EXP017 유지

1. **OfficialVal Gate:** 기존 200의 96.5365%를 새 후보가 유지하지 못했다. Batch128=96.4653%, Batch64=96.3125%.
2. **Shortcut Gate:** Batch128의 D×1.2 Family Flip은 3 Seed 평균 22.19%, 개별 Seed 최악 31.50%로 사전 상한 20%·30%를 초과. Batch64도 B·8·D 최악 평균 20.39%로 기존 Gate를 미통과.
3. **Hand-made2560 Gate:** Batch128은 92.7734%로 통과, Batch64는 92.1615%로 통과하나, 한 개 Gate 통과가 다른 미달을 상쇄하지 않는다.
4. **438장:** Batch64/128의 88.7367%는 추가적인 필체 진단의 가치가 있지만, 사후 품질 판독 및 반복 평가된 세트이므로 모델/하이퍼파라미터 재선정 근거로 사용하지 않는다.
5. **결정:** `EXP017 slot1_alpha_up`, Batch 200, Size80% + Stroke14% + CoM, 3 Seed 기준선 **동결 유지**. Soft Voting도 이 438장 결과만으로 채택하지 않는다.
