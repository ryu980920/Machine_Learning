# 최종 모델 선정 — EXP017 `slot1_alpha_up`

- **확정일:** 2026-11-19
- **연구 범위:** Normal MLP · 숫자 0–9 및 문자 A–F, 총 16클래스 분류
- **최종 상태:** **EXP017 `slot1_alpha_up` 선정 확정 / 하이퍼파라미터 및 체크포인트 동결 / 추가 최적화 종료**
- **확정 범위:** Seed 42·43·44의 기존 MLP 체크포인트 3개와 공통 전처리·학습 설정. 배포용 단일 Seed 또는 Soft Voting 앙상블은 별도로 채택하지 않음.

## 1. 선정 기준

이번 프로젝트의 모델 선정 목표는 OfficialVal 정확도를 높이면서도, 학습 데이터의 크기 차이를 이용해 숫자와 문자를 구분하는 Shortcut 편향을 억제하고, 팀원이 직접 작성한 손글씨에서도 기존 성능을 유지하는 것이었다. 따라서 손글씨 정확도나 OfficialVal 정확도 하나가 높다는 이유만으로 최종 모델을 교체하지 않았다.

EXP017에서 기존 80%-Size·14%-Stroke·CoM 전처리를 유지한 상태로 MLP의 구조, L2 규제와 초기 학습률을 탐색했다. 이후 새로운 후보의 교체 여부는 다음 세 조건을 동시에 만족하는지로 결정했다.

1. **OfficialVal:** 기존 확정 모델의 3-Seed 평균 정확도 **96.5365% 이상**.
2. **Shortcut:** 기존 EXP017의 크기 개입 안전 Gate **전체 통과**. 핵심 조건은 B·8·D의 0.8/1.2배 Family Flip 최악 3-Seed 평균 **20% 이하**, 개별 Seed 최악 **30% 이하**이며, 전체 16클래스·숫자/문자 계열별 확률 변화와 정상 정확도 조건도 포함한다.
3. **Hand-made:** 기존 작성자 4명의 **2,560장**에서 3-Seed 평균 정확도 **92.0703% 이상**.

Family Flip은 동일한 이미지를 확대·축소했을 때 예측의 **숫자/문자 계열 자체가 바뀐 비율**이다. 일반적인 클래스 오분류율 또는 B·8·D Recall과 구분하여 판단했다. 위 3중 기준은 EXP017을 기준선으로 확정한 후 후속 후보의 비퇴보 여부를 검증하는 규칙이며, 438장 사후 평가 결과에 맞춰 완화하지 않았다.

## 2. 최초 선정

EXP017에서는 1차 26조합과 2차 20조합, **총 46개 하이퍼파라미터 조합 × Seed 3개 = 138개 모델**을 학습했다. 기존 크기 Shortcut 안전 Gate를 모두 통과한 조합은 **10개**였으며, 통과한 조합 가운데 OfficialVal 원본 이미지 정확도를 기준으로 `slot1_alpha_up`를 선택했다.

선택된 모델은 OfficialVal **96.5365%**, B·8·D 최악 Family Flip **16.67%**를 기록했다. 비교 후보 중 초기 학습률 0.0014 조건은 OfficialVal **96.5521%**로 소폭 높았지만, B·8·D 최악 Family Flip **21.69%**로 제한 20%를 초과해 제외했다. 이는 최초 선정부터 정확도와 편향 안정성을 함께 고려했음을 보여준다.

동결 후 기존 Hand-made 2,560장을 평가한 결과 3-Seed 평균 **92.0703%**를 기록해, 후속 실험의 손글씨 유지 기준으로 사용했다.

## 3. 후속 검증

EXP017 선정 후에는 학습 종료 시점과 Batch Size에 따라 성능이 개선되는지 확인했다. 각 실험에서 새 후보를 만든 이유와 실제 판단은 다음과 같다.

| 실험 | 검증 질문과 수행 내용 | 관찰 결과 | 선정 판단 |
|---|---|---|---|
| **EXP021** | Early Stopping ON/OFF의 학습곡선과 일반화 성능 비교 | OFF의 Train Loss가 감소하는 동안 Val NLL 악화 신호 관찰. 다만 ON/OFF의 실제 학습량·종료 규칙이 달라 원인 분리 불가 | 종료 방식 변경 보류 |
| **EXP022** | OfficialTrain 내부 69,119장 학습·7,681장 검증, 동일 학습 경로에서 Accuracy Best/Loss Best/Last 비교 | OfficialVal Accuracy Best **96.5399%**, Loss Best **96.4601%**, Last **96.3090%** | 같은 학습 경로에서는 검증 기반 선택이 유효하나 FullTrain 적용 여부 미확정 |
| **EXP023** | EXP022의 원본 체크포인트를 재학습 없이 Hand-made 2,560장에 평가 | Accuracy Best **91.6927%**, Loss Best **91.6146%**, Last **91.2109%** | 기존 EXP017 **92.0703%**에 미달 |
| **EXP024** | EXP022에서 정한 Epoch를 고정하고 OfficialTrain 76,800장 전체로 재학습 | FullTrain Last: OfficialVal **96.1979%**, Hand-made **92.0703%** | 손글씨 동률이지만 OfficialVal 저하 및 전체 Shortcut Gate 동등 통과 미입증으로 불채택 |
| **EXP025** | 모델·전처리·Seed를 고정하고 Batch Size 32·64·128·256만 비교 | 기존 Batch 200보다 손글씨가 높은 후보는 있었으나 OfficialVal 유지 및 Shortcut 안전 조건을 동시에 충족한 신규 후보는 없음 | Batch 200 유지 |

특히 Early Stopping 실험은 검증 데이터로 체크포인트를 선택하는 효과와 전체 학습 데이터 76,800장을 사용하는 효과가 동일하지 않다는 점을 보여줬다. 따라서 내부 Validation에 최적인 Epoch를 그대로 최종 모델의 학습 종료 시점으로 채택하지 않았다.

## 4. Batch Size

EXP025에서는 **오직 Batch Size만 변경**하여 Seed 42·43·44의 신규 모델 12개를 학습하고, Batch 200은 EXP017 동결 체크포인트를 그대로 재사용했다. 각 조건의 3-Seed 평균은 다음과 같다.

| Batch Size | OfficialVal 19,200장 | B·8·D 최악 Family Flip | Shortcut Gate | Hand-made 2,560장 | 최종 교체 조건 |
|---:|---:|---:|---|---:|---|
| 32 | 95.3229% | 11.94% | 통과 | 90.9766% | 미달 |
| 64 | 96.3125% | 20.39% | 미달 | 92.1615% | 미달 |
| **128** | 96.4653% | **22.19%** | **미달** | **92.7734%** | **미달** |
| **200 — EXP017** | **96.5365%** | **16.67%** | **통과** | **92.0703%** | **통과** |
| 256 | 96.4826% | 21.61% | 미달 | 91.7839% | 미달 |

Batch 128은 기존 손글씨 정확도가 Batch 200보다 **0.7031%p** 높아 가장 유력한 후속 후보였다. 그러나 OfficialVal은 **0.0712%p 낮았고**, 문자 D를 1.2배 확대했을 때의 Family Flip이 **22.19%**로 평균 상한 20%를 초과했다. Seed 43에서는 **31.50%**로 개별 Seed 상한 30%도 초과했다. 또한 기존 Hand-made에서 문자 B Recall은 **92.71% → 89.17%**, 문자 D Recall은 **83.75% → 81.46%**로 감소했다.

따라서 Batch 128의 손글씨 전체 정확도 개선은 연구 결과로 보존하되, **OfficialVal 유지와 크기 Shortcut 안정성이라는 선행 조건에 실패했기 때문에 최종 모델로 채택하지 않았다.** 작은 정확도 차이만으로 통계적 우열이 입증됐다는 뜻이 아니라, 사전에 고정한 교체 조건을 충족하지 못했다는 판단이다.

## 5. 추가 손글씨

사용자 판독으로 480장에서 42장을 제외한 **438장**도 15개 동결 체크포인트로 사후 평가했다. 기존 Batch 200은 **87.8995%**, Batch 64와 128은 각각 **88.7367%**였다. 3-Seed Soft Voting 사후 진단에서는 Batch 64가 **91.0959%**로 가장 높았다.

하지만 438장은 이미 육안 품질 판독과 반복 오분류 분석에 사용된 **개발용 평가 자료**다. 새로운 독립 Test가 아니며, 해당 결과를 보고 Batch Size를 다시 선택하거나 Soft Voting을 최종 방식으로 도입하지 않았다. 기존 3중 Gate의 기준을 유지했다.

## 6. 최종 확정

**최종 모델을 EXP017 `slot1_alpha_up`으로 확정하고, Normal MLP 최적화 단계를 종료한다.** EXP021~025에서 관찰한 일부 개선 결과는 연구 근거로 보존하되, 기존 모델을 대체하지 않는다.

| 항목 | 확정 값 |
|---|---|
| 모델 | `sklearn.neural_network.MLPClassifier` |
| 은닉층 | `(256, 128)` |
| Activation / Solver | `relu` / `adam` |
| L2 `alpha` | `0.03` |
| `learning_rate_init` | `0.001` |
| Batch Size | **200** (`batch_size='auto'`의 실제 값) |
| Early Stopping | `False` |
| `max_iter` / `tol` / `n_iter_no_change` | `200` / `0.0001` / `10` |
| 학습 입력 | OfficialTrain **76,800장**; 80%-Size + 14%-Stroke + CoM |
| 추론 입력 | **CoM 정렬 → PixelScaler255 → 동결 모델** |
| 동결 체크포인트 | Seed **42·43·44** 기존 학습 파일 3개 |

최종 확정 대상은 **3개의 원본 가중치와 이들의 공통 설정**이다. 이번 확정으로 단일 Seed를 선택하거나 세 Seed를 Soft Voting으로 결합해 배포하는 정책을 새로 결정한 것은 아니다.

## 7. 종료 원칙

본 실험에서 최종 모델 선정은 **완료**됐다. 이후 신규 모델 탐색·Calibration·앙상블 분석이 진행되더라도 이는 최종 확정 모델을 변경한 것이 아니라 별도 후속 연구다. 변경하려면 사전 정의된 3중 Gate 검증과 별도 승인 절차가 필요하다.

본 연구에서 기록한 OfficialVal과 Hand-made 2,560장 및 사용자 판독 438장 정확도는 **학습·개발 검증 성능**이며, Original Test와 교수님 Test의 미공개 평가 결과로 대체할 수 없다. 두 Test는 이번 선정 과정에서 사용하지 않았다. 초기 목표였던 OfficialVal **97.30%에는 도달하지 못했지만**, 완료한 후보 비교에서 정확도·크기 편향 안정성·손글씨 성능을 종합해 가장 일관되게 조건을 충족한 EXP017 모델을 최종 선택했다.

**결론: EXP017 `slot1_alpha_up` / `(256,128)` / `alpha=0.03` / LR `0.001` / Batch `200` / Early Stopping OFF / Size80% + Stroke14% + CoM — 최종 동결 확정.**
