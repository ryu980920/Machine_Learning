## 1. 사전 연구 질문 및 검증 설계

**가설 2:** Size-only 입력의 무게중심이 숫자 MLP의 학습 좌표와 맞지 않아 숫자 정확도가 크게 낮아졌고, Size→CoM 재정렬이 이를 회복한다.

이전 EXP유006의 Size-only 모델 숫자 36.4583%와 Size→CoM 모델 숫자 84.0625%의 **+47.6042%p 차이**는 **입력 전처리와 학습된 가중치가 동시에 다른 비교**였다. 이를 둘로 분리하기 위해 기존 모델을 **고정**하고 동일 손글씨의 Size-only 입력과 Size→CoM 입력을 교차 평가한다.

- 학습 고정 모델: EXP유006 성공 실행의 CoM, Size-only, Size→CoM 각각 seed42·43·44 = 9개 모델 (새 학습 없음).
- 평가 입력: Raw, CoM, Size, Size→CoM, 즉 **3개 학습 조건×4개 평가 표현**을 Official Validation 19,200장과 Hand-made 2,560장에 동일하게 적용.
- 모든 원본 모델의 `model.joblib` SHA256과 실제 원본 실험의 Seed별 OfficialVal·Hand-made 전체/숫자/문자 정답 수가 **완벽히 일치하지 않으면 중단**. 성공 실행에서 전부 일치함.
- 같은 이미지의 정오답 교정/신규 오류, B↔8/D↔0/5↔F, CoM 이동량·중심 오프셋·픽셀 질량 변화 측정.

## 2. 실제 결과 — 학습 모델과 평가 입력 교차표

**Hand-made 3-Seed 평균**, 각 행은 실제 기존 MLP를 다시 불러 고정한 평가 결과:

| 학습 모델 | 평가 입력 | 숫자 | 문자 | Official Validation |
|---|---|---:|---:|---:|
| CoM | CoM | 84.4167% | 66.4931% | 97.0521% |
| CoM | Size | 81.3125% | 39.8611% | 76.5694% |
| CoM | Size→CoM | **91.4792%** | 55.3472% | 81.9045% |
| **Size** | **Size** | **36.4583%** | **94.2014%** | 96.6858% |
| **동일한 Size** | **Size→CoM** | **73.8125%** | 69.7222% | 86.4080% |
| Size→CoM | Size | 72.2708% | 77.2917% | 91.9983% |
| **동일한 Size→CoM** | **Size→CoM** | **84.0625%** | **91.7708%** | 96.0608% |

원래 가설 설명에서 'Size-only 36.46→Size+CoM 84.06'은 모델과 입력 둘 다 다른 비교였다. 이번에는 **Size 모델 자체를 고정**했으므로, 추가 CoM 입력의 반응은 숫자 **+37.3542%p (36.4583→73.8125)**, 문자 **−24.4792%p (94.2014→69.7222)**로 분리돼 측정됐다.

## 3. 같은 이미지의 정오답 교정/신규 오류

**Size-only 모델 고정** 후 입력만 Size→CoM으로 변경했을 때, Seed당 평균:

| 실제 그룹 | 기존 오답→정답 | 기존 정답→오답 | 순증 정답 | 정확도 변화 |
|---|---:|---:|---:|---:|
| **숫자 0–9** | **631.00장** | 33.33장 | **+597.67장** | **+37.3542%p** |
| 문자 A–F | 18.33장 | **253.33장** | **−235.00장** | **−24.4792%p** |

숫자 복구는 많은 동일 이미지의 예측 오류가 수정된 실제 결과다. 같은 위치 보정이 문자를 오히려 오답으로 전환하는 것은 모델의 입력 픽셀 위치 의존성을 나타낸다.

CoM 전후 Hand-made 전체 중심 오프셋 평균은 **1.347px → 0.380px**이었고, **81.52%**의 이미지가 정수 픽셀 기준 실제 이동했다. 이미지 전체 픽셀 질량의 전후 평균 비율은 **0.999883**으로 큰 소실 없이 위치 중심을 정렬했다. (정수 이동 과정에서 가장자리가 잘린 일부 이미지는 있을 수 있으므로 픽셀 질량도 함께 보존.)

**경로 의존성(상호작용)을 확인했다.** Size-only 대각선 숫자 **36.4583%**에서 (1) 동일 Size 모델의 입력을 먼저 CoM으로 정렬하면 **73.8125% (+37.3542%p)**, 이어 해당 입력에 맞춘 Size→CoM 학습 모델로 바꾸면 **84.0625% (+10.2500%p)**가 된다. 그러나 순서를 바꾸면 (2) 동일 Size 입력에서 Size→CoM 학습 모델로 먼저 바꾸는 효과는 **+35.8125%p**(36.4583→72.2708), 그 모델에 CoM 입력을 주는 효과는 **+11.7917%p**(72.2708→84.0625)다. **47.6042%p 전체 효과는 경로마다 달리 분해되므로, +37.35%p를 독립적인 순수 CoM 기여율이라고 취급하면 안 된다.**

크로스 클래스 전체 예측 CSV로 확인한 **실제 숫자→문자 / 문자→숫자 오분류 비율**(대각선 평가, 3 Seed 평균):

| 모델·입력 | 실제 숫자→문자 | 실제 문자→숫자 |
|---|---:|---:|
| CoM-only | 8.10% | **31.56%** |
| Size-only | **60.23%** | 0.66% |
| Size→CoM | 9.31% | 4.41% |

## 4. 문자·숫자 판단 편향의 역전: 주요 혼동쌍

**각 학습 모델의 자기 전처리 입력으로 평가한 Seed당 평균 오분류 건수:**

| 실제 → 예측 | CoM-only | Size-only | Size→CoM |
|---|---:|---:|---:|
| **B→8** | **72.7건** | 1.3건 | 11.3건 |
| **8→B** | 33.3건 | **97.0건** | 37.0건 |
| **D→0** | **64.7건** | 1.7건 | 16.3건 |
| **0→D** | 25.0건 | **78.7건** | 18.0건 |
| **5→F** | 11.3건 | **76.3건** | 13.0건 |
| **F→5** | 13.0건 | 0.0건 | 0.3건 |

즉, CoM 모델은 **B·D를 숫자 8·0으로 오분류**하는 경향이 컸지만, Size-only 모델은 반대로 **숫자 8·0·5를 문자 B·D·F로 오분류**했다. 이는 문자·숫자 정확도가 단순히 조금씩 변한 것이 아니라 **혼동의 방향 자체가 반전**된 결과다.

## 5. 가설 2 판정

**강하게 지지:** 같은 Size-trained 모델을 고정해도 CoM 입력 정렬만으로 숫자 정확도가 **+37.35%p**로 회복되고 문자는 **−24.48%p**로 하락했다. 위치 변경의 직접적인 입력 효과는 실제 관찰됐다.

**동시에 확인된 효과:** Size-trained 모델에 CoM 입력을 넣은 73.81%와 Size→CoM으로 학습된 모델에 같은 입력을 넣은 84.06% 사이에도 숫자 **+10.25%p** 차이가 남는다. 이 차이는 **학습 시 입력 분포에 맞춰 형성된 모델 가중치의 효과**와 부합한다. 그러나 두 모델 간의 최적화 차이까지 제거한 단독 인과 분리로 과도하게 주장하지 않는다.

**한계:** 교차평가의 비대각 조건은 모델이 학습할 때 경험하지 않은 전처리 분포(OOD)일 수 있다. 이 비교는 입력 민감도 진단이지 새로운 최종 모델 정확도가 아니다.
