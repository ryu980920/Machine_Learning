# EXP유015 — Shortcut 억제를 최우선으로 둔 크기 증강 비율 × 획 증강 강도 최적화

> **단계:** 사전등록 → GitHub Actions 학습·실측 → 사전 Gate 적용 → 결과 확정
> **이전 실험:** [EXP유013](EXP유013_기하특징_이진분류.md) · [EXP유014](EXP유014_Shortcut_완화_학습.md)
> **전처리 위치:** Official Training에서만 Scale/Stroke Augmentation, **모든 학습·평가 입력에 CoM 정렬**. Validation/Hand-made 증강본은 진단용으로만 활용.

## 1. 문제 설정

EXP유014에서 Training 약 50%에 크기+획 증강을 적용하자 Hand-made 숫자 89.40% / 문자 88.19%로 동시 개선되고, 숫자를 1.2배 확대했을 때 숫자↔문자 Family flip이 CoM 기존 71.60%→6.83%, 문자를 0.8배 축소했을 때 46.08%→8.40%로 감소했다. 그러나 공식 Validation은 97.05%→95.60%로 낮아졌다.

이번 실험은 **크기 Shortcut이 다시 강해지지 않는 것을 최우선 제약으로 설정**한 뒤, 제약 통과 모델 사이에서 Official Validation 정확도를 최대화한다. 필요하면 OfficialVal 성능 일부를 포기한다. `max(OfficialVal)`을 Shortcut보다 우선하지 않는다.

## 2. 사전 등록된 조건과 고정값

- **원본 데이터:** Official Train 76,800장 / Official Validation 19,200장 / Hand-made 2,560장(작성자 41~44). Test 파일 전면 미사용.
- **모델:** EXP유006 기본 sklearn `MLPClassifier(random_state=seed)`, 입력 `PixelScaler255`; Seed 42·43·44; 학습행 수 모두 76,800장.
- **전처리:** 기존 EXP유006과 동일한 `center_batch(method="mass")`, 이미지 28×28, 흰색 전경 임계값32, 중심13.5px.
- **실험축 1:** 증강 대상 비율 **10%, 20%, 30%, 40%, 50%** (0%는 **기존 EXP유006 CoM 체크포인트를 재사용하는 고정 대조군**).
- **실험축 2:** 획 굵기 증강 강도 **0%, 14%, 28%**: 0%는 크기만 변경; 나머지는 원본 EXP유014의 Erode/Dilate + 혼합을 강도만 변형하고 topology 변화가 생기면 해당 획 변형은 거부.
- **계획 총량:** 5비율 × 3획 강도 × 3 Seed = **45개 신규 MLP 학습**. 추가 비율40%는 30↔50% 중간 구간 보강. 기존 50%·28% 조합으로 EXP유014 결과를 재현 확인.
- **이미지 크기 목표:** 16·18·20·22·24px을 클래스마다 동일 횟수 배정. 이 비율은 Training 원본 클래스별 50% 목표 크기 배정을 기준으로 **nested subset**으로 선택하며 Seed별 동일 이미지 사용.
- **평가:** 기본 Official Validation 및 Hand-made는 무작위 Augmentation 없이 **CoM만 적용**. 별도 손글씨 크기 민감도 검증에서만 **Hand-made 원본→0.8·0.9·1.0·1.1·1.2배→CoM**.
- **고정 원본 체크포인트:** EXP유006 CoM Seed 42·43·44 및 hash/역사적 예측 수 검증. 기존 모델 변형 없음.

## 3. Shortcut 재발 방지: *결과를 보기 전에* 고정한 합격 기준

**다음 조건을 모두 통과해야 후보 자격이 있다.**

1. 실제 숫자 Hand-made를 **1.2배** 확대한 입력의 숫자/문자 Family 판단 전환율(1.0배 대비)이 **3-Seed 평균 10% 이하**.
2. 실제 문자 Hand-made를 **0.8배** 축소했을 때 Family 판단 전환율 **3-Seed 평균 10% 이하**.
3. 두 핵심 개입에서 `P(letter)=Σ P(A..F)` 평균 **절대 변화량 각각 0.12 이하**. 단순 threshold 근처 불안정성을 넘어서 실제 확률이 흔들리는지도 통제.
4. 핵심 개입의 **각 Seed 개별 Family flip이 15%를 초과해서는 안 됨**.
5. 0.8·0.9·1.1·1.2배 전체 × 실제 숫자/문자 각 집단의 **평균 Family flip이 모두 12% 이하**.
6. 정상 Hand-made의 숫자 Accuracy **85% 이상**, 문자 Accuracy **80% 이상** (각 3-Seed 평균): 언제나 숫자만 찍는 불변 모델의 허위 통과를 방지.

가장 중요한 것은 ①~⑤의 Shortcut 불안정성 방지이다. ⑥은 최소 유효 모델 조건. 이 조건을 실패한 모델은 공식 Val 정확도가 아무리 높아도 **선택하지 않는다**.

이 게이트는 **크기 Shortcut이 완전히 사라졌음을 수학적으로 입증하는 절대 기준이 아니라**, 이전 EXP유014가 달성한 행동 안정성에 근거한 보수적인 통제 기준이다. Size·Width·Height·InkMass 등 기하학적 출처 편향이 남는지 추가 측정한다.

## 4. 통과 모델의 성능 비교

①~⑥을 통과한 모델들만 공식 Validation 평균 Accuracy를 **우선순위 1**로 순위화. 동점이면 Hand-made 숫자·문자 가운데 더 낮은 정확도(`min`)를 높이는 후보 우선; 그래도 같으면 전체 스케일 판단 민감도 최소화.

- 공식 Val 목표 **97.30%**, 차선 목표 **97.0%**.
- Hand-made 숫자 **85%**, 문자 **80%** 이상은 합격 기준이지 단독 최적화 대상이 아님.
- B↔8·D↔0·F↔5 클래스별 오류, 작성자별 Accuracy·크기 민감도까지 측정해 국소적인 Shortcut 재발 점검.
- 증강 Training의 Size-only 이진분류기를 OfficialVal로 평가한 지표는 **남은 기하학적 정보의 진단**이다. 해당 숫자가 높다는 사실만으로 MLP의 Shortcut을 확정하지 않고, Family flip과 함께 판단.

## 5. 결과 해석/데이터 경계

- Hand-made는 이미 여러 번 평가된 동일 네 작성자의 **개발용 데이터**다. Grid 탐색에 따른 Selection Bias가 있으므로 독립 신규 작성자 평가 전에는 일반화 성능을 주장하지 않는다.
- 원본 OfficialVal도 이미 반복 사용된 개발 Validation이다. **어떤 데이터도 새 모델 fitting에 입력하지 않는다.**
- 모든 증강 대상은 원본 Official Training에서만, 원본 Training 행 수는 동일. 씨앗을 바꿔도 증강 입력은 일치하고 MLP 초기화만 달라진다.
- EXP유013에서 확인한 원본 크기 Shortcut (Original Size-only Balanced Accuracy 99.76%)과 EXP유014 대조 MLP를 반드시 원본 기록과 구분한다.
- 원본 Test/교수님 Test 사용 금지. 안전 Gate 통과 모델이어도 **자동 최종 모델 교체·main 병합 금지**. GitHub Draft PR에만 기록하며 사용자 승인을 받는다.

### 이겼다는 것과 Shortcut 완전 제거는 다르다

- 선택 규칙(Shortcut Gate 통과 후 OfficialVal 최대) 기준 우수 후보는 **30% / 28%**.
- 기존 EXP유014의 50% / 28%보다 공식 Validation 약 **+0.58%p** 회복했으나, 목표 **97.30%**에는 **−1.12%p** 미달.
- 전체 숫자·문자 Family flip 평균은 각 10% 이하이지만, 주요 혼동 클래스 **8의 0.8배 Family flip 26.46%**, **B의 0.8배 25.62%**, **D의 1.2배 22.50%**. 이 통계는 각 클래스 160장×3 Seed.
- **따라서 크기 Shortcut 재발 문제를 완전히 해결했다고 말할 수 없으며**, 특히 B·8의 특정 크기 개입 취약성이 잔존한다. 모든 후보는 최종 모델로 **채택 보류**.
- 가장 낮은 초점 클래스 최대 Family flip은 **40% / 28% (21.88%)**이지만 공식 Val 95.94%이므로 기존 사전 Gate 기준 30% / 28%보다 낮게 순위화됐다.
- 크기와 함께 질량·횟수·획 폭도 변화하므로 단일 Size 값만으로 발생한 오류라고 확정할 수 없음.

### 최종 교차 데이터 진단 — 평가만, 새 학습 없음 (사전 선언)

Hand-made만을 여러 번 사용한 탐색의 과적합 위험을 점검하기 위해, 완료된 78개 중 **사전 Gate 합격 9개 후보와 기존 CoM 통제**를 모두 **Official Validation에 대한 0.8~1.2배 규모 개입**으로 별도 평가한다. 이 감사는 **새로 학습하지 않고 모델 가중치를 고정**하며, 78개 조합의 사전 Gate 기준을 사후 수정하지 않는다.

- OfficialVal 19,200장을 각 배율에 따라 변형한 뒤 CoM, 기존 모델에 입력.
- 숫자/문자 Family flip 및 평균 절대 `ΔP(letter)`, B↔8·D↔0·F↔5 클래스별 전환, 기본 정확도 변화.
- 기존 Original Test/교수님 Test는 사용하지 않음.
- 이 진단에서 이상이 발견되면 **모델 채택을 보류**하고 전체 연구 결과에서 한계로 명확히 기록한다.

- **일반화에 관한 한계:** OfficialVal은 새로운 Test가 아니라 이미 반복 사용한 개발 Validation이므로 새 작성자에서의 일반화 보증은 아니다.
- **크기 Shortcut 완전 소멸을 주장할 수 없음:** Hand-made 8(0.8배) 26.46% 및 B(0.8배) 25.62% Family flip 잔존. 원본 Training의 Size·Width·Mass 분포를 클래스별로 완전히 동일하게 만드는 방식도 아님.
- **최종 모델 채택 보류:** 사전등록 Gate 통과 최상위는 30% / 28%이지만 원래 공식 Val **97.30%** 목표를 달성하지 못하며, 특정 혼동 클래스의 잔존 민감도가 있음.
- **30% / 42%는 차선 후보:** OfficialVal 평균 96.13%로 30% / 28% 대비 단 **0.047%p 차이**. 3 Seed별 우위 방향은 일치하지 않으며, Hand-made 숫자·문자/Flip은 30% / 42%가 약간 유리함. 두 후보의 최종 채택은 새로운 Writer 평가 없이 확정하지 않음.

### 전체 연구 결론

**Training 전용 클래스별 균형 Scale Augmentation + 약한 topology 보존 Stroke Augmentation + 모든 입력 CoM 정렬**로, 원본 MLP에서 숫자·문자를 글자 크기로 구별하던 강력한 Shortcut 행동을 Hand-made 및 Official Validation 두 개발 데이터에서 현저히 감소시켰다. 

그러나 **크기를 판단 기준으로 절대로 사용하지 않는다는 보장은 아직 얻지 못했다.** 크기를 조절할 때 픽셀 질량과 획도 바뀌며 특정 클래스 Family flip이 남는다. 따라서 실제 결과에는 **Shortcut 강하게 완화**, **완전 제거 불확정**, **공식 Validation 목표 미달**, **최종 모델 교체 보류**를 분명히 표기한다.

- 미공개 Original Test 및 교수님 Test **열지 않음**.
- `main`·현재 최종 모델 **변경하지 않음**.
- 모든 78개 신규 모델과 공식 Val 개입 검증 CSV/NPZ 및 Seed별 체크포인트는 성공한 GitHub Actions Artifact에 원본 보존. 체크포인트 SHA256은 원본 EXP유006 통제 검증으로 추적 가능하며, 모든 신규 모델 상태는 실험 브랜치에만 기록함.
