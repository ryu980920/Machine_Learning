# EXP유017 — 80-14 고정 MLP 하이퍼파라미터 최적화

**사전 등록:** 2026-11-16. EXP유016까지는 두 후보 70-0/80-14를 모두 동결하였고, 이번 실험은 사용자가 고른 **80-14**를 중점으로 수행한다. 다른 증강 비율과 CoM/Size 조합은 탐색하지 않는다.

## 1. 가장 중요한 분할 규칙

- Official Train 76,800장만 MLP 가중치 학습에 사용한다. 입력은 **80%만 클래스 균형 BBox 목표 (16·18·20·22·24px) 증강 → 같은 대상에 획 팽창/침식 픽셀 혼합 강도 14%(Topology 검사) → CoM**, 나머지 20%는 CoM만 적용한다.
- **Official Validation 19,200장**만 하이퍼파라미터 선택에 사용한다. 모든 배율 개입은 원본 OfficialVal의 **0.8·0.9·1.0·1.1·1.2배 변형 → CoM**으로 정의한다. 원본과 변형을 서로 섞어 학습하지 않는다.
- **팀원이 모은 손글씨(기존 Hand-made 포함)에는 최적화 도중 절대 접근하지 않는다.** 최종 최적화가 모두 끝나고 학습 코드·하이퍼파라미터·가중치가 동결된 이후 따로 Validation한다.
- Original Test 및 교수님 Test는 전체 실험에서 사용하지 않는다. 기존 70-0의 체크포인트도 수정하지 않는다.

## 2. 탐색 변수와 범위

현재 EXP유016 원본 80-14 기준 MLP는 sklearn MLPClassifier 기본값: `hidden_layer_sizes=(100,)`, ReLU+Adam, `alpha=0.0001`, `learning_rate_init=0.001`, `max_iter=200`, `early_stopping=False`, 학습 Seed 42·43·44.

**1차 구조/규제 탐색:** 은닉층 후보 `(100,)`, `(128,)`, `(192,)`, `(256,)`, `(128,64)`, `(256,128)` × 규제/학습률 3종 `(alpha,LR)=(0.0001,0.001),(0.001,0.001),(0.01,0.001)`, 그리고 구조 `(128,),(192,),(128,64),(256,128)`에 `(0.001,0.0005),(0.001,0.002)` 추가. 합계 **26개 HP 조합 × Seed 42·43·44 = 78개 신규 MLP**. 모두 ReLU/Adam/max_iter=200/조기 종료 False 고정.

**2차 미세 조정:** 1차 순위에서 통과 조건과 최악 Shortcut 위험을 기준으로 사전에 정의한 규칙으로 최대 4개 구조를 선정하고, 기존 1차 탐색값 주변에서 추가 학습률 및 정규화 조합과 `early_stopping=True` 옵션을 비교한다. 새 모델은 별도 3 Seed로 재실행한다. 실험 중 팀 손글씨 결과를 보거나 사용하지 않는다.

## 3. 원본 Validation Shortcut 보호 규칙 (선택 전에 고정)

비교 기준은 **기존 동결 80-14 세 Seed**, 신규 MLP는 3 Seed 평균으로 평가한다.

1. **16개 클래스×(0.8·1.2)** 변화에서 **각 클래스의 숫자·문자 Family Flip 평균 최대 ≤25%**.
2. 특히 **8·B·D의 0.8·1.2 최악 전환율 ≤20%** 및 Seed별 최악 ≤30%. 기존 80-14는 OfficialVal D×1.2 ≈25.56%로 이 항목에 탈락한다.
3. 숫자 전체×1.2, 문자 전체×0.8 Family Flip 평균 각각 ≤10%. `P(letter)=ΣP(A..F)`의 절대 변화도 각각 ≤0.12.
4. 새 모델 OfficialVal 1.0 정확도는 **기존 80-14 94.8108%보다 0.5%p 넘게 하락하면 탈락**. 목표는 **97.30%**, 달성 못하면 미달로 보고한다.
5. 범주별 정확도(숫자·문자), 모든 확대·축소 배율의 16-class 정확도, 오분류쌍 B↔8·D↔0·F↔5도 기록한다. Flip이 낮다고 반드시 정답인 것은 아니다.

**선정 순서:** 안전 Gate 전부 통과 → OfficialVal 정상 정확도 최대 → B·8·D 최악 Flip 최소 → 16개 클래스 최악 Flip 최소. 통과 조건이 없으면 ‘최종 채택 없음’으로 표시하고 가장 나은 Pareto 후보를 비교만 한다. 성공했다는 가정을 하고 최종 채택하지 않는다.

## 4-1. 실험 설계 당시의 판단과 하이퍼파라미터별 변경 이유

### 해결하려던 문제와 비교 기준

EXP유016의 80-14는 Training에서 크기·획 증강으로 필체 다양성을 늘린 모델이지만, **OfficialVal 정상 정확도 94.8108%**, **D×1.2에서 숫자·문자 계열 판단 전환율 25.56%**로 취약 클래스의 크기 민감도가 남아 있었다. 이번 EXP유017의 질문은 다음 두 가지다.

1. **전처리를 더 바꾸지 않고 MLP 자체의 학습 설정을 변경하면 정상 정확도가 높아지는가?**
2. **동시에 확대·축소로 숫자↔문자 판단이 뒤집히는 문제, 특히 B·8·D를 악화시키지 않는가?**

전처리까지 변경하면 개선 원인을 구분하기 어렵기 때문에 80-14 및 CoM을 고정하였다. 모든 후보는 **동일 Official Train 76,800장**을 사용해 학습하고 **동일 OfficialVal 19,200장**에서 Seed 42·43·44 평균으로 비교한다. Hand-made는 하이퍼파라미터의 탐색·선택에 사용하지 않았다.

### 어떤 항목을 왜 탐색했는가

| 변경 대상 | 기존 설정 | 탐색의 목적(사전 설계 가설) | 평가로 확인할 항목 |
|---|---|---|---|
| 은닉층 너비·깊이 | \`(100,)\` | 크기·획·필체 변화가 다양한 16클래스의 복합 패턴을 표현할 여지를 늘린다. 단순 확대가 언제나 좋다는 가정은 하지 않는다. | OfficialVal 정확도와 16클래스·B8D 크기 변화 |
| L2 정규화 \`alpha\` | \`0.0001\` | 복잡해진 모델의 지나치게 큰 가중치에 페널티를 부여해 특정 특징에 과도하게 의존하는 현상을 완화할 가능성을 검증한다. | 정확도 및 Family Flip의 동시 변화 |
| Adam 초기 학습률 | \`0.001\` | 다른 수렴 경로·속도가 정답 분류 및 크기 변화 안정성에 미치는 영향 확인 | 정확도, 크기 Flip, 실제 학습 반복 수 |
| Early Stopping | \`False\` | 내부 검증 점수로 학습을 일찍 종료하면 과적합 가능성을 완화하는지 확인 | OfficialVal 정확도, Flip, 반복 수 |

**주의:** 위의 표현 능력·과적합·픽셀 의존성은 하이퍼파라미터를 변경한 **이론적 동기**이며, EXP유017에서 개별 뉴런·가중치·입력 민감도를 직접 분석해 메커니즘을 증명한 것은 아니다. 이 실험이 입증한 것은 후보 간 **실측 정확도 및 크기 안정성 차이**다.

### 실험 시작 전에 정한 모델 선정 Gate

핵심 지표인 **Family Flip**은 같은 이미지의 크기를 변경했을 때 \`P(letter)=ΣP(A..F)\`가 0.5를 가로질러 **숫자/문자 계열 판단이 바뀌는 비율**이다. 이는 16-class 정확도나 \`7→9\`처럼 숫자끼리의 혼동과 **다른 지표**다.

| 항목 | 사전등록 상한·하한 | 설정 목적 |
|---|---|---|
| OfficialVal 1.0배 정확도 | **94.3108% 이상** (기존 94.8108%에서 0.5%p 이내 하락) | Shortcut만 억제하고 정상 분류 성능을 지나치게 희생하지 않기 위한 최소선 |
| B·8·D 최악 Family Flip(0.8·1.2배, 3-Seed 평균) | **20% 이하** | 기존 25.56%가 나타난 취약 클래스 우선 보호 |
| B·8·D 개별 Seed 최악 Flip | **30% 이하** | 평균만 좋고 특정 Seed에서 심하게 무너지는 조건 제외 |
| 16개 클래스 전체 최악 Family Flip | **25% 이하** | B·8·D 외 클래스의 계열 판단 붕괴 방지 |
| 숫자 전체×1.2 / 문자 전체×0.8 Flip | **각 10% 이하** | 두 계열의 확대·축소 반응 안정성 확인 |
| 같은 조건의 \`P(letter)\` 평균 절대 이동 | **각 0.12 이하** | 최종 0/1 계열 판단이 같더라도 확률이 크게 흔들리는 조건 제외 |
| 정상 OfficialVal 숫자 정확도 / 문자 정확도 | **각 85% 이상** | 전체 평균에 가려진 계열별 성능 저하 방지 |
| OfficialVal 목표 | **97.30%** | 달성 여부는 별도로 보고; 미달해도 다른 모든 Gate를 만족한 후보 중 최상을 선정 |

**선정 순서는 사전 고정**하였다. ① Gate 전체 통과 여부 → ② 통과 모델 중 OfficialVal 1.0배 정확도 내림차순 → ③ 동률이면 B·8·D 최악 Flip 최소 → ④ 다시 동률이면 전체 16클래스 최악 Flip 최소. 따라서 **정확도만 가장 높은 모델을 뽑지 않는 규칙**이었다.


## 5. 1차 26조건×3 Seed (78개 MLP) 실측 완료 — 2026-11-16

[원본 모델 학습 Run #43833188106](https://github.com/ryu980920/Machine_Learning/actions/runs/43833188106)의 **9개 Train job 전부 success**. 해당 Run의 집계 job은 문서 출력 시 `pass_all_gates` / `passes_all_gates` 오타로 실패했으나 학습 데이터/모델/측정에는 영향 없었다. 코드를 수정한 후 **재학습 없이** [집계 전용 Run #43836060651](https://github.com/ryu980920/Machine_Learning/actions/runs/43836060651)에서 전체 26조합 3-Seed를 정상 집계했다.

- **Gate 전체 통과: 2 / 26조건**.
- **1위:** 은닉층 **(256,128)**, ReLU/Adam, `alpha=0.01`, `learning_rate_init=0.001`, `max_iter=200`, 3-Seed OfficialVal **96.4358%**, B·8·D 최악 **18.14%**, 전체 16클래스 최악 **18.14%**.
- **2위:** 은닉층 **(256,128)**, `alpha=0.0001`, `learning_rate_init=0.001`, OfficialVal **96.3385%**, B·8·D 최악 **18.81%**.
- 이전 EXP유016 80-14 `MLPClassifier()` 기본 은닉층 (100,), `alpha=0.0001`, OfficialVal **94.8108%**, B·8·D 최악 **25.56%**. 1차 현재 상위 설정은 OfficialVal 약 **+1.625%p** 및 B·8·D 최악 **−7.42%p** 개선.
- **97.30% OfficialVal 목표는 여전히 미달**, 크기 Shortcut 소멸 입증 아님.

**2차 입력으로 사전 순위 규칙에 의해 서로 다른 네 은닉층 선택:**
1. (256,128), alpha=.01, LR=.001 (Gate 통과)
2. (128,), alpha=.01, LR=.001 (1차 Gate 미달 — 경계 탐색)
3. (192,), alpha=.001, LR=.0005 (1차 Gate 미달 — 경계 탐색)
4. (128,64), alpha=.01, LR=.001 (1차 Gate 미달 — 경계 탐색)

2차에서는 각 구조당 alpha×0.3, alpha×3, LR×0.7, LR×1.4, `early_stopping=True` 총 5조건을 Seed 42/43/44에서 평가한다. **전체 20조건×3Seed=60개 신규 MLP**. Team Hand-made 데이터는 학습·모델선택에 사용하지 않는다. [2차 학습·최종 집계 Run #43836257716](https://github.com/ryu980920/Machine_Learning/actions/runs/43836257716).

### 5-1. 1차 탐색: 은닉층 구조 확장과 정규화 범위의 선정 과정

1차 탐색은 **6개 구조 × 3개 alpha = 18조건**, 여기에 **4개 구조 × 2개 추가 학습률 = 8조건**, 총 **26조건×3 Seed=78모델**로 구성하였다.

- **구조:** \`(100,)\`, \`(128,)\`, \`(192,)\`, \`(256,)\`, \`(128,64)\`, \`(256,128)\`. 한 층의 폭만 넓히는 경우와 은닉층을 하나 더 두는 경우를 함께 비교하기 위한 설계다.
- **기본 alpha:** \`0.0001 / 0.001 / 0.01\`; 학습률은 \`0.001\`로 고정. 구조가 바뀌어도 규제 강도가 최적점에 영향을 주는지 탐색했다.
- **추가 학습률:** \`(128,)\`, \`(192,)\`, \`(128,64)\`, \`(256,128)\`에서 \`alpha=0.001\`로 고정하고 \`0.0005 / 0.002\`를 비교. 너무 빠르거나 느린 업데이트가 안정성에 미치는 영향을 살폈다.
- **공통 고정:** ReLU, Adam, \`max_iter=200\`, \`early_stopping=False\`, 동일 전처리·데이터·3 Seed.

**결과:** 26조건 중 안전 Gate **2조건만 통과**, 두 조건 모두 \`(256,128)\`이었다.

| 1차 Gate 통과 설정 | OfficialVal | B·8·D 최악 Flip | 해석 |
|---|---:|---:|---|
| \`(256,128)\`, alpha=0.01, LR=0.001 | **96.4358%** | **18.14%** | 1차 1위: 정확도·안정성 동시 우수 |
| \`(256,128)\`, alpha=0.0001, LR=0.001 | 96.3385% | 18.81% | 1차 2위: 동일 구조에서 alpha 변화의 영향 관찰 |
| 기존 \`(100,)\`, alpha=0.0001, LR=0.001 | 94.8108% | 25.56% | 새 Gate 미통과 기준 모델 |

따라서 **\`(256,128)\` 자체는 여러 구조의 비교 결과로 선택**했고, 그 구조에서 alpha를 더 탐색할 근거가 생겼다. \`(256,128)\`가 더 많은 특징을 표현한다는 설계 의도와, 실제로 이 구조가 최고 성능이었다는 사실을 구분한다.

**2차 실험에 넣은 네 구조의 선정 로직:** 1차 결과를 (a) Gate 통과 모델은 높은 정확도순, (b) 미통과 모델은 실패 Gate 수가 적고 B8D Flip이 낮은 순으로 정렬한 뒤, **서로 다른 은닉층 구조 4개**를 순서대로 뽑았다. 그 결과 \`(256,128)\`, \`(128,)\`, \`(192,)\`, \`(128,64)\`가 선정됐다. **앞의 구조만 Gate 통과**, 나머지 3개는 1차 안전 기준을 만족하지 못했지만 조정 여지가 있는 구조를 추가로 살펴보기 위한 비교 대상이었다. 이들을 1차 합격 모델로 오해하지 않는다.

### 6-1. 2차 미세 탐색: 1차 최고 설정 주변에서 한 변수씩 변경

2차에서는 1차에서 선정한 **서로 다른 4개 구조** 각각에 아래 **5가지 수정**을 적용했다. 구조마다 5조건 × 3 Seed를 학습하므로 **20조건×3 Seed=60모델**이다. 1차 우승 구조 \`(256,128)\`의 시작점은 **alpha=0.01, LR=0.001, Early Stopping=False**다.

| 수정 실험 | 우승 구조에서의 적용값 | 시험 이유 |
|---|---|---|
| \`alpha_down\` | alpha **0.003** | L2 규제를 약하게 했을 때 정확도·Flip 변화 확인 |
| \`alpha_up\` | alpha **0.03** | L2 규제를 강화했을 때 정확도·Flip 변화 확인 |
| \`lr_down\` | LR **0.0007** | 업데이트 폭 감소의 효과 확인 |
| \`lr_up\` | LR **0.0014** | 업데이트 폭 증가의 효과 확인 |
| \`early_stopping\` | **True** (alpha=0.01, LR=0.001) | 내부 검증을 이용한 조기 종료 효과 확인 |

\`early_stopping=True\` 실험만 \`max_iter=260\`, \`n_iter_no_change=15\`, \`validation_fraction=0.1\`을 사용하였다. 나머지는 \`max_iter=200\`, Early Stopping False를 유지했다. 그러므로 Early Stopping 조건의 비교에는 조기 종료 외에 **최대 반복 수 차이도 포함**된다. Early Stopping만의 인과 효과라고 단정하지 않는다.

#### 1차 우승 구조 \`(256,128)\`의 2차 실제 결과

| 후보 | OfficialVal 1.0배 | B·8·D 최악 Flip | 사전 Gate | 판단 |
|---|---:|---:|---|---|
| 1차 기준: alpha=0.01, LR=0.001 | 96.4358% | 18.14% | 통과 | 2차 실험의 기준점 |
| \`alpha_down\` (0.003) | 96.2691% | 23.08% | **탈락** | 규제 완화 시 정확도·B8D 안정성 모두 저하 |
| **\`alpha_up\` (0.03)** | **96.5365%** | **16.67%** | **통과** | **2차 최종 선정** |
| \`lr_down\` (0.0007) | 96.3646% | 21.42% | **탈락** | B8D 20% 기준 초과 |
| \`lr_up\` (0.0014) | **96.5521%** | 21.69% | **탈락** | 최고 정확도지만 B8D 20% 기준 초과 |
| \`early_stopping=True\` | 96.4757% | 18.58% | 통과 | 합격했으나 alpha_up보다 정상 정확도 낮음 |

**alpha를 0.01 → 0.03으로 높인 이유와 근거:** 더 큰 MLP의 가중치에 강한 규제를 부여하면 특정 입력 패턴에 지나치게 의존하는 경향을 줄일 가능성이 있다고 판단해 alpha×3을 시도했다. 실제로 **동일 구조·동일 LR·동일 Early Stopping 조건**에서 OfficialVal은 **+0.1007%p**, B8D 최악 Flip은 **−1.47%p**로 개선됐다. 이것은 **관측된 성능 차이**이며, 가중치 크기나 특정 픽셀 의존성이 실제로 감소했다는 내부 메커니즘은 이번 실험에서 직접 측정하지 않았다.

**LR을 0.001로 유지한 이유:** LR 0.0014는 정확도만 보면 alpha=0.03보다 **0.0156%p 더 높았지만**, B8D 최악 Flip이 **21.69%**로 사전 Gate를 위반했다. 반대로 LR 0.0007도 21.42%로 기준을 넘었다. 따라서 이 구조에서 학습률 변경 조건을 최종 선정하지 않았다. 학습률이 일반적으로 클수록 항상 불안정하다는 뜻은 아니다.

**Early Stopping을 끈 이유:** True 모델은 Gate를 통과했지만 OfficialVal **96.4757%**로 alpha=0.03 모델의 **96.5365%**보다 낮았다. 사전에 정한 **'Gate 통과 후 정상 정확도 최대'** 규칙을 적용해 False를 유지했다. Early Stopping 자체가 무효하다고 결론 내린 것은 아니다.
