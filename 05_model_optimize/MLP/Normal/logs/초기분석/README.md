# 초기분석 — 가설 A·B 설정

## 검증 목적

기존 Normal MLP가 공식 MNIST·EMNIST에서는 높은 정확도를 보이지만 팀원 Hand-made에서는 정확도가 떨어지는 이유를 탐색한다.

- **가설 A:** 유사한 숫자와 문자를 모델이 어떤 특징으로 구별하는가? 획의 형태·곡선·연결 구조에 대한 판단이 충분한가?
- **가설 B:** 모델이 이미지의 **절대 위치·명암·획 굵기·크기** 변화에 민감한가?

## 실험 목록

1. **[EXP유001 — Pixcel Attribution](EXP유001_Pixcel_Attribution.md):** 정상·오분류 실제 이미지 **98장**의 Integrated Gradients로 픽셀 기여도 초기 관찰. 가설 A/B 설정.
2. **[EXP유002 — Input Sensitivity](EXP유002_Input_Sensitivity.md):** 기존 MLP 가중치를 고정하고 원본 포함 **21개 변형 조건**, 총 **456,960개 예측**을 분석. 위치·크기 등에 따른 예측 뒤집힘 확인.

## 검증 결과와 다음 연구

초기 실험만으로 형태 학습의 부족과 위치 민감도 중 하나를 유일한 원인으로 단정하지 않았다. 입력 변화 민감도를 확인했으므로 **[가설 B](../가설B/README.md)**의 공간 분포·CoM 실험을 우선 진행하고, 해결되지 않은 문자 정확도 문제는 **[가설 A](../가설A/README.md)**에서 검증한다.

기존 실험 번호·결과·모델은 변경하지 않는다.
