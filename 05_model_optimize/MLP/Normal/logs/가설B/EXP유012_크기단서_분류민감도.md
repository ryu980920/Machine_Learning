## 1. 질문과 사전 계획

**가설 3:** MLP가 B와 8, D와 0, F와 5를 구별할 때 위치와 획 형태 이외에 **입력 글자의 크기**를 판단 단서로 학습한 결과, CoM-only에서는 작은 문자들이 숫자로 오인식되고, Size-only에서는 숫자가 문자로 오인식된다.

**개입 방법:** 완전히 동일한 Hand-made 2,560장을 각각 **0.8배, 0.9배, 1.0배, 1.1배, 1.2배** 등방성 BBox-중심 affine 변환(원본 EXP유006과 동일 SciPy order1/cval0)한 뒤 **CoM(13.5,13.5) 재정렬**. MLP 가중치는 기존 EXP유006 성공 실행의 CoM-only, Size-only, Size→CoM 각 Seed 42/43/44 **9개 모델 그대로 고정**, 체크포인트 SHA256와 기존 정답 수 일치 검증. 모든 샘플에서 true class 확률, 지정 혼동 클래스 확률, 16-class 예측, pair margin=P(true)−P(confuser), 글자 크기/잉크량/CoM 잔여거리/위상 연결 구조 변화를 전수 기록. `scale 1.0`의 입력은 **원본 Hand-made→CoM**이며, Size→CoM 정규화 입력과 다른 조건임을 유의.

## 2. 크기 배율만 변경해도 숫자·문자 정확도 방향이 뒤집힌다

**CoM-only 학습 모델 고정, Hand-made 숫자/문자 정확도, 3 Seed 평균.**

| 입력 원본 대비 크기 | 숫자 정확도 | 문자 정확도 | 실제 숫자를 문자로 예측 | 실제 문자를 숫자로 예측 |
|---|---:|---:|---:|---:|
| 0.8× | 75.31% | 25.00% | 0.31% | **73.37%** |
| 0.9× | 88.23% | 40.90% | 0.54% | **57.92%** |
| **1.0× (원본→CoM)** | **84.42%** | 66.49% | 8.10% | 31.56% |
| 1.1× | 49.06% | 89.79% | **46.75%** | 8.09% |
| 1.2× | 19.06% | **95.35%** | **79.65%** | 0.56% |

**핵심 관찰:** 기존 CoM-only 모델에서 글자를 **확대**하면 문자 정확도가 극적으로 상승하고 숫자가 문자로 오분류되며, **축소**하면 반대 현상이 발생한다. 이는 모델이 *형태에 더해 크기 관련 픽셀 패턴*에도 매우 민감하다는 직접적인 개입 근거다.

**반대로 Size→CoM 학습 모델은 이 크기 반응 방향이 다르게 나타났다**(고정 모델, 같은 원본→scale→CoM 평가).
- 0.8×: 숫자 45.42%, 문자 **91.11%**
- 1.0×: 숫자 83.23%, 문자 82.33%
- 1.2×: 숫자 75.35%, 문자 39.10%

즉, 학습된 전처리 방식에 따라 **어떤 크기에 문자/숫자 점수를 부여하는지가 달라진다**. 위 결과는 개별 클래스 확률을 포함해 `all_scale_response.csv`에 보존되어 있다.

## 3. 동일한 B/8, D/0의 예측 반응 — CoM-only 모델 고정

3 Seed × 클래스당 160장의 평균. *진짜 클래스에 대한 Recall*.

| 실제 클래스 | 0.8× | 1.0× | 1.2× |
|---|---:|---:|---:|
| B | 0.62% | 35.83% | **93.96%** |
| 8 | 53.54% | 73.33% | **2.29%** |
| D | 10.42% | 54.79% | **95.42%** |
| 0 | 90.83% | 81.88% | **2.29%** |
| F | 13.33% | 76.04% | **95.00%** |
| 5 | 73.75% | 77.29% | **10.21%** |

**B·8 지정 경쟁 클래스 확률 차이의 평균 [P(true)−P(confuser)]:**
- **B vs 8:** 0.8× **−0.1573** → 1.0× **−0.0724** → 1.2× **+0.9331**.
- **8 vs B:** 0.8× **+0.5154** → 1.0× **+0.5256** → 1.2× **−0.8366**.
- **D vs 0:** 0.8× **−0.6380** → 1.0× **+0.1394** → 1.2× **+0.9482**.
- **0 vs D:** 0.8× **+0.8757** → 1.0× **+0.6505** → 1.2× **−0.8475**.

**분류 편향:** 이 결과는 '작은 B→8, 큰 8→B', '작은 D→0, 큰 0→D'라는 가설의 핵심 방향과 일치한다. 가설 1(원본 Training의 문자 긴 변24px, 숫자 긴 변20px)과도 정합적이다.

## 4. 형태 연결 구조가 바뀌지 않은 이미지에서도 유지되는가?

스케일 변환은 크기 외에 획 굵기, 보간, 일부 픽셀과 연결 형태도 바꿀 수 있으므로 동일한 이미지에서 **다섯 배율(0.8~1.2) 모두 topology(Euler·연결요소) 지표가 원본과 같은 B/8/D/0/F/5 이미지**만 추가 추출하여 동일 실험 결과를 재집계했다.

- 기존 6개 클래스 × 160장 × 3 Seed = 2,880건 중 **2,142건(74.38%)**이 다섯 배율 모두 topology 지표 유지.
- 해당 집합에서도 CoM-only 모델의 **B Recall은 0.8× 1.01% → 1.2× 97.31%**.
- **8 Recall은 0.8× 54.29% → 1.2× 2.22%**.
- **D Recall은 0.8× 10.57% → 1.2× 97.56%**, **0 Recall은 0.8× 92.42% → 1.2× 2.53%**.
- 같은 집합의 1.2× CoM 잔여 오프셋 최대는 약 1.02px로, 대형 이동이 중심 가정의 주 원인은 아니었다.

**해석:** 단순히 글자가 연결/분리되어서 클래스 판단이 뒤집힌 것만으로 이 효과를 설명하기 어렵다. 하지만 **topology 유지 ≠ 획 굵기·보간 픽셀 불변**이므로 '크기만의 순수 단일 원인'은 아니다. 동시 이동하는 픽셀 변화와 크기 관련 단서를 함께 포착한 결과다.

## 5. 기술적 교란 요인 정량 측정

원본 전체 목표 6클래스(각 배율 480건/클래스), 크기를 바꿀 때 topology 변동률:
- B: 0.8× **28.13%**, 1.2× **17.50%**
- 8: 0.8× **30.63%**, 1.2× **19.38%**
- D: 0.8× **20.00%**, 1.2× **11.25%**
- 0: 0.8× **14.38%**, 1.2× **7.50%**

전체 Hand-made 평균 총 픽셀 밝기 비율은 0.8×에서 약 **0.639**, 1.2×에서 **1.431**로 변했다. 일부 확대·축소에서 topology가 바뀌고 잉크량도 바뀌므로 이를 별도로 통제하지 않은 강한 인과 주장에는 주의해야 한다.

## 6. 가설 3 판정과 다음 연구

**판정:** 고정한 같은 모델의 같은 이미지를 스케일 조절한 결과 예측 방향이 극적으로 역전되었고, 연결 구조가 유지된 이미지만으로도 관찰됐다. **크기 관련 픽셀 패턴이 MLP의 숫자/문자 구분에 강하게 작용한다는 가설을 지지**한다. 원본 6클래스의 크기 차이가 반응 방향과 일치하지만, 추가 실험 없이 단일 '크기만의' 순수 인과효과·가중치 해석으로 단정하지 않는다.

후속 분리 통제로는 ① 크기를 유지하면서 획 굵기를 별도 조절, ② 유사한 픽셀 질량/shape 변화에서 CoM을 유지하는 대조, ③ 실제 Hand-made 새 작성자의 검증이 가능하다. 이번 연구에서는 모델 추천/변경은 하지 않는다.
