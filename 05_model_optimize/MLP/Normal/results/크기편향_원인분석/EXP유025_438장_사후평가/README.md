# EXP025 × 사용자 판독 438장 — 공개용 집계 결과

**분석일:** 2026-11-18  
**연구로그:** [438장 15모델 비교 및 EXP017 유지 결정](../../../logs/크기편향_원인분석/EXP유025_438장_사후평가_모델선정진단.md)

원본 480장 중 사용자 품질 판정으로 42장을 제외한 438장(16클래스)에서, 기존 EXP017 Batch200과 EXP025 Batch32·64·128·256 × Seed42·43·44의 **15개 고정 MLP 모델**을 다시 학습하지 않고 평가했다. 기존 EXP017 Seed42/43/44 정답 381·386·388장이 재현됐으며, 이전 평가의 총 1,314개 분류 결과와 모두 일치한다.
