# 연구 목적별 통합 Notebook

기존 180개 원본 코드의 주제별 55개 Notebook과 최종 모델별 10개 학습·추론 Notebook. 원본 경로/커밋/해시 및 로그 유지. 2차 Fine-Tuning 제외.

[전체 매핑](EXPERIMENT_MAPPING.csv) · [정적 검사](VALIDATION_REPORT.json)

## 사용 순서
1. 연구 목적 Notebook을 선택한다. 원본 코드를 `%%archive_source` 셀로 확인한다. Run All은 등록만 하며 실제 학습하지 않는다.
2. 해당 원본의 고정 커밋 checkout과 승인된 데이터, 원본 CLI 인자를 준비한다. `WORKTREE`, `LOG_DIR`, `RUN_PLAN`을 설정하고 실행을 명시적으로 승인한다.
3. 각 실험은 독립 subprocess로 실행하고 외부 로그를 남긴다. 기존 실험 자료와 새 결과를 구분한다.
4. 최종 모델 Notebook은 `06_Final_Models/Individual/`에서 선택. 기존 private kit 및 원본 가중치 필요. SVC Combined는 C2_G2, KNN Combined는 기존 baseline.

공통 실행 제어만 통합했고, 실험별 함수는 결과 동등성이 검증되지 않은 상태에서 합치지 않았다. 180개 원본의 코드 본문을 포함한다. 176개 원본의 로컬 정적 검사와 추가 4개 원본의 고정 Git blob 해시 대조를 완료했다. 전체 학습/추론 재실행은 미완료.
