## 평가 범위 및 변화

- **16개 클래스:** 숫자 0–9, 대문자 A–F.
- **4-Writer 보류 OOF:** 각 Fold에서 공식 Training 76,800장 + 다른 작성자 3명의 손글씨 1,920장으로 학습, 보류 작성자의 640장으로 평가(4인 합계 2,560장).
- **최종:** 3시드 × 4Fold = 12개 모델의 **평가 평균**; 12개 모델의 확률 평균 앙상블 점수가 아니다.

## 최적화 의사결정

1. 0↔D·8↔B 혼동 분석 → CoM·크기·획 분포의 영향을 비교.
2. 크기 + CoM을 함께 정규화하면 손글씨 OOF 88.9453%까지 개선됐지만 공식 Validation 손실이 발생해 전면적 크기 통일을 유보.
3. **31개 크기·획 증강 조건** 비교에서 Size30%·Stroke28% 선정. 증강 비율을 100%까지 높이는 방식은 정상 정확도와 공식 성능이 하락해 제외.
4. 너비 256개 채택. 추가 층, L2 규제 변경, 학습률 변경 및 종료 방식은 주요 혼동/보호 기준 상충으로 교체하지 않음. 후속 개발 판단에서 Batch 128 사용.
5. Local Warp·Rotation·Shear 추가 변형은 기존 설정을 교체할 근거가 없었으며, 신규 손글씨 480장 보강 또한 작성자 보류 OOF 기준선을 넘지 못해 채택하지 않음.

## 최종 선정 설정 (2026-11-19)

| 항목 | 확정 |
| --- | --- |
| 학습 데이터 | 공식 76,800장 + Fold별 다른 3 Writer 손글씨 1,920장 |
| 공식 학습 증강 | 이미지 30%에 목표 긴 변 16·18·20·22·24 px 균형 배정 및 선택 대상 획 혼합 28% |
| 전처리 | 모든 입력 CoM, 평가 시 CoM 후 /255 |
| MLP | `hidden_layer_sizes=(256,)`, ReLU, Adam |
| L2 alpha | `0.0001` |
| 초기 학습률 | `0.001` |
| 배치 | `128` |
| 종료 | Early Stopping OFF, `max_iter=200`, `tol=1e-4`, `n_iter_no_change=10` |
| 신규 480장 | 최종 학습에 추가하지 않음 |
| 확정 범위 | 모델·학습 구성·평가 규칙, 보존된 CV 가중치 |

주요 네 혼동 방향 각각 5% 미만의 목표는 달성하지 못했다. Batch 128이 최초 안전 가드레일을 통과한 것으로 소급 표시하지 않는다. **새 단일 전체 학습용 최종 추론 가중치 또는 12모델 앙상블을 생성·배포하지 않았으며**, Original Test와 교수님 Test는 사용하지 않았다.
