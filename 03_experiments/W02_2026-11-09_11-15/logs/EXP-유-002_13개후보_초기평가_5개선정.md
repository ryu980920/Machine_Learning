## 1. 문제 발견 및 실험 목적

- **질문:** W01에서 이론적으로 비교한 모델 중 어느 후보가 16개 클래스 손글씨 분류에서 높은 정확도와 현실적인 학습·추론 시간을 보이는가?
- **판단 필요성:** 이론만으로 3~4개를 미리 정하면 다른 후보의 실제 성능과 시간 비용을 검증하지 못한다. 교수님 피드백에 따라 **짧은 초기 학습 결과로 후보를 선정한 근거**를 남긴다.
- **실험 범위:** W01의 **13개 후보 항목**(SVC는 이번에는 기본 RBF만 수행; 다른 커널은 별도 실험 아님). 모델당 1회, 기본 Hyperparameter 기준. OvR Logistic Regression은 `OneVsRestClassifier` 래퍼로 구현.

## 2. 방법 및 공통 조건

| 항목 | 이번 실행에 적용된 조건 |
|---|---|
| 입력 데이터 | `02_data/datasets/MNIST_EMNIST_official_split_112000.npz` (최종 v3, SHA256 `0e9570d0eb04c0c1da99d043b85bfdab7f3b639eebe4b10335b05b57ad671879`) |
| 원래 공식 데이터 | Training 96,000장 / 공식 Test 16,000장(**사용 안 함**) |
| 분할 | 원본·증강본의 그룹을 고려한 `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)`의 첫 분할 → Train 76,800장·Validation 19,200장 |
| 빠른 실험용 추출 | Train **12,000장(16종×750)**, Validation **3,200장(16종×200)**; 각 후보에 동일 이미지·레이블 적용 |
| 추출 Seed | Train 42, Validation 43; 그룹 중복 0 확인 |
| 입력 | 28×28 흑백, Flatten → 784 features, `float32` |
| 기본 전처리 | 선형·SVC·KNN·MLP 계열에 픽셀 `/255` 적용, 트리·앙상블은 원본 픽셀값; 모델별 스케일링 여부 CSV에 기록 |
| 모델 설정 | scikit-learn **기본 Hyperparameter**, 재현을 위한 `random_state=42`만 가능한 모델에 지정. OvR·SVC(RBF) 등 방식 지정은 구현상 필요 |
| 실행 | 13개 후보 각각 1회, 실행 상한 95초; 모두 실행 성공. CPU 스레드 환경변수 `OPENBLAS/OMP/MKL/NUMEXPR=2` |
| 평가 | 동일 Validation의 Accuracy, Macro F1, 전체 3,200장 `predict` 시간, `fit` 시간, 수렴 경고 |
| 환경 | Python 3.13.5, scikit-learn 1.8.0, NumPy 2.3.5 |
| 추가 데이터 | 공식 Test 16,000장 및 Hand-made 2,560장은 **13개 후보 초기 선정에 사용하지 않음** |

**중요:** 이 단계에서는 Hyperparameter Grid Search, 본격 Preprocessing 탐색, 공식 Test 평가 및 Hand-made 추가 학습을 수행하지 않았다. 계산 시간은 단일 실행값이므로 모델의 안정적인 평균 속도로 일반화하지 않는다.

**실행 과정:** (1) v3 SHA256 및 96,000장 원본 검증 → (2) 증강 원본 그룹을 기준으로 Train/Validation 분할 → (3) 16개 클래스별 고정 표본 추출 → (4) 13개 모델 각각 기본 설정으로 `fit` 및 `predict` → (5) 성능·시간·경고·클래스별 결과 CSV 생성 → (6) threshold 및 모델 계열 중복을 근거로 5개 선정.

**재현 방법:** 저장소 루트에서 `python 02_data/notebooks/W02_13_candidates/prepare_subset.py --official 02_data/datasets/MNIST_EMNIST_official_split_112000.npz` 실행 후 `python 02_data/notebooks/W02_13_candidates/run_13_candidates.py --all --timeout 95`. 코드가 생성하는 `common_subset.npz`는 원본 데이터로 재생성 가능하므로 이 GitHub 기록에 중복 업로드하지 않는다.

### 평가 지표 계산 검증

`accuracy_score(y_val,y_pred)`와 `f1_score(y_val,y_pred,average='macro',labels=list(range(16)),zero_division=0)`를 각각 계산했다. 실제 분할에는 클래스당 **200장**이 동일하게 들어 있다. Confusion Matrix 대각선 합/3,200으로 Accuracy를, 클래스별 F1의 산술평균으로 Macro F1을 독립 검증했으며 기록값과 일치한다. **두 지표가 매우 비슷한 것은 오류가 아니라 균형 표본 및 유사한 클래스별 Precision·Recall 특성에 따른 결과**다. 클래스별 수치는 별도 CSV에 보존했다.

**특이사항:** Softmax Regression의 기본 `max_iter=100`에서 `ConvergenceWarning`이 발생했다. 기록된 정확도는 측정값이지만 수렴 완료 성능으로 해석하면 안 된다. SVC의 RBF 이외 커널은 초기 실험 대상이 아니었다.

## 4. Threshold 90% 적용 및 5개 후보 선정

- **1차 기준:** 동일 Validation에서 Accuracy **90% 이상**인 후보를 통과시킨다. 통과: **SVC(RBF) 95.16%, HistGradientBoosting 94.53%, MLP 94.13%, Extra Trees 94.06%, Random Forest 93.72%, KNN 92.53%** (6개).
- **2차 기준:** Random Forest와 Extra Trees는 모두 트리 앙상블 기반이므로, 같은 계열을 두 모델 모두 남기지 않는다는 **후보 다양성 기준**을 적용한다. 그중 이 예비 실험에서 더 높은 Accuracy와 더 짧은 학습 시간을 보인 **Extra Trees를 유지**한다. 이는 Random Forest가 성능이 낮아 실패했다는 뜻이 아니다.
- **KNN 유지 이유:** 정확도 92.53%로 Threshold를 통과했고, `fit` 시간 **0.010초**로 가장 짧다. 다만 훈련 예제를 저장하는 방식이므로 추론 시간 **1.176초/3,200장**은 다른 후보보다 느릴 수 있어 **학습 속도와 추론 속도를 반드시 구분**한다.

**후속 비교 대상 5개 모델**

| 후속 후보 | Validation Accuracy | 선정 근거 및 관찰할 과제 |
|---|---:|---|
| **SVC (RBF)** | **95.16%** | 1위 정확도; 8.660초/3,200장의 높은 추론 비용 |
| **HistGradientBoosting** | **94.53%** | 2위 정확도; 약 80.98초의 학습 비용 |
| **MLP** | **94.13%** | 높은 정확도 및 빠른 추론; 수렴·반복 수 최적화 |
| **Extra Trees** | **94.06%** | 트리 앙상블 대표; Random Forest와 중복 최소화 |
| **KNN** | **92.53%** | 가장 빠른 `fit`; 비교적 느린 추론 시간을 함께 검증 |

**이번에 제외된 8개:** Random Forest(계열 중복), Logistic Regression OvR, Softmax Regression, LinearSVC, SGDClassifier, Perceptron, Decision Tree, AdaBoost(마지막 7개는 정확도 90% 미만). 제외는 **이 초기 데이터 규모·기본 설정 조건에서의 후보 선정**이며 최적화 가능성이 없다는 뜻은 아니다.

## 5. 최종 판단 및 다음 단계

- **해결한 질문:** 13개 후보를 실측 비교했으며 정확도 Threshold 90%와 계열 중복 제한을 근거로 **5개 모델 선정 완료**.
- **미완료:** 선정된 5개 모델의 Hyperparameter 변경·Preprocessing 비교, 반복 Seed 측정, Normal/Combined(Hand-made 추가 학습) 비교, 최종 모델 1개 선정 및 공식 Test 평가는 **이 실험 범위 밖**이다.
- **후속 원칙:** 5개 모델 모두 동일한 본 학습/Validation 분할로 Baseline과 최적화를 비교한다. 정확도와 Macro F1뿐 아니라 추론 시간을 함께 기록하고, 최적화 후 상위 모델 성능이 근접하면 두 모델을 병행 Fine-tuning한다. Hand-made 추가 학습 시 학습에 포함한 손글씨와 같은 평가 이미지는 겹치지 않도록 관리한다.
