## 1. 이번 주 목표

W01에서 선정한 세 모델을 **독립적으로 학습**하여, 동일한 검증 기준에서 초기 성능을 비교한다. 우선순위는 공통 데이터·평가 조건 확보이며, 지나친 Hyperparameter 최적화는 이후 단계로 분리한다.

## 3. 공통 비교 기준

- **동일한** Training/Validation 데이터셋, 버전, 레이블 맵과 분할을 사용한다.
- 입력은 28×28 Grayscale 이미지를 784개 특성으로 변환한다.
- Accuracy, Macro F1, Confusion Matrix, 학습 시간, 예측 시간을 보고한다.
- 모델별 Hyperparameter·Seed·수렴 상태·라이브러리 버전과 적용 전처리를 모두 기록한다. 필요하면 LinearSVC/MLP에 적절한 스케일링을 적용하되, 그 차이를 명시한다.
- 교수님 배포 데이터 및 테스트 전용 Hand-made는 학습·튜닝하지 않는다.
- 중복·증강 데이터 품질 검증이 완료되지 않았다면 해당 한계를 명시하고 임의로 '확정 데이터셋'으로 표시하지 않는다.

## 4. W01 미완료 사항의 이관

데이터 중복 검수 및 증강 품질 검증이 완료되지 않았다면 해당 과제를 병행하거나 선행 처리해야 한다. **추론 전처리 파이프라인 비교는 모델 선정 이후 W02 또는 후속 주차 과제로 검토**하며, 이번 주의 모델 초기 비교와 섞어서 성능 개선 원인을 단정하지 않는다.
