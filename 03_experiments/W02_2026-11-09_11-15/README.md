## 1. 연구 목표와 변경 사항

**여러 알고리즘의 빠른 1차 실험 → 실제 성능으로 4개 모델 선정 → 4개 모델 각각 전처리·Hyperparameter 개선 → 성능·추론 시간 비교 → 필요 시 상위 2개 동시 Fine-tuning → 최종 모델 1개 결정.**

W01에서 검토한 **13개 후보 항목 모두를 초기 예비 평가 대상으로 확정**한다. 이전에 정한 **LinearSVC, RandomForestClassifier, MLPClassifier**에 **KNeighborsClassifier(KNN)**를 추가한 조합은 현재의 **우선 검토 4종**으로 둔다. 이는 **최종 성능 검증 전의 잠정 후보**이며, 초기에 다른 알고리즘도 소규모로 비교해 **왜 해당 네 모델을 남기는지**를 수치로 설명한다. W01의 이론적 선정 결과를 실제 성능 평가 완료로 간주하지 않는다.

| 이전 W02 계획 | 수정된 방향 |
|---|---|
| 사전 지정 3개 모델의 기본 성능 확인 | **W01의 13개 후보를 모두 간단히 평가**한 수치로 **4개 모델 선정** |
| 초기 성능에 따라 1개 모델 우선 선정 | **선정된 4개 모두** 전처리·Hyperparameter 개선 실험 |
| Accuracy 중심의 러프한 비교 | 성능 외에 **추론 시간, 수렴 여부, 반복 실행 안정성** 확인 |
| 최적화는 선정 후에 1개에 집중 | **최적화 후 최종 1개 선정**; 상위 2개가 근접하면 **동시 Fine-tuning** |
| Hand-made를 전부 테스트 전용으로 제한 | 교수님 요구에 맞춰 **Normal Dataset vs Combined Dataset** 학습 비교. 단, 추가 학습과 평가는 겹치지 않게 분할 |

## 2. 단계별 실험 계획과 완료 기준

### 단계 A — 기존 13개 후보 전수 빠른 예비 평가 (범위 확정)

**예비 평가 대상은 W01에서 이론적으로 검토한 아래 13개 항목 모두로 확정**한다. 이 중 Logistic Regression OvR·Softmax는 같은 선형 계열의 서로 다른 방식이고, SVC의 여러 커널은 하나의 후보 항목에 묶여 있다. 따라서 **13개 항목 ≠ 서로 독립적인 알고리즘 13종**이다.

| 번호 | W01의 예비 평가 후보 | 예비 실험 메모 |
|---:|---|---|
| 01 | Logistic Regression + OvR | `OneVsRestClassifier` 등 구현 방식 기록 |
| 02 | Softmax Regression | 다중 클래스 Logistic Regression의 공동 확률 모델 |
| 03 | SGDClassifier | 사용 `loss`와 반복 제한을 명시 |
| 04 | LinearSVC | 수렴 경고, `max_iter` 기록 |
| 05 | SVC (linear / polynomial / RBF) | **한 후보 항목**; 초기에는 대표 커널 하나를 정해 기록하고, 다른 커널 비교 시 별도 실행 행으로 기록. 계산 시간에 유의 |
| 06 | KNeighborsClassifier (KNN) | `fit`보다 **예측 시간** 및 메모리 사용을 중요하게 기록 |
| 07 | DecisionTreeClassifier | 단일 트리 기본 성능·과적합 여부 |
| 08 | RandomForestClassifier | 트리 수와 학습/예측 시간 |
| 09 | ExtraTreesClassifier | Random Forest와 비교 |
| 10 | AdaBoostClassifier | 약한 학습기 수·시간 |
| 11 | HistGradientBoostingClassifier | 반복 수·학습 시간·실행 예산 |
| 12 | Perceptron | 반복 수·수렴 기록 |
| 13 | MLPClassifier | 반복 수·수렴 경고·입력 스케일 |

**1차 평가의 공통 조건 (모델 선정용 Baseline, 아직 실행 전)**

1. **데이터와 누출 방지:** 최종 v3 공식 Training 96,000장을 **원본+증강본 그룹 단위로 먼저** Train/Validation으로 나누고 그 후 계층화·균형화된 소규모 표본을 추출한다. 예비 규모는 **Train 12,000장(클래스당 750장) / Validation 3,200장(클래스당 200장)**을 출발안으로 한다. 그룹 제약으로 정확한 수량 확보가 불가능하면 실제 개수 및 이유를 기록한다. 13개 후보는 **완전히 동일한 샘플 인덱스**를 사용한다.
2. **최소 공통 전처리:** 모든 모델은 28×28 → 784개 특성, `float32`, 픽셀 `/255`를 기준으로 한다. `StandardScaler`처럼 모델별로 필요한 추가 전처리를 사용하는 경우 **학습 데이터에서만 `fit`하는 Pipeline**에 넣고 적용 여부를 표시한다. 초기 탐색에서 모델별 전처리가 다르면 단일 변수만의 효과로 해석하지 않는다.
3. **실행 예산:** 기본값 또는 단순한 초기 설정으로 **후보당 짧게 1회 학습**한다. 전체 데이터 최적화, GridSearch 및 다중 Seed 반복은 이 단계에서 수행하지 않는다. 동일 컴퓨터·CPU 스레드 등 실행 환경과 후보별 **사전 시간 상한**을 실행 전에 기록한다. 제한 시간 초과·메모리 부족은 **실패 사유**로 기록하며 정확도 0점으로 간주하지 않는다.
4. **독립 평가 데이터:** 이 단계는 **공식 Training에서 분리한 Validation만** 사용한다. 공식 Test 16,000장 및 Hand-made 2,560장은 13개 초기 후보의 학습·순위 산정에 섞지 않는다. Hand-made를 통한 Normal/Combined 비교는 후속 C단계에서 수행한다.

**초기 평가 지표 및 선정 우선순위**

| 순서 | 항목 | 정의·기록 기준 | 활용 |
|---|---|---|---|
| **1 (핵심)** | **Validation Accuracy** | 전체 정답 수 / 같은 Validation 이미지 수 | 1차 성능 순위 |
| **2 (핵심)** | **Macro F1** | 16개 클래스 F1의 단순 평균 | 클래스별 성능 편차 확인, 정확도 근접 시 판단 |
| **3 (필수)** | **추론 시간** | 동일 Validation 3,200장에 대한 전체 `predict` 시간 및 이미지당 평균 시간. 전처리 포함 여부 통일 | 근접 모델의 실제 사용 효율 비교 |
| **4 (필수)** | **학습 시간** | `fit` 전체 실행 시간. Pipeline의 전처리 학습 포함 | 반복 최적화 비용과 실행 가능성 |
| **보조** | 수렴/실행 안정성 | 경고, 오류, 수렴 반복 수, 메모리·시간 제한, `random_state` 적용 여부 | 결과의 신뢰성 및 실행 불가 사유 |

- **선정 원칙:** Accuracy를 우선하고 Macro F1로 검증한다. **성능 차이가 근소한 후보군**에서는 추론 시간을 더 중요하게 비교하고, 유사한 성능·비용이라면 **분류 원리의 다양성**도 고려한다. 근소함을 구분할 수치 범위는 초기 결과의 분포·반복 변동을 본 후 확정한다. 근거 없는 임의 가중치로 종합 점수 하나를 만들지 않는다.
- **중요:** 기존 우선 검토 모델 **LinearSVC / Random Forest / MLP / KNN** 4종은 *사전 잠정안*일 뿐이다. 13개 결과가 다른 조합을 더 설득력 있게 보여주면 **최종 4종을 변경할 수 있다.**
- **원본 기록 보존:** W01의 EXP-유-001은 당시의 **이론 기반 3개 선정 이력**으로 남겨두고, W02의 **실측 기반 13개 → 4개 재선정**을 새 실험으로 기록한다.
- **완료 기준:** **13개 후보 전부**의 성공·실패·미실행 사유까지 포함한 비교표, 공통 조건·코드 및 **4개 선정/9개 보류·제외 사유**. 실측 결과가 나오기 전에는 등수를 작성하지 않는다.

### 단계 B — 선정된 4개 모델의 학습·개별 최적화

- 고정한 **동일 Training/Validation 분할**로 각 모델의 기본 설정과 개선 설정을 비교한다. 개선 전에 기준(Baseline)을 저장한다.
- 공통 입력(28×28 → 784개 특성), 공통 평가 코드와 데이터 버전은 유지한다. 전처리(0~1 정규화, 모델별 표준화 등) 및 Hyperparameter는 모델 특성에 맞게 바꾸되, **변경 전/후 조건과 결과를 각각 기록**한다.
- 예시 탐색 축(확정 값 아님):

| 모델 | 조정할 변수 후보 | 전처리·확인 항목 |
|---|---|---|
| **LinearSVC** | `C`, `max_iter`, 허용 오차 | 정규화·표준화; 수렴 경고 및 Margin 기반 분류 |
| **RandomForestClassifier** | `n_estimators`, `max_depth`, `min_samples_leaf`, `random_state` | 트리 계열의 불필요한 스케일링 여부, 학습/추론 시간 |
| **MLPClassifier** | `hidden_layer_sizes`, `alpha`, `learning_rate_init`, `max_iter`, `random_state` | 입력 스케일링, Loss·수렴·반복 횟수 |
| **KNeighborsClassifier** | `n_neighbors`, `weights`, 거리 지표·`p` | 스케일링, 이웃 탐색·예측 시간. **반복 학습(`max_iter`) 대상 아님** |

- 교수님 피드백 반영: 확률적 요소가 있는 모델은 **Random State를 바꿔 반복 실행**해 변동성을 확인한다. `max_iter`에 도달했고 **미수렴 또는 개선 추세**가 관찰되는 모델은 반복 횟수 확대를 검토한다. **이미 수렴했거나 성능 향상이 멈춘 경우 무조건 반복 수만 늘리지 않는다.**
- **완료 기준:** 모델별 Baseline과 최소 한 가지 전처리·Hyperparameter 변경 결과를 비교할 수 있는 실행 로그, 설정표, 성능표. 정확한 탐색 횟수와 범위는 실측 비용 확인 후 정한다.

### 단계 C — Normal/Combined Dataset 비교 및 성능 저하 분석

- **Normal:** MNIST·EMNIST만 사용한 학습 결과.
- **Combined:** MNIST·EMNIST에 **Hand-made 일부를 추가**해 학습한 결과.
- Hand-made 4개 파일(41·42·43·44, 각 640장, 총 2,560장)은 **학습에도 사용 가능**하다. 다만 같은 이미지를 학습과 평가에 동시에 쓰지 않으며, 예를 들어 **작성자 단위 보류 평가(한 명 제외 후 나머지 작성자로 학습)** 방식 등을 별도 확정한다.
- 41·42·44번 이미지 방향과 0/1 픽셀 극성 등 입력 검증을 포함해 **두 학습 방식에 동일한 평가 데이터·전처리 기준**을 적용한다.
- Validation 대비 Hand-made 인식 정확도 하락, 작성자별 성능 차이, Normal 대비 Combined 변화량을 기록한다. **모델 선정에 사용한 평가셋을 '미사용 최종 독립 Test'라고 부르지 않는다.**
- **완료 기준:** 학습에 포함한 Hand-made 출처 및 이미지 수, 홀드아웃 출처, 두 학습 조건의 비교 결과표.
- 교수님이 단계적으로 배포하는 **1차/2차 외부 평가 데이터의 사용 규칙은 그 단계의 별도 조건에 따라 관리**한다.

### 단계 D — 최종 후보 선정과 추가 Fine-tuning

- 4개 모델의 개선 후 **Validation Accuracy·Macro F1·Confusion Matrix**, Hand-made에 대한 일반화 성능과 **추론 시간**을 종합해 순위를 정한다.
- **상위 1·2위 성능이 근소하면** 두 모델을 동시에 추가 Fine-tuning한다. 실제 차이의 허용 범위와 판단 기준은 실측 변동성·실행 비용을 보고 결정한다.
- 추론 시간을 비교할 때는 **같은 하드웨어, 같은 입력 수·배치 크기, 같은 전처리 포함 범위**를 사용한다.
- **완료 기준:** 최종 모델 1개의 **실측 근거가 있는 선정 사유**, 경쟁 모델의 제외 이유, 필요 시 상위 2개 추가 비교표. 최종 설정 확정 후 별도로 보류한 Test로 최종 평가한다.

> **주차 범위:** W02는 우선 **A단계 후보 비교 및 4개 선정, B단계의 Baseline과 초기 개선 실험 착수**를 목표로 한다. B~D 전 과정을 11월 15일까지 완료했다고 미리 가정하지 않으며, 후속 주차에 연결한다.

## 3. 실험 간 공통 비교 원칙

1. **데이터:** [최종 v3 112,000장 NPZ](../../02_data/datasets/MNIST_EMNIST_official_split_112000.npz). 공식 Training **96,000장** 안에서 고정된 Training/Validation을 만든다. 공식 Test **16,000장**은 최종 독립 평가용으로 분리한다.
2. **누출 방지:** 기존 증강본과 생성 원본이 같은 학습/검증 그룹에 있도록 분할하고, Validation의 정보로 학습 전처리 통계량을 산출하지 않는다. 정확한 그룹핑 기준과 인덱스/Seed를 저장한다.
3. **기본 입력:** 16개 클래스(0~9, A~F), 28×28 → 784. 0~255 입력과 Hand-made 0/1 입력의 스케일 차이를 기록해 공통적으로 처리한다.
4. **평가:** Accuracy, Macro F1, 클래스별 점수, Confusion Matrix, 학습 시간 및 **실제 예측 시간(추론 시간)**. 필요하면 수렴 횟수·경고·시간 제한을 보고한다.
5. **공정 비교:** 같은 Validation 샘플과 공통 성능 계산 로직을 사용하되, **모델별로 적절한 전처리·Hyperparameter 탐색은 허용**한다. 예비 평가 결과와 최적화 결과는 별도 표로 기록한다.
6. **재현성:** 입력 파일/버전, 추출 표본/분할 방식/Seed, 코드·scikit-learn 버전, 장치/스레드, 모델별 파라미터, 시작/종료 시각과 실제 실행 결과를 기록한다.

**역할 분담 원칙:** 4명의 팀원(유용성·김다연·이선형·곽지호)이 병렬로 참여하도록 배분한다. **누가 어느 알고리즘을 맡을지, **13개 후보의 모델별 초기 구현 방식**, 실험 시간 예산, 주요 전처리 및 Hyperparameter 탐색 횟수는 다음 회의에서 확정한다.** W01의 완료 기록과 실제로 실행하지 않은 W02 결과를 혼동하지 않는다.

## 5. W01에서 이어지는 사항 및 기록 규칙

- W01: 이론적 모델 검토 및 데이터셋 v3 구성·검증. W02: **기존 13개 후보 전체의 소규모 예비 학습 → 실제 수치에 근거한 4개 모델 선정 → 최적화 실험 착수**.
- 기존 [실험일지 양식](../EXPERIMENT_TEMPLATE.md)에 따라 개별 실험의 입력, 조건, 변경 이유, 실행 코드, 결과 및 검증을 기록한다. 실패한 실험도 보존한다.
