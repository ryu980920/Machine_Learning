## 팀원 전원 후속 공통 수행 항목

| 작업 | 모두가 수행할 일 | 최소 근거 |
|---|---|---|
| **오류·원인 분석** | Raw/현행 입력에서 오분류를 추출하고 실제 개발 데이터의 이미지·작성자·클래스/특성을 비교 | 오분류 예시, 혼동 클래스, 추정 원인과 확인된 사실 분리 |
| **데이터 특성 정량화** | Original과 Hand-made의 중심/크기/밝기/기울기/획 굵기/잘림 등 담당 가설의 차이를 수치로 측정 | 분포표·그림, 샘플 수·계산 함수, 코드 |
| **Pipeline/증강 실험** | 각자 다른 자동 전처리 또는 Training 증강 가설을 개발·검증; 임의 수동 이미지 보정과 구별 | Raw vs 개선, 변수 고정, Accuracy·Macro F1·시간 |
| **모델 비교·로그** | 동일 Validation에서 Normal/Combined와 후보 모델 효과를 검증하고 악화 결과도 기록 | Notebook, CSV/Confusion Matrix, 실험일지·다음 시도 |

팀원별 구체적인 역할·담당 모델·병렬 일정은 팀장이 직접 작성할 예정이므로 현재는 미확정이다. 교수님 강조사항인 오류 분석·데이터 처리·전처리 검증의 중요성만 공통 원칙으로 남긴다.

## 교수님 최신 답변을 반영한 후속 실험 순서

[확정 연구 흐름도](../01_project/RESEARCH_FLOW.md)를 따른다.

1. 기존 Hand-made **2,560장 Confusion Matrix/오분류·분포 분석**과 Training Augmentation·자동 Pipeline을 개발한다. 실제 작성자 기준 Group CV는 개발용 선택지이고 신규 Validation 수집도 가능하다.
2. **Normal 최적 모델 1개, Combined 최적 모델 1개를 각각 독립 선정·최적화**한다. 같은 설정의 Normal/Combined 비교는 보조 통제 실험이다.
3. **최적 모델 2개 설정 동결 → Original Test 16,000장(MNIST 10,000 + EMNIST A–F 6,000) 평가 → 교수님 1차 Hand-made Test**에서 성능 확인한다.
4. **1차 만족:** 추가 변경 없이 평가 결과를 보고서에 정리하고 제출한다.
5. **1차 미흡:** 교수님 직접 허용에 따라 1차를 **Validation으로 전환**하여 오류·특성 분석, 데이터·전처리·모델 개선. 설정을 다시 고정한 뒤 **교수님 2차 최종 Test에 한 번만** 적용하고 종료한다.
6. **독립 Test와 개발용 Validation 구별:** Original Test/2차는 최적화에 사용하지 않는다. 1차도 최초 평가 전에는 개발에 쓰지 않고, Validation 전환 후 결과는 **독립 Test로 주장하지 않는다**. 입력 자동 Pipeline은 각 Test 시점에 사전 고정한 설정을 동일하게 적용한다.

**아직 미실시:** 5개 모델의 독립 Normal/Combined 최적화, 최종 모델 2개 선정, 교수님 1·2차 평가. 기존 W01/W02 실측 수치는 변경하지 않았다.
