# 03_experiments — 모델 실험 및 결과 기록

## 1. 개요

머신러닝 모델 학습과 평가, 성능 저하 원인 분석, 데이터·모델 개선 과정 및 시행착오를 기록합니다. 특히 어떤 문제를 발견했고 무엇을 바꾼 뒤 결과가 어떻게 달라졌는지를 남깁니다.

## 2. 작업 내용

- eMNIST 16개 클래스로 초기 모델을 학습하고 Training/Validation 조건 및 기본 성능을 기록합니다.
- 초기 모델을 손글씨 데이터로 평가하여 클래스별 오분류와 데이터 특성 차이를 분석합니다.
- Hand-made 데이터를 추가한 Combined Dataset을 구성한 뒤 전후 성능을 비교합니다.
- 수업에서 배운 모델 또는 scikit-learn 모델 후보를 비교하고, 선택 근거와 Hyperparameter 변경 과정을 기록합니다.
- 1차 배포 데이터로 Semi-supervised Learning과 Label Propagation을 검증합니다.
- 레이블이 없는 2차 배포 데이터로 후속 학습을 진행하고, 마지막 독립 테스트 데이터에서 모델을 평가합니다.
- 정확도·학습시간·예측시간·오분류 사례·가능한 경우 Learning Curve를 기록하고 Notebook 및 그래프와 연결합니다.

**실험 원칙:** TensorFlow·PyTorch 신경망 모델은 사용하지 않으며, 수업에서 배운 머신러닝 및 허용된 scikit-learn 모델을 사용합니다. 초기 성능이 낮거나 가설이 틀린 실험도 결과와 이유를 함께 보존합니다.
