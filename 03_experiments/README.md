## 파일 관리 규칙

1. **주차별 `README.md`**: 팀장 지시 시점의 담당자·작업 목표·완료 기준·산출물, 지시 변경 이력을 기록한다.
2. **`logs/EXP-[A/B/C/D]-[번호]_제목.md`**: 팀원의 작업 과정·선택 이유·적용 조건·실제 수치·문제·근거 파일을 기록한다. A=유용성, B=김다연, C=이선형, D=곽지호.
3. **`WEEK_SUMMARY.md`**: 실제로 제출된 로그를 근거로 완료·미완료·보완 사항을 종합한다. 주차가 끝나기 전에는 **초안**으로 표시한다.
4. 공통 작성 기준은 [EXPERIMENT_TEMPLATE.md](EXPERIMENT_TEMPLATE.md)를 따른다. 수행·증강 절차 기록을 강화하는 템플릿 개정은 후속 작업으로 진행한다.
5. Notebook·NPZ 등의 데이터 산출물은 `02_data/`, 발표자료는 `04_reports/`에 저장하고 각 실험 로그에서 참조한다. 같은 데이터 파일을 주차별로 복제하지 않는다.
6. 실험 로그를 AI로 정리할 때에도 실제 실행·실측이 아닌 내용을 작성하지 않는다. 확인 안 된 부분은 `확인 필요`, 아직 측정하지 않았으면 `미측정`으로 표시한다.

**데이터 이용 원칙:** 교수님 배포 평가 데이터와 사전에 테스트 전용으로 지정한 Hand-made 데이터는 학습·튜닝에 사용하지 않는다. 전처리 파이프라인은 독립적으로 정의한 뒤 평가 시 동일한 절차로 적용한다. 이전 계획에 있던 테스트 데이터 의사 레이블 재학습은 현재 계획에 포함하지 않는다.
