**현재 실제 완료:** 실험 1(13개 후보 평가·5개 선정), 실험 2(Normal Baseline 5개), 실험 3(Hand-made 평가·데이터 오류 분석) 및 별도 42번 구/신 Grayscale 비교. [EXP유002 8절](W02_2026-11-09_11-15/logs/EXP유002_5개모델_Normal_Baseline.md)에서 **새 42번 예측과 기존 41·43·44번 예측을 결합한** 최신 Rotation 비교 확인. 5개 모델의 Combined 학습과 본격 최적화는 미실시.

|---|---|---|
| ① Normal vs Combined | 모델 기본 설정 고정. 공식 Train 76,800 vs 동일 Train+Hand-made 2,560 후보를 **같은 신규 Hand-made Validation** 및 공식 Validation에서 평가 | 계획 |
| ② 모델별 최적화 | 데이터 오류 분석·전처리·증강·하이퍼파라미터 등 각 모델의 변경 전후 비교 | 계획 |
| ③ 최적화 5개 비교 | 동일한 신규 Hand-made Validation 우선, 공식 Validation과 시간 보조 | 계획 |
| ④ 최종 모델 확정 | 1개 선정·추가 개선 후 모델 및 전처리 고정 | 계획 |
| ⑤ 독립 Test | 신규 Hand-made Test + 공식 MNIST·EMNIST Test 16,000장, 각각 평가 | 계획 |

신규 손글씨 Validation 640장(8명×80) 및 Test 640장(다른 8명×80)은 **권장안으로 아직 미확정**. 작성자 누출 금지. 손글씨 Training 편입도 효과 검증 후 확정. LOWO-CV는 논의했으나 운영 방식으로 확정하지 않았다. [최신 연구계획](../01_project/RESEARCH_PLAN.md) 및 [데이터 수집·분할안](../02_data/HANDMADE_SPLIT_PLAN.md) 참조.

**재현 코드 제공:** [학습 전 모델 5개](model_optimization/README.md). 개별 `build_baseline()`을 보존하고 `build_candidate()`를 수정하여 팀원이 직접 학습. **저장된 .joblib 5개 파일을 공유하지 않는다.** 새 코드의 전체 실제 재학습 결과 일치 여부는 검증 전까지 미검증이다.

## 파일 관리 규칙

1. **주차별 `README.md`**: 팀장 지시 시점의 담당자·작업 목표·완료 기준·산출물, 지시 변경 이력을 기록한다.
2. **`logs/EXP-[유/김/이/곽]-[번호]_제목.md`**: 팀원의 작업 과정·선택 이유·적용 조건·실제 수치·문제·근거 파일을 기록한다. 유=유용성, 김=김다연, 이=이선형, 곽=곽지호.
3. **`WEEK_SUMMARY.md`**: 실제로 제출된 로그를 근거로 완료·미완료·보완 사항을 종합한다. 주차가 끝나기 전에는 **초안**으로 표시한다.
4. 공통 작성 기준은 [EXPERIMENT_TEMPLATE.md](EXPERIMENT_TEMPLATE.md)를 따른다. 개정된 양식에는 **AI의 팀원 대상 누락 정보 질문·자료 요청 절차**, 단계별 수행 기록표, 데이터 증강·모델 선정·학습 유형별 필수 확인 항목이 포함되어 있다.
5. Notebook·NPZ 등의 데이터 산출물은 `02_data/`, 발표자료는 `04_reports/`에 저장하고 각 실험 로그에서 참조한다. 같은 데이터 파일을 주차별로 복제하지 않는다.
6. 실험 로그를 AI로 정리할 때에도 실제 실행·실측이 아닌 내용을 작성하지 않는다. 확인 안 된 부분은 `확인 필요`, 아직 측정하지 않았으면 `미측정`으로 표시한다.

**로그 파일명:** `W01`, `W02` 등 **주차별·작성자별 `EXP유001`부터 시작**한다. 작성자 코드 유/김/이/곽. 예: W02 유용성 로그는 `EXP유001` ~ `EXP유004`; 기존 결과 CSV/이미지 파일명은 이력 보존을 위해 그대로 둔다.

**데이터 이용 원칙:** 교수님 설명에 따라 Normal Dataset(MNIST·EMNIST)과 Combined Dataset(Hand-made 추가 학습)을 구분해 실험할 수 있다. **학습에 사용한 Hand-made 이미지를 같은 실험의 평가 데이터로 다시 쓰지 않으며**, 홀드아웃과 작성자 구분을 기록한다. 교수님이 단계적으로 배포하는 평가 데이터는 해당 단계의 별도 지침에 따라 관리한다. 입력 전처리는 학습 데이터 기준으로 정의하고 평가에 동일하게 적용한다.
