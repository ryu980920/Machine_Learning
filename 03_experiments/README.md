## 파일 관리 규칙

1. **주차별 `README.md`**: 팀장 지시 시점의 담당자·작업 목표·완료 기준·산출물, 지시 변경 이력을 기록한다.
2. **`logs/EXP-[유/김/이/곽]-[번호]_제목.md`**: 팀원의 작업 과정·선택 이유·적용 조건·실제 수치·문제·근거 파일을 기록한다. 유=유용성, 김=김다연, 이=이선형, 곽=곽지호.
3. **`WEEK_SUMMARY.md`**: 실제로 제출된 로그를 근거로 완료·미완료·보완 사항을 종합한다. 주차가 끝나기 전에는 **초안**으로 표시한다.
4. 공통 작성 기준은 [EXPERIMENT_TEMPLATE.md](EXPERIMENT_TEMPLATE.md)를 따른다. 개정된 양식에는 **AI의 팀원 대상 누락 정보 질문·자료 요청 절차**, 단계별 수행 기록표, 데이터 증강·모델 선정·학습 유형별 필수 확인 항목이 포함되어 있다.
5. Notebook·NPZ 등의 데이터 산출물은 `02_data/`, 발표자료는 `04_reports/`에 저장하고 각 실험 로그에서 참조한다. 같은 데이터 파일을 주차별로 복제하지 않는다.
6. 실험 로그를 AI로 정리할 때에도 실제 실행·실측이 아닌 내용을 작성하지 않는다. 확인 안 된 부분은 `확인 필요`, 아직 측정하지 않았으면 `미측정`으로 표시한다.

**데이터 이용 원칙:** 교수님 설명에 따라 Normal Dataset(MNIST·EMNIST)과 Combined Dataset(Hand-made 추가 학습)을 구분해 실험할 수 있다. **학습에 사용한 Hand-made 이미지를 같은 실험의 평가 데이터로 다시 쓰지 않으며**, 홀드아웃과 작성자 구분을 기록한다. 교수님이 단계적으로 배포하는 평가 데이터는 해당 단계의 별도 지침에 따라 관리한다. 입력 전처리는 학습 데이터 기준으로 정의하고 평가에 동일하게 적용한다.
