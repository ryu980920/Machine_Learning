## 2. 작업 간 연계와 경계

1. 곽지호 데이터셋의 수량·형식 확보와 이선형의 중복 검수·증강 다양화는 **별도 완료 조건**으로 취급한다.
2. 원본 데이터, 이동 증강본, 회전·획 두께 증강본의 출처와 버전을 구분한다. Train/Validation 간 원본·증강 중복이 있는지 확인한다.
3. 기존 곽지호 로그는 **105,341개 원본 + 6,659개 증강 및 90/10 계층화 분할**을 기록한 이전 버전이다. 현재 GitHub의 **공식 분할 기준 Notebook/NPZ는 별도 버전**이므로, 검증 없이 같은 실행 결과로 묶지 않는다.
4. 팀장 선정 모델 3개는 **LinearSVC / RandomForestClassifier / MLPClassifier**이다. 모델 학습·성능 비교는 W01에서 실시한 것으로 기록하지 않는다.
5. 교수가 배포한 테스트 전용 데이터는 학습·튜닝에 포함하지 않는다.
