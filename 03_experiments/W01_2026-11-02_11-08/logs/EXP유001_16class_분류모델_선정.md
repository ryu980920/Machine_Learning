## 1. 문제 발견 및 실험 목적

- **현재 상황/발견한 문제:** 프로젝트는 MNIST 숫자 0–9와 EMNIST 대문자 A–F를 통합한 **16개 클래스 손글씨 분류**를 목표로 한다. 강의에서 배운 분류기 중 어떤 모델을 비교해야 각 알고리즘의 차이가 명확하게 드러나는지 결정해야 했다.
- **문제의 근거:** 강의에 등장하는 분류기에는 선형 분류, 거리 기반 분류, 결정 트리, 앙상블, 다층 신경망 등 다양한 방식이 포함되어 있다. 단순히 이름이 다른 모델을 선택하면 학습 원리가 겹칠 수 있다. 예를 들어 Logistic Regression의 OvR과 Softmax는 같은 선형 확률 분류 계열이고, Decision Tree·Random Forest·Extra-Trees도 트리 기반이라는 공통점이 있다.
- **이번 작업의 목표:** 강의 범위의 후보를 나열하고, 선정·제외 근거를 남긴 뒤 **분류 원리가 다른 3개 모델**을 확정한다. 정확도 우열은 이번 작업에서 판단하지 않는다.

## 2. 원인 분석 및 해결 방법

### 2.1 검토 기준 설정

모델을 바로 3개 고르지 않고 다음 기준으로 후보를 검토하였다.

| 검토 기준 | 확인 내용 |
|---|---|
| ① 다중 클래스 적용 | 0–9, A–F의 16개 레이블을 처리할 수 있는가? OvR·OvO 등의 확장 방식도 포함한다. |
| ② 학습 원리의 차별성 | 세 모델의 **목적함수·파라미터 학습 방식·분류 원리**가 충분히 다른가? |
| ③ 강의 범위 및 구현 | 강의에서 다룬 내용을 바탕으로 scikit-learn에서 구현·설명할 수 있는가? |
| ④ 데이터 규모 | 28×28 이미지(784개 픽셀 특성), 약 10만 개 이상의 학습 후보 데이터에서 실험을 시도하기 현실적인가? |
| ⑤ 후속 비교 가능성 | 같은 학습·검증 분할에서 Accuracy, Macro F1, Confusion Matrix, 학습·예측 시간을 측정할 수 있는가? |

> **주의:** 위 기준은 모델을 선택하기 위한 사전 판단 기준이다. 학습 속도나 정확도를 실제로 측정하여 순위를 매긴 결과가 아니다.

### 2.2 1차 검토 — 강의에서 다룬 후보 13개 항목

아래 13개는 **후보 항목 수**이다. OvR Logistic Regression과 Softmax Regression처럼 동일 계열의 구현 방식이 별도 항목으로 포함되어 있어, 완전히 독립적인 알고리즘 13종이라는 뜻은 아니다.

| 번호 | 모델·방식 | 다중 클래스 처리 | 이번 선정에서의 판단 |
|---:|---|---|---|
| 1 | Logistic Regression + OvR | 클래스마다 이진 분류기 구성 | **제외:** Softmax 및 LinearSVC와 선형 분류라는 공통점이 크다. |
| 2 | Softmax Regression | 16개 클래스의 점수를 함께 확률화 | **보류:** 직접 다중 클래스 분류가 가능하지만, 이번에는 선형 계열 대표로 Margin 기반 LinearSVC를 선택한다. |
| 3 | SGDClassifier | 설정한 손실함수로 학습, 다중 클래스는 OvR | **제외:** `loss='hinge'` 등 설정에 따라 선형 SVM과 학습 목표가 겹친다. |
| 4 | **LinearSVC** | 기본 OvR, 16개의 이진 선형 분류기 | **선정:** Margin 기반 목적함수를 사용하는 선형 기준 모델. |
| 5 | SVC (linear / polynomial / RBF) | 기본 OvO | **보류:** RBF 등으로 비선형 분류가 가능하지만, 대규모 데이터에서 학습 비용 부담을 우선 고려한다. |
| 6 | KNeighborsClassifier (KNN) | 가장 가까운 이웃의 레이블로 직접 분류 | **보류:** 거리 기반이라는 차별점이 있으나, 학습 데이터를 보관하고 많은 이미지에 대해 거리를 계산해야 하므로 예측 비용을 고려한다. |
| 7 | DecisionTreeClassifier | 분기 규칙으로 직접 분류 | **제외:** 트리 계열에서는 단일 트리보다 여러 트리의 변동성을 줄이는 Random Forest를 대표 모델로 선택한다. |
| 8 | **RandomForestClassifier** | 결정 트리들의 클래스 확률을 평균 | **선정:** 분기 기준과 Bootstrap·무작위 특성 선택을 사용하는 트리 앙상블. |
| 9 | ExtraTreesClassifier | 매우 무작위적인 트리 앙상블 | **제외:** Random Forest와 같은 트리 앙상블 계열이라 세 모델의 원리 차별성이 줄어든다. |
| 10 | AdaBoostClassifier | 약한 학습기를 순차적으로 결합 | **보류:** 앙상블의 다른 방식이지만, 이번에는 트리 계열 대표로 Random Forest를 우선한다. |
| 11 | HistGradientBoostingClassifier | 순차적 Boosting 기반 분류 | **보류:** 별도 실험 가치가 있지만, 이번 3개 선정 목적에서 앙상블 계열 중복을 줄인다. |
| 12 | Perceptron | 선형 결정 경계 기반 분류 | **제외:** 선형 모델이라는 점에서 겹치고, 비선형 표현을 살펴보기 위해 MLP를 선택한다. |
| 13 | **MLPClassifier** | Hidden Layer와 16개 출력으로 직접 분류 | **선정:** 비선형 활성화 함수, 역전파 및 최적화 알고리즘으로 가중치를 학습한다. |

**후보에 포함하지 않은 방법:** VotingClassifier와 StackingClassifier는 여러 분류 모델을 조합하는 **메타 앙상블 구성 방식**으로 구분하였다. 이번 목적은 독립 모델 3개의 성능 차이를 먼저 비교하는 것이므로 별도 후보로 선정하지 않았다. PCA는 차원 축소, K-Means·DBSCAN은 군집화 알고리즘이므로 분류기 후보에서 제외하였다. **Random Forest 역시 앙상블 모델**이지만, 의사결정나무 기반의 독립적인 분류 알고리즘 한 종류로 평가할 수 있다는 점에서 포함하였다.

### 2.3 2차 검토 — 겹치는 학습 원리 정리

1. **선형 계열:** OvR Logistic Regression, Softmax Regression, SGDClassifier, Perceptron, LinearSVC는 손실함수·최적화 방식에 차이가 있지만 선형 결정 경계를 사용한다는 공통점이 있다. 이번에는 **Margin 및 위반 페널티**라는 해석 기준이 분명한 LinearSVC를 선정하였다.
2. **트리·앙상블 계열:** Decision Tree, Random Forest, Extra-Trees, Boosting 계열을 검토하였다. 여러 트리의 분할 규칙을 활용하는 Random Forest를 선정하여 선형 모델과 다른 학습 방식을 비교하기로 했다.
3. **비선형 표현 학습 계열:** MLP는 트리의 분할 규칙과 달리 층별 가중치와 Bias를 **역전파**로 학습한다. 이를 통해 세 번째로 다른 학습 원리를 확보하고자 선정하였다.
4. **대안 후보:** RBF SVC와 KNN은 각각 커널 기반 비선형 분류와 거리 기반 분류를 대표하지만, 데이터 규모에 따른 계산 부담을 고려해 이번 3개에서는 보류하였다. 이는 성능이 낮다고 확인되어 제외한 것이 아니다.

### 2.4 최종 선정 모델 및 근거

| 선정 모델 | 분류·학습 원리 | 학습 시 결정하는 내용 | 비교에서 확인할 질문 |
|---|---|---|---|
| **LinearSVC** | OvR로 16개 이진 선형 분류기 구성. 정규화 항과 Margin 위반 손실(기본 `squared_hinge`)을 함께 최소화 | 클래스별 가중치·Bias | 선형 결정 경계만으로 16개 손글씨를 얼마나 구분할 수 있는가? |
| **Random Forest** | 무작위 표본·특성을 사용해 여러 결정 트리를 생성. 각 분기에서 Gini Impurity 등의 불순도 감소를 기준으로 분할 | 각 트리의 분기 특성·임계값·잎 노드의 클래스 분포 | 트리의 비선형 분기와 앙상블이 실제 손글씨 분류에 어떤 결과를 보이는가? |
| **MLPClassifier** | 층별 가중합과 비선형 활성화 함수로 특징을 변환. Cross-Entropy 기반 손실을 역전파하여 가중치 최적화 | 은닉층·출력층의 가중치·Bias | 비선형 표현을 학습하는 신경망이 다른 두 접근법과 어떻게 다른 성능을 보이는가? |

**선택 이유:** 세 모델은 각각 **Margin 기반 선형 최적화 / 트리의 불순도 기반 분기 및 앙상블 / Cross-Entropy 기반 역전파 학습**을 대표한다. 또한 모두 scikit-learn에서 구현할 수 있고, 같은 검증 데이터에 대해 동일한 평가 지표를 사용할 수 있다.

**예상 결과:** 모델마다 손글씨 위치·굵기·형태 변화에 대한 반응과 학습·예측 비용에 차이가 나타날 가능성이 있다. 어느 모델의 정확도가 더 높을지는 실제 학습 후 확인한다.

| 학습 시간 / 예측 시간 | 미측정 | **미측정** | 모델 학습 없음 |

- **관찰된 변화:** 비교 목표를 단순한 '모델 2개 비교'에서 **서로 다른 학습 원리의 모델 3개 비교**로 구체화하였다.
- **대표 사례 또는 예외:** Random Forest도 여러 결정 트리를 결합하는 앙상블이므로 VotingClassifier와 '앙상블 여부'만으로 구분할 수 없다. 대신 **Random Forest 자체를 한 개 분류 모델로 평가하는 것**과 **서로 다른 모델을 조합한 VotingClassifier를 추가로 학습하는 것**을 구분했다.
- **비교 가능성:** 세 모델의 실제 정확도 비교는 아직 불가능하다. 다음 주 동일한 학습·검증 데이터, 같은 평가 지표, 기록된 전처리 조건에서 비교할 예정이다.

## 5. 결과 해석 및 최종 판단

- **최초 문제/질문에 대한 답:** **해결 — 3개 모델 선정 완료.** 강의 범위의 후보를 검토하고, 중복되는 학습 원리를 줄이면서 서로 다른 방식을 비교할 수 있는 3개 모델을 정했다.
- **판단 근거:** LinearSVC는 Margin 최적화, Random Forest는 불순도 기반 트리 분할·앙상블, MLP는 비선형 활성화 함수·역전파라는 구별되는 학습 과정을 가진다.
- **한계·추가 확인 사항:** 아직 학습을 실행하지 않았으므로 성능 우열, 학습 시간, 수렴 여부, 실제 필체 변화에 대한 일반화 성능은 판단할 수 없다. 후보 선정에 사용한 계산 비용 판단은 사전 고려사항이며 실측 결과가 아니다.
- **이번 작업의 결론:** **LinearSVC, RandomForestClassifier, MLPClassifier**를 다음 주 비교 실험 대상으로 사용한다. 이번 주 담당 업무는 모델 선정으로 마무리한다.
