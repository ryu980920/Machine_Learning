- **작성 기준일:** 2026-11-06

- **지시 사항:** [W01 README](README.md)

## 1. 이번 주 목표

MNIST·EMNIST 16개 클래스 데이터셋 구성과 품질 개선을 병행하면서, 다음 주 비교 학습할 원리별 모델 3개를 선정한다.

## 2. 담당자별 확인 현황

| 담당 | 확인된 작업 | 현재 판단 | 증거 |
|---|---|---|---|
| 유용성 | 13개 후보 항목을 검토하고 LinearSVC / Random Forest / MLP를 선정 | **선정 업무 완료**. 학습·평가 미실시 | [EXP-유-001](logs/EXP-유-001_16class_분류모델_선정.md) |
| 곽지호 | 기존 분할 방식으로 16개×7,000개 데이터셋 구성, 이동 증강 6,659개 기록 | **수량·파일 구조 검증 보고됨**. 중복·이미지 품질 추가 확인 필요 | [EXP-곽-001](logs/EXP-곽-001_MNIST_EMNIST_데이터셋_구성.md) |
| 이선형 | 중복 데이터 우선 검증·정리, 회전 및 획 두께 조절 증강 업무 배정 | **성과 자료 미확인**. 완료 여부 미판정 | 로그 미제출 |
| 김다연 | 중간 발표자료 작성 업무 배정 | **성과 자료 미확인**. 완료 여부 미판정 | 발표자료 미확인 |

## 3. 실제 확인 가능한 산출물

- [팀장 모델 선정 로그](logs/EXP-유-001_16class_분류모델_선정.md): 이론적 비교·선정만 수행, 실측 성능 없음.
- [곽지호 데이터셋 구성 로그](logs/EXP-곽-001_MNIST_EMNIST_데이터셋_구성.md): 원본 PDF의 수치·실행 이력 및 미확인 항목을 보존한 전사본.
- [공식 분할 구성 Notebook](../../02_data/notebooks/02_official_split_dataset.ipynb) 및 [공식 분할 NPZ](../../02_data/datasets/MNIST_EMNIST_official_split_112000.npz): **기존 EXP-곽-001의 분할 결과와 동일한 버전으로 간주하지 않음**.

## 4. 미완료·검증 대기 사항

- 중복 이미지 정의, 중복 탐지 결과 및 처리 전후 개수
- 픽셀 이동·회전·획 두께 증강의 실제 적용 범위, 변환 설정, 이미지 식별 가능 여부 및 Train/Validation 간 누출 검사
- 이선형 수행 로그와 개선 데이터셋의 존재·내용 확인
- 발표자료 제출 여부와 확정 내용 확인
- 기존 로그의 '선택 이유 확인 필요', 증강 품질 미측정 등 누락 정보 보완

## 5. 다음 주로 연결할 작업 (계획)

- 비교 후보: LinearSVC / RandomForestClassifier / MLPClassifier
- 세 모델의 담당자 배정은 **아직 미확정**. [W02 작업 지시](../W02_2026-11-09_11-15/README.md)에서 확정한다.
- 동일 데이터 분할·평가 지표로 Baseline을 측정하고, 각 모델의 조건·전처리·학습 시간·Accuracy·Macro F1·Confusion Matrix를 남긴다.
- 전처리 파이프라인 비교는 데이터 검증·모델 초기 비교 후 후속 실험으로 진행한다.

> **종합 판단은 주차 종료 시 갱신:** 현재 '모델 선정 완료' 이외의 업무를 완료했다고 확정하지 않는다.
