# 2026 머신러닝 프로젝트 연구계획 (2026-11-10)

## 연구 목적
MNIST·EMNIST 숫자 0–9 / 영문 A–F 총 16개 클래스에서 기본 모델의 Validation 성능은 높지만, 실제 팀원 Hand-made에서 정확도가 크게 떨어졌다. 후속 연구의 목표는 **새로운 사람의 손글씨를 더 잘 인식하도록 개선하고, 그 개선 효과를 별도 데이터로 입증**하는 것이다. 공식 MNIST·EMNIST 성능이 유지되는지도 별도 확인한다.

## 실제 완료한 실험

1. **실험 1:** 13개 후보 모델을 간단히 평가하여 SVC(RBF), HGB, MLP, Extra Trees, KNN 5개 선정. [EXP-유-002](../03_experiments/W02_2026-11-09_11-15/logs/EXP-유-002_13개후보_초기평가_5개선정.md)
2. **실험 2:** 공식 Training 96,000장 안에서 동일한 Train 76,800 / Validation 19,200 분할. 기본 하이퍼파라미터, 필요한 모델에만 스케일링, 5개 Baseline 성능 확인. [EXP-유-003](../03_experiments/W02_2026-11-09_11-15/logs/EXP-유-003_5개모델_Normal_Baseline.md)
3. **실험 3 및 추가 분석:** 팀원 4명 × 640장 = Hand-made 2,560장에 기존 5개 Normal 모델 평가. 성능 저하, 회전·극성·42번 Grayscale 원본 문제 분석. 원본 버전별 수치와 평가 시점은 EXP-유-004·005 및 EXP-유-003 8절에 보존한다. **아직 5개 모델 본격 최적화 및 Combined 학습은 실행하지 않음.**

## 향후 연구 순서

| 단계 | 핵심 활동 | 평가·결정 원칙 |
|---|---|---|
| ① Hand-made 추가 학습 효과 검증 | 각 모델의 Normal = 공식 Train 76,800, Combined = 같은 Train + 기존 Hand-made 2,560 후보 | **기본 설정을 고정**하고 같은 신규 작성자 Validation / 공식 Validation에서 비교. 성능 근거가 있을 때 추가 학습 채택 |
| ② 5개 모델별 최적화 | 오류 분석 → 전처리·증강·샘플 비중·모델별 Hyperparameter 조정 | 변경 이유, 변수, 전후 Accuracy·Macro F1·시간 기록 |
| ③ 최적화된 5개 모델 비교 | 동일한 Validation으로 재평가 | 신규 손글씨 우선, 공식 Validation·작성자별·클래스별 편차 및 추론비용도 확인 |
| ④ 최종 1개 선정 및 추가 개선 | 필요 시 Fine-tuning/재학습, 이후 설정 고정 | 최종 학습 데이터·설정·Seed 기록 |
| ⑤ 독립 Test | **미사용 신규 Hand-made Test와 공식 MNIST·EMNIST Test 16,000장**을 최종 모델에 각각 평가 | 손글씨 Test와 공식 Test 결과를 분리 보고; 이 점수로 재튜닝하지 않음 |
| ⑥ 교수님 배포 1차 데이터 평가 | 배포 지침에 따른 외부 평가 | 1차 후 개선 과제가 있으면 이후 평가와 구분해 기록 |

## 데이터 활용 및 확정 수준

- 기존 Hand-made 2,560장: **Combined Training 추가 후보**이며, 추가 학습의 효과 확인 전 자동 채택하지 않는다. 기존 2,560장이 '교수님 지침으로 테스트 전용'이라는 주장은 확정 사실이 아니다.
- 신규 Hand-made Validation: **권장 8명 × 80장 = 640장**, 새로운 작성자, 개발·모델 선택용.
- 신규 Hand-made Test: **권장 다른 8명 × 80장 = 640장**, 학습과 최적화에 미사용.
- **각 640장은 제안이지 확정된 수집 규모가 아니다.** 9:1 비율은 필수 규칙이 아니며 작성자 간 분리를 우선한다.
- 공식 Training 내부 Validation 19,200장과 공식 Test 16,000장을 혼동하지 않는다. 공식 Test는 ④ 후에 사용한다.
- 교수님 1차 데이터는 별도의 배포 지침과 수업 운영 방향에 따른다.
