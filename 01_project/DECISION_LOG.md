## 교수님 최신 개별 답변 및 팀 확정 실행 순서 (2026-11-10)

| 근거 | 확정된 내용 |
|---|---|
| 교수님 직접 답변 | **Original Test** = MNIST Test 10,000장. 본 팀의 16-class Original 평가에서는 사용자 확인에 따라 **EMNIST A–F 6,000장**을 합쳐 **총 16,000장** 적용 |
| 교수님 직접 답변 | **1차 Hand-made** = 최초 Test 후 **Validation으로 활용 가능** |
| 교수님 직접 답변 | **2차 Hand-made** = **최종 Test 용도로 한 번만 사용** |
| 교수님 직접 답변 | **Normal 및 Combined** = 각각 최적 모델을 독립적으로 찾음. 반드시 같은 알고리즘일 필요 없음 |
| 사용자 확정 운영안 | 기존 2,560장 분석·개선 → Normal/Combined 독립 최적화 → 모델 2개 동결 → **Original 16,000장** 평가 → **1차 Test 평가**. **만족하면 보고서 제출**, **불만족하면 1차를 Validation으로 전환**하여 보완 → **2차 Test 한 번 평가** |
| 평가 독립성 | 1차를 Validation으로 전환한 이후의 점수는 개발용 Validation 결과. 2차로 튜닝하지 않음. Original Test를 모델 선택에 사용하지 않음 |
